## bootstrap
- /ˈbuːtstræp/ · n. 引导程序；v. 引导，启动
- **bootstrap the system** 引导启动系统：The kernel bootstraps the system before handing control to user space.
- **bootstrap a project** 从零启动项目：They bootstrapped the startup without outside funding.

## module
- /ˈmɑːdʒuːl/ · n. 模块
- **import a module** 导入模块：Each module exposes a small, focused API.

## package
- /ˈpækɪdʒ/ · n. 软件包；v. 打包
- **install a package** 安装软件包：The package bundles the library with its dependencies.

## vocab
- /ˈvoʊkæb/ · abbr. 词汇（vocabulary）
- **build one's vocab** 扩充词汇：Reading source code builds your technical vocab.

## concatenate
- /kənˈkætəneɪt/ · v. 连接
- **concatenate strings** 拼接字符串：The function concatenates the first and last names.

## superfluous
- /suːˈpɜːrfluəs/ · adj. 多余的，不必要的
- **superfluous code** 冗余代码：Delete superfluous comments that restate the code.

## interpolate
- /ɪnˈtɜːrpəleɪt/ · v. 插入；内插
- **interpolate values** 内插数值：The shader interpolates colors across the triangle.

## lightweight
- /ˈlaɪtweɪt/ · adj. 轻量的
- **a lightweight framework** 轻量级框架：Flask is a lightweight web framework.

## de facto
- /ˌdeɪ ˈfæktoʊ/ · 事实上（的），实际（的）
- **the de facto standard** 事实上的标准：JSON has become the de facto standard for APIs.
