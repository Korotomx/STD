## simplistic
- /sɪmˈplɪstɪk/ · adj. 过分简单化的
- **a simplistic view** 过于简单化的看法：It's a simplistic view of a complex problem.

## hash
- /hæʃ/ · n. 哈希，散列
- **a hash function** 哈希函数：A hash function maps keys to buckets.

## decompose the problems
- 分解问题
- **decompose the problem into smaller ones** 把问题分解成小问题：Decompose the problem into smaller subproblems before coding.

## clutter
- /ˈklʌtər/ · n. 杂乱，凌乱
- **visual clutter** 视觉杂乱：Refactor to reduce visual clutter in the UI.

## Render Output
- 渲染输出
- **render output to the screen** 把输出渲染到屏幕：The GPU renders output to the screen at 60 frames per second.

## readability
- /ˌriːdəˈbɪləti/ · n. 可读性
- **improve code readability** 提高代码可读性：Meaningful names improve code readability.

## abbreviation
- /əˌbriːviˈeɪʃn/ · n. 缩写
- **an abbreviation for sth.** ……的缩写："CPU" is an abbreviation for Central Processing Unit.

## full name
- 全名，全称
- **the full name of a function** 函数的全称：Use the full name of the variable to avoid ambiguity.

## a to b inclusive
- 从 a 到 b（含两端）
- **from 1 to 10 inclusive** 从 1 到 10（含 1 和 10）：The loop runs from 1 to 10 inclusive.

## bash
- /bæʃ/ · v. 猛击；n. Bash（命令行解释器）
- **a bash script** Bash 脚本：The build is automated with a bash script.
