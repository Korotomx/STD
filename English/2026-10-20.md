## Claude Shannon
- 克劳德·香农（美国数学家、工程师，被誉为信息论创始人）
- **Claude Shannon's information theory** 香农的信息论：Claude Shannon laid the groundwork for digital communication.

## kick off
- 开始，启动
- **kick off a meeting / project** 开始会议 / 项目：Let's kick off the sprint with a quick stand-up.

## squishy and ill-defined
- 模糊不清、难以界定的
- **a squishy and ill-defined concept** 模糊难定的概念："Intelligence" remains a squishy and ill-defined concept.

## thought-provoking
- /ˈθɔːt prəvoʊkɪŋ/ · adj. 发人深省的
- **a thought-provoking question / paper** 发人深省的问题 / 论文：The paper asks a thought-provoking question about scaling.

## inexorable
- /ɪnˈeksərəbl/ · adj. 不可阻挡的，无法改变的
- **the inexorable growth of** ……不可阻挡的增长：The inexorable growth of data demands better tools.

## ponder
- /ˈpɑːndər/ · v. 沉思，仔细考虑
- **ponder a question / whether** 思考一个问题 / 是否：He pondered whether to refactor the whole module.

## decently intuitive
- 相当直观的
- **decently intuitive** 相当直观：The API is decently intuitive once you try a few examples.

## collocation
- /ˌkɑːləˈkeɪʃn/ · n. 搭配，词语搭配
- **a common collocation** 常见搭配："Heavy rain" is a common collocation, but "strong rain" is not.

## drawn to sth
- 被某事吸引
- **be drawn to sth.** 被某事吸引：I'm drawn to functional languages for their clarity.

## contingent on
- 视……而定，取决于
- **be contingent on sth.** 取决于某事：Deployment is contingent on passing all tests.

## fractional
- /ˈfrækʃənl/ · adj. 部分的；分数的，小数的
- **fractional gains / precision** 微小的收益 / 精度：The tweak buys only fractional gains in accuracy.

## interplay
- /ˈɪntərpleɪ/ · n. 相互作用，相互影响
- **the interplay between A and B** A 与 B 的相互作用：The paper studies the interplay between data and model size.

## apocryphal
- /əˈpɑːkrɪfl/ · adj. 可疑的，可能是杜撰的
- **an apocryphal story** 可能是杜撰的故事：The story about the bug is probably apocryphal.

## vicarious
- /vaɪˈkeriəs/ · adj. 替代的，间接感受到的
- **vicarious lessons / experience** 间接经验：Reading postmortems gives vicarious lessons from others' failures.

## endow
- /ɪnˈdaʊ/ · v. 赋予，使天生具有
- **be endowed with** 天生具有，被赋予：The model is endowed with strong reasoning abilities.

## adjacent
- /əˈdʒeɪsnt/ · adj. 邻近的，相邻的
- **adjacent to** 与……相邻：The bug lives in the file adjacent to the one you changed.

## adjacent layer
- 相邻层
- **adjacent layer** 相邻层：Each neuron connects to nodes in the adjacent layer.

## long-range dependence
- 长程相关（相隔较远的数据点之间仍存在较强相关性）
- **capture long-range dependence** 捕捉长程相关：Attention helps models capture long-range dependence.

## in hindsight
- 事后看来，后见之明
- **in hindsight** 事后看来：In hindsight, we should have added more tests first.

## hoard
- /hɔːrd/ · v./n. 囤积，储藏
- **hoard data / resources** 囤积数据 / 资源：The app hoards user data it never actually uses.

## regression analysis
- 回归分析（研究变量之间关系的统计方法）
- **run a regression analysis** 做回归分析：We ran a regression analysis on pricing and sales.

## classification
- /ˌklæsɪfɪˈkeɪʃn/ · n. 分类，类别
- **a classification task / model** 分类任务 / 模型：Image classification assigns a label to each picture.

## handicap
- /ˈhændikæp/ · n. 障碍，不利条件 / v. 妨碍
- **a handicap for sb.** 对某人的不利因素：Limited RAM is a handicap for training on this laptop.

## spatial
- /ˈspeɪʃl/ · adj. 空间的
- **spatial features / information** 空间特征 / 信息：ConvNets extract spatial features from images.

## elementwise
- 逐元素的（对每个元素分别执行相同的操作）
- **elementwise multiplication / addition** 逐元素乘法 / 加法：Elementwise multiplication combines two tensors of the same shape.

## downsampling
- n. 下采样（降低分辨率或样本数）
- **downsampling a signal / image** 对信号 / 图像下采样：Downsampling the image cut the input size in half.

## reiterate
- /riˈɪtəreɪt/ · v. 重申
- **reiterate a point / concern** 重申某一点：Let me reiterate the key point before we close.
