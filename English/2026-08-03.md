## repository
- /rɪˈpɑːzətɔːri/ · n. 仓库；代码仓库
- **a code repository** 代码仓库：Push your changes to the remote repository.
- **a repository of knowledge** 知识库：The wiki serves as a repository of project knowledge.

## incognito
- /ˌɪnkɑːɡˈniːtoʊ/ · adj./adv. 隐姓埋名的，匿名的
- **browse incognito** 匿名浏览：He opened an incognito window to search privately.

## init
- /ɪˈnɪt/ · abbr. 初始化（initialization）
- **call init** 调用初始化：The script calls init to set up the data structures.

## a plethora of
- 大量的，过多的
- **a plethora of options** 过多的选项：The config file offers a plethora of options.

## intellisense
- n. 智能感知（编辑器的自动补全提示）
- **IntelliSense suggestions** 智能感知提示：IntelliSense suggests methods as you type.

## kick in
- 开始生效，起作用
- **the effect kicks in** 效果开始显现：The compiler optimizations kick in at higher optimization levels.

## parameter
- /pəˈræmɪtər/ · n. 参数
- **pass a parameter** 传入参数：The function takes two parameters.

## inline
- /ˈɪnlaɪn/ · adj. 内联的
- **an inline function** 内联函数：The compiler inlines small functions to reduce call overhead.

## console
- /ˈkɑːnsoʊl/ · n. 控制台，终端
- **the developer console** 开发者控制台：Errors are logged to the console.

## MCP
- abbr. 主控程序（Master Control Program）
- **the MCP** 主控程序：The MCP coordinates access to shared system resources.

## less error-prone
- 更不易出错的
- **a less error-prone approach** 更不易出错的做法：Immutability makes code less error-prone.
