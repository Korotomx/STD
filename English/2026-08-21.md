## apostrophe
- /əˈpɑːstrəfi/ · n. 撇号，省略号
- **an apostrophe in a string** 字符串里的撇号：Escape the apostrophe in the string literal.

## plurality voting system
- 相对多数制（得票最多者当选的选举制度）
- **a plurality voting system** 相对多数制：In a plurality voting system, the candidate with the most votes wins.

## first-past-the-post
- /ˌfɜːrst ˌpæst ðə ˈpoʊst/ · adj. 最高票者当选的
- **a first-past-the-post election** 简单多数当选的选举：First-past-the-post elections can elect a winner without a majority.

## implement a program
- 实现一个程序
- **implement a program** 实现程序：The assignment is to implement a program that sorts a file.
