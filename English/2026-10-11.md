# 2026-10-11 · 单词（14）

## akin
- /əˈkɪn/ · adj. 类似的，同类的
- **be akin to** 与……相似：A neural net is akin to a stack of simple functions.

## system prompt
- 系统提示词（发给大模型的系统级指令，设定角色与规则）
- **set / write a system prompt** 设置系统提示词：A clear system prompt keeps the model on topic.

## peel back
- 揭开，剥开（表层以显露里面）
- **peel back the layers** 一层层剥开：Peel back the layers and you'll see how it really works.

## lend itself to
- 适用于，适宜于；有助于
- **lend itself to sth.** 适合做某事：The problem lends itself to a recursive solution.

## decision tree
- 决策树（机器学习中按特征逐步分支做分类或回归的模型）
- **train a decision tree** 训练决策树：A decision tree splits data by simple if-else rules.

## deterministic
- /dɪˌtɜːrmɪˈnɪstɪk/ · adj. 确定性的
- **a deterministic algorithm / process** 确定性算法 / 过程：A deterministic algorithm always returns the same output for the same input.

## minimax
- /ˈmɪnəˌmæks/ · n. 极小化极大（博弈中让己方最坏收益最大化、对方收益最小化的策略）
- **the minimax algorithm** 极小化极大算法：Chess engines once relied on the minimax algorithm.

## tried-and-true
- adj. 久经考验的，靠得住的
- **a tried-and-true method / trick** 屡试不爽的方法：Binary search is a tried-and-true technique.

## reprimand
- /ˈreprɪmænd/ · n./v. 训斥，谴责
- **reprimand sb. for sth.** 因某事训斥某人：The manager reprimanded him for skipping the code review.

## mold
- /moʊld/ · n. 模具；类型，风格；霉菌 / v. 塑造
- **break the mold** 打破常规：The new framework breaks the mold of old UI kits.
- **mold sth. into** 把……塑造成：She molded the prototype into a polished product.

## machine learning
- 机器学习（让计算机从数据中学习规律的技术）
- **a machine learning model** 机器学习模型：A machine learning model improves as you feed it more data.

## supervised learning
- 监督学习（用带标签的数据训练模型）
- **a supervised learning task** 监督学习任务：Spam filtering is a classic supervised learning task.

## deep learning
- 深度学习（基于多层神经网络的机器学习分支）
- **a deep learning framework** 深度学习框架：PyTorch is a popular deep learning framework.

## hallucination
- /həˌluːsɪˈneɪʃn/ · n. 幻觉；（大模型）一本正经地编造内容
- **model hallucination** 模型幻觉：Model hallucination makes the chatbot invent fake citations.
