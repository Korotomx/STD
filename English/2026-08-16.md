## hindsight
- /ˈhaɪndsaɪt/ · n. 后见之明
- **in hindsight** 事后看来：In hindsight, we should have tested earlier.
- **with the benefit of hindsight** 事后诸葛亮：With the benefit of hindsight, the bug was obvious.

## deletion
- /dɪˈliːʃn/ · n. 删除
- **the deletion of a file** 删除文件：The deletion of unused code simplified the codebase.

## synopsis
- /sɪˈnɑːpsɪs/ · n. 概要，大纲
- **a synopsis of the paper** 论文概要：The abstract gives a brief synopsis of the paper.

## uncheck
- /ˌʌnˈtʃek/ · vt. 取消勾选
- **uncheck a box** 取消勾选复选框：Uncheck the box to disable automatic updates.

## supercharge
- /ˌsuːpərˈtʃɑːrdʒ/ · vt. 大幅增强，强力提升
- **supercharge productivity** 大幅提升效率：Caching supercharges query performance.

## untapped
- /ˌʌnˈtæpt/ · adj. 未开发的，未利用的
- **untapped potential** 尚未挖掘的潜力：The dataset holds untapped potential for research.

## repo
- /ˈriːpoʊ/ · n. 代码仓库（repository 的简称）
- **clone a repo** 克隆仓库：Clone the repo and run the tests.

## inline blame annotation
- 内联 blame 注解（编辑器里逐行显示提交信息的注释）
- **show inline blame annotations** 显示内联 blame 注解：The editor shows inline blame annotations for each line.

## collide
- /kəˈlaɪd/ · vi. 碰撞，冲突
- **collide with each other** 相互冲突：Two variable names collided in the same scope.

## thus far
- 迄今，到目前为止
- **thus far, ...** 到目前为止：Thus far, the tests have all passed.

## implicit
- /ɪmˈplɪsɪt/ · adj. 含蓄的；隐式的
- **implicit conversion** 隐式转换：The compiler performs an implicit conversion from int to double.
