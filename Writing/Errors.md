## 2026-11-08 · 把代词换成一个没有先行词的模糊名词

- 题目：改写 `Running the process configures permissions and generates a user ID. This lets users authenticate to the app.`
- 当时的想法：把 `This` 换成 `All these methods`，以为换掉代词就没有歧义了。
- 错在哪：前一句里没有 `methods` 这个先行词。代词的问题不是「形式上是代词」，而是「指针能不能唯一解析」；换成一个前文没出现过的模糊名词，指针同样落空。
- 正确落点：[[Google 技术写作#节点 2 · 代词：读者脑内的指针必须唯一可达]]
- 识别信号：想用 `this / these / it / they` 或「这些方法/这些操作」时，先问前一句有没有一个**同名、同数、同类别**的先行词；没有就点名具体对象。
- 自信度：中

## 2026-11-08 · 遇到指代歧义时把决定权推给读者

- 题目：改写 `...because a bug in their core may cause accidental mass unfriending.`
- 当时的想法：写了 `their core (explicitly quote what the core exactly are)`，想请读者或作者再说明 core 指谁。
- 错在哪：改写要把指代定下来，而不是在正文里留下「请说明」的备注。读者不该替作者做这个决定；如果确实不知道，作者要先确认事实，再写进文档。
- 正确落点：[[Google 技术写作#节点 2 · 代词：读者脑内的指针必须唯一可达]]
- 识别信号：改写到一半开始写「这里指谁」「需要说明」时，停下来——那是待办事项，不是文档内容；把待办移出正文，选一个确定的指代。
- 自信度：中
