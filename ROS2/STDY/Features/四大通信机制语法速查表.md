## Topic

```cpp
// 发布端
m_pub = this->create_publisher<std_msgs::msg::String>("chatter", 10);  // 10 = QoS Depth
auto msg = std_msgs::msg::String();
msg.data = "hello";
m_pub->publish(msg);

// 订阅端
m_sub = this->create_subscription<std_msgs::msg::String>(
  "chatter", 10, std::bind(&Listener::cb, this, std::placeholders::_1));

void cb(const std_msgs::msg::String::SharedPtr msg) { ... }   // 或 const Msg &
```

回调也可写 lambda：`[this](const Msg::SharedPtr msg) { ... }`。

QoS：`rclcpp::QoS(10)`、`.reliable()` / `.best_effort()`、`.transient_local()`。

```bash
ros2 topic list -t
ros2 topic info /chatter
ros2 topic echo /chatter --once
ros2 topic pub -r 1 /chatter std_msgs/msg/String 'data: hello'
ros2 topic hz /chatter
```

## Service

```cpp
// 接口 .srv：请求 --- 响应
// 服务端
m_srv = this->create_service<AddTwoInts>(
  "add_two_ints",
  std::bind(&AddServer::cb, this, std::placeholders::_1, std::placeholders::_2));

void cb(const AddTwoInts::Request::SharedPtr req,
        AddTwoInts::Response::SharedPtr res) {
  res->sum = req->a + req->b;      // 返回即自动回复
}

// 客户端
m_client = this->create_client<AddTwoInts>("add_two_ints");
m_client->wait_for_service(1s);
m_client->async_send_request(req,
  [this](rclcpp::Client<AddTwoInts>::SharedFuture f) { f.get()->sum; });
```

main 里一次性调用可用 `rclcpp::spin_until_future_complete(node, future, timeout)`；**回调里绝不能用 `wait_for` / `get()` 阻塞**，会死锁（见 [[ROS2/Errors/Errors]] E004）。

```bash
ros2 service list -t
ros2 service type /add_two_ints
ros2 service call /add_two_ints example_interfaces/srv/AddTwoInts '{a: 3, b: 4}'
```

## Action

```yaml
# .action 硬性三段，两个 ---
float32 duration      # goal
---
bool completed        # result
string message
---
float32 elapsed       # feedback（不用就留空，不能删段）
```

```cpp
// 服务端
m_server = rclcpp_action::create_server<Patrol>(
  this, "patrol",
  handle_goal,       // GoalResponse: ACCEPT_AND_EXECUTE / REJECT
  handle_cancel,     // CancelResponse: ACCEPT / REJECT
  handle_accepted);  // 起线程执行 execute

void handle_accepted(std::shared_ptr<GoalHandlePatrol> gh) {
  std::thread{std::bind(&PatrolServer::execute, this, _1), gh}.detach();
}
// execute 内（ServerGoalHandle 方法，继承）：
// gh->publish_feedback(fb); gh->is_canceling(); gh->canceled(res); gh->succeed(res);

// 客户端
m_client = rclcpp_action::create_client<Patrol>(this, "patrol");
m_client->wait_for_action_server(5s);
auto options = rclcpp_action::Client<Patrol>::SendGoalOptions();
options.feedback_callback = [](auto, std::shared_ptr<const Patrol::Feedback> fb) { ... };
options.result_callback   = [](const auto & r) {
  // r.code: SUCCEEDED / ABORTED / CANCELED；r.result 是结果内容
};
m_client->async_send_goal(goal, options);
```

```bash
ros2 action list
ros2 action info /patrol
ros2 action send_goal /patrol turtle_patrol/action/Patrol '{duration: 10.0}' --feedback
```

## Parameter

```cpp
this->declare_parameter("background_r", 30);              // 默认值定类型
int r = this->get_parameter("background_r").as_int();
this->set_parameter(rclcpp::Parameter("background_r", 255));

// 被改后通知（写入之后触发，读得到新值）
m_cb_handle = this->add_post_set_parameters_callback(
  [this](const std::vector<rclcpp::Parameter> & params) { ... });

// 改别的节点
auto pc = std::make_shared<rclcpp::AsyncParametersClient>(this, "/turtlesim");
pc->set_parameters({rclcpp::Parameter("background_r", 255)},
  [](std::shared_future<...> f) { f.get(); });
```

三种回调时机：`add_pre_set_parameters_callback`（写入前，可改列表）、`add_on_set_parameters_callback`（写入前，可拒绝，读到旧值）、`add_post_set_parameters_callback`（写入后，读新值）。

```bash
ros2 param list /turtle_painter
ros2 param get / set / describe / dump / load
ros2 run <pkg> <node> --ros-args -p background_r:=255
ros2 run <pkg> <node> --ros-args --params-file params.yaml
```

## 通用 main

```cpp
int main(int argc, char ** argv) {
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<Talker>());
  rclcpp::shutdown();
  return 0;
}
```

有订阅 / 服务 / 动作 / 定时器才需要 spin；纯发布可直接调方法，见 [[N009 Executor事件循环]]。多节点 / 多线程用 `MultiThreadedExecutor` + `add_node`。

## CLI 速查

| 目的 | 命令 |
|---|---|
| 节点 | `ros2 node list` / `ros2 node info <节点>` |
| 接口 | `ros2 interface list` / `show <类型>` |
| 包 | `ros2 pkg list` / `prefix <包>` / `executables <包>` |
| 构建 | `colcon build` / `--packages-select <包>` / `--symlink-install` |
| 重映射 | `--ros-args -r /旧:=/新` |
| 诊断 | `ros2 doctor` / `ros2 daemon stop` |

Topic 一对多持续流，Service 一对一一次问答，Action 在其上加 goal/feedback/result，Parameter 是节点内配置；所有异步结果的取法都遵守「回调里 get、不在 executor 线程阻塞」。
