ROS 2 严格分层：`rclcpp/rclpy` 是语言外壳，`rcl` 是核心逻辑，`rmw + DDS` 是通信管道；消息类型独立定义、由 rosidl 生成多语言代码。本篇给出层与库的职责对应。

## 四层

```
你的节点代码 (C++ / Python)
        │
rclcpp / rclpy    客户端库：Node、create_publisher 等语言风格 API
        │
rcl (纯 C)        核心库：图、节点、话题/服务/参数/action、时间、日志
        │
rmw               中间件抽象：隔离具体 DDS
        │
DDS 实现          CycloneDDS / FastDDS / Connext：发现、序列化、传输
```

| 层 | 职责 |
|---|---|
| rclcpp / rclpy | 按语言习惯封装 API，**不实现通信** |
| rcl | ROS 真正核心逻辑，语言无关 |
| rmw | 抽象层，换 DDS 不改上层 |
| DDS | 节点发现、序列化、跨进程/跨机器传输 |

**rclcpp 是外壳，rcl 是大脑，rmw + DDS 是管道。**

消息类型是横向独立的一层：`.msg/.srv/.action` 只写定义，rosidl 生成 C / C++ / Python 多套代码，所以 `std_msgs/msg/String`、自定义消息都能跨语言共用。

数据流：`publish(msg)` → rclcpp → rcl → rmw → CycloneDDS 序列化/发送；对端反向穿过四层触发回调。

## 库与职责

先分两大类：**代码库**（有逻辑、提供功能）和**消息/接口包**（只有定义、无逻辑，经 rosidl 生成类型）。`std_msgs` 属于后者，不是通信库。

**核心通信库**

| 库 | 语言 | 职责 |
|---|---|---|
| rclcpp | C++ | Node、create_publisher、spin 等面向对象 API |
| rclpy | Python | Python 客户端库 |
| rclc | C | 嵌入式精简客户端库 |
| rcl | C | 核心库，语言无关 |
| rmw | C | 中间件接口 |
| rmw_cyclonedds_cpp 等 | C/C++ | 具体 DDS 实现 |
| rcutils | C | 日志宏、分配器、字符串处理 |

**接口生成工具链**：rosidl（解析定义）+ rosidl_generator_c/_cpp/_py（生成类型）+ rosidl_typesupport_*（序列化）。

**常用消息/接口包**

| 包 | 典型消息 |
|---|---|
| builtin_interfaces | Time、Duration |
| std_msgs | String、Int32、Float32、Bool、Header |
| geometry_msgs | Twist、Pose、Point、Quaternion、TransformStamped |
| sensor_msgs | Image、PointCloud2、LaserScan、Imu |
| nav_msgs | Odometry、Path、OccupancyGrid |
| visualization_msgs | Marker、MarkerArray |
| action_msgs | GoalStatus |
| rcl_interfaces | ParameterValue、Log |
| lifecycle_msgs | State |
| turtlesim_msgs | Pose、Color |
| 自定义接口包 | `.srv` / `.action` |

**工具**：ros2cli（`ros2` 命令，背后用 rclpy 查图）、colcon（构建）、ament_cmake/ament_python（包构建系统）。

**常用功能库**：tf2（坐标变换）、rclcpp_action、rclcpp_lifecycle、rclcpp_components、pluginlib/class_loader。

## 坑

- `ros2 node list` / `ros2 topic list` 查的是 rcl 维护的「图」，不是 DDS 原始端点。
- 换 DDS 只改环境变量 `RMW_IMPLEMENTATION`，rclcpp 代码一行不动——这正是 rmw 抽象层的价值。
- 消息包和应用包可能被拆开（如 Lyrical 的 `turtlesim` 与 `turtlesim_msgs`），见 [[ROS2/Errors/Errors]]。

> PS：查包里有什么用 `ros2 pkg list` / `ros2 interface list` / `ros2 interface show`。

四层各司其职——外壳（rclcpp）、大脑（rcl）、抽象（rmw）、管道（DDS）；消息类型独立于分层、由 rosidl 跨语言生成。
