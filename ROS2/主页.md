## 今日学习（2026-10-08）

1. N040 实例 instance 是什么 — 类 = 图纸（编译期类型定义），实例 = 照图纸造出的实物（运行期真实内存 + 自己的数据）；类 → 实例叫实例化；`make_shared<rclcpp::Node>` 就是在实例化
2. N041 栈和堆的底层实现与区别 — 栈：一个寄存器（RSP）移动指针即分配/释放，编译期定大小 + LIFO，快但死板；堆：allocator（malloc/free 空闲链表 + 头记账），运行期任意大小/生命周期，灵活但慢；两者是「速度 vs 灵活性」的权衡
3. N042 同步异步与阻塞非阻塞 — 同步/异步 = 结果「当场给 vs 回头通知」，阻塞/非阻塞 = 等待时线程「挂起 vs 继续跑」，两个正交维度；ROS2 正统姿势是异步非阻塞（回调 + executor），fut.get() 是同步阻塞（主流程用会卡死 executor → 死锁）
4. 深化 N030 future 机制 — 异步为什么总配回调：异步函数一调用就「先 return」（return 值拿不出结果），结果只能换出口、靠回调参数送回；future 就是这条「回头通知」链的凭证
5. 深化 N039 句柄 handle — 补「经典原型」：文件描述符 fd（open 返回 int、read/write/close，看不到内核 FILE）；句柄全谱系（fd / HWND / 裸指针 / shared_ptr / future / GoalHandle）；本质 = 不直接给资源，给「标识 + 操控 + 生命周期」的抽象引用

**统计：2026-10-08 完成 C++ 语法 3 条新增笔记（N040 实例、N041 栈与堆、N042 同步异步与阻塞非阻塞）+ 2 条深化（N030 future 机制、N039 句柄）。**
