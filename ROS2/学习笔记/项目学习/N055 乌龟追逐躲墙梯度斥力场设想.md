# 乌龟追逐躲墙·墙边梯度斥力场（设想） · 项目学习 · N055

**时间:** 2026-10-15
**标签:** #项目学习 #turtlesim #架构Architecture #数学Math #几何
**关联:** [[N049 双龟追逐进阶任务参考与伪代码]] [[N052 双龟追逐三节点Action实现]] [[N021 控制海龟运动]] [[N053 角度归一化atan2-sin-cos]]

## 背景

进阶任务三节点 Action 闭环（[[N052]]）已跑通，但「乌龟碰墙不能贴墙/卡住」这步没做。本文**不落地到项目**，只记录一种设想的实现方案：给 B 龟所在空间叠加一个**墙边梯度斥力场（向量场）**，让 B 靠近墙时被自动、平滑地推开。

## 问题拆解：B 和 A 难度不对称

- **B（runner）无目标**，随机游走——躲墙 = 缩小随机朝向的范围，简单。
- **A（chaser）有目标**（追 B）——躲墙与「追 B」两股力打架，难。
- **关键简化：只抓 B、不抓 A。** B 远离墙 → A 追 B 的轨迹也远离墙，A 一行都不用改。整个「撞墙」问题因此被收敛成「给 B 加一个斥力场」。

## 感知约束

turtlesim 没有传感器，每只龟唯一能拿到的是自己的 `/pose`（x, y, theta）。所以**任何规避都只能靠「读 pose + 判断离墙距离」**。画布约 11×11（坐标 0～11，中心约 5.5），龟有半径，判断时要往里收一段 margin。

## 斥力场构造（一维 → 二维递进）

**1. 一维斥力（单面墙）**：左墙在 x=0，龟在墙右边，斥力指向 +x（背离墙），离墙越近越强：

```
F(d) = k · (d0 − d)   （线性衰减，d ∈ [0, d0]）
或     k · (d0 − d)²  （平方衰减，更柔）
```

- `d` = 离墙距离；`d0` = 作用半径（超过 d0 斥力为 0）；`k` = 斥力强度。
- d=0（贴墙）时最大 k·d0，d=d0 时刚好归零，d>d0 完全不介入。

**2. 二维合成（四堵墙）**：每堵墙各给一个「指向墙内」的斥力，按坐标分量叠加：

```
左墙 x=0    →  +x 方向 F(x)
右墙 x=11   →  −x 方向 F(11 − x)
下墙 y=0    →  +y 方向 F(y)
上墙 y=11   →  −y 方向 F(11 − y)

总斥力 F_wall = 四个分量按 (x, y) 求和
```

**3. 墙角不用单独处理**：在角落，两面墙的斥力合成指向对角（约 45°），天然把 B 斜着推出去。这正是斥力场相对「半平面采样」（[[N049]] 差距表里的原方案）更省事的地方——半平面要靠墙时单独 if 处理墙角，势场法天生就处理了。

## 叠加到运动

B 现在每周期抽一个随机角速度 `ω_rand`。改成「随机项 + 斥力项」合成，把斥力方向当作「转向目标」：

```
ω = ω_rand + K_wall · angle_diff( F_wall 的方向 , 当前朝向 )
```

- 这跟 [[N052]] 追击的「角度差比例控制」是同一个式子，只是「目标」从 B 的位置换成了斥力方向；角度差用 [[N053]] 归一化。
- 斥力只在 margin 带内非零，所以远离墙时 `F_wall = 0`，退化为纯随机游走，行为不变。

## 为什么对 B 无「平衡点」（关键）

势场法最被诟病的坑是「引力 + 斥力在某处平衡 → 卡住」。但 **B 只有斥力、没有引力**：它的「引力」是随机游走项，随机项永远在扰动，不可能和斥力形成稳定平衡。所以 B 用斥力场**不会卡死**——这是它区别于 A 的核心原因（A 若也用势场，追 B 的引力和墙斥力才可能平衡）。

## kill+spawn 的定位：兜底，不是主规避

- 主规避靠斥力场；`kill`+`spawn` 只做「贴墙超时」的最后保险。
- 不拿它当主方案的两个原因：
  1. 它只解决「结局」不解决「过程」——B 随机游走撞墙是高频事件，每次都 kill/spawn 会变成频繁瞬移，观感比撞墙还怪；
  2. 检测「卡住」一样要读 pose + 判断贴墙，前置成本 ≈ 做规避的成本，没省到难的那部分。

## 待定参数

- `d0` 作用半径、`k` 斥力强度、`K_wall` 转向增益。
- 需实测：太小 B 仍贴墙；太大 B 不敢靠近墙，会显得「贴着内圈跑」。直观上 `d0` 取「乌龟半径 + 一点余量」的量级。

## 总结

「撞墙」被收敛成「给 B 加一个墙边斥力场」的小改动：B 远离墙 → A 追 B 的轨迹自然也远离墙，A 不用动。斥力场对 B 无平衡点（只有斥力、无引力）、墙角天然合成对角线斥力，比「半平面采样」更平滑、更省 if，代价只是定 `d0`/`k` 两个参数。
