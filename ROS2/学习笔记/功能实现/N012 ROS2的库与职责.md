# ROS2 的库与职责 · 功能实现 · N012

**时间:** 2026-10-04 17:19
**标签:** #功能实现 #架构Architecture #库 #消息类型 #工具
**关联:** [[N011 ROS2分层架构]] · [[N010 订阅者与回调参数]]

## 疑惑点

ROS2 下有哪些库？比如 rcl、std_msgs，还有呢？各自负责什么功能？

## 实际情况

先区分两大类：**代码库**(有 C++/C/Python 逻辑，提供功能) vs **消息/接口包**(只有 `.msg/.srv/.action` 定义，无逻辑，经 rosidl 生成类型代码)。`std_msgs` 属于后者，不是通信库。

**① 核心通信库（上层 → 底层）：**

| 库 | 语言 | 职责 |
|----|------|------|
| rclcpp | C++ | 客户端库：Node、create_publisher、spin 等面向对象 API |
| rclpy | Python | Python 版客户端库 |
| rclc | C | 嵌入式精简客户端库 |
| rcl | C | 核心库，语言无关；节点/图/话题/服务/参数/action 逻辑 |
| rmw | C | 中间件接口，隔离具体 DDS |
| rmw_cyclonedds_cpp / rmw_fastrtps_cpp / rmw_connextdds_cpp | C/C++ | 具体 DDS 实现 |
| rcutils | C | 底层工具：日志宏、分配器、字符串处理 |

**② 接口生成工具链（rosidl 家族）：** rosidl(解析定义) + rosidl_generator_c/_cpp/_py(生成各语言类型) + rosidl_typesupport_*(序列化)。

**③ 消息/接口包（只有定义）：**

| 包 | 典型消息 |
|----|---------|
| builtin_interfaces | Time、Duration |
| std_msgs | String、Int32、Float32、Bool、Header |
| geometry_msgs | Twist、Pose、Point、Quaternion、TransformStamped |
| sensor_msgs | Image、PointCloud2、LaserScan、Imu |
| nav_msgs | Odometry、Path、OccupancyGrid |
| visualization_msgs | Marker、MarkerArray |
| action_msgs | GoalStatus |
| rcl_interfaces | ParameterValue、Log |
| lifecycle_msgs | State |
| turtlesim_msgs | Pose、Color |
| turtle_demo_interfaces(自定义) | TeleportTurtle.srv、PatrolTurtle.action |

**④ 工具：** ros2cli(ros2 命令行，背后用 rclpy 查图)、colcon(构建)、ament_cmake/ament_python(包构建系统)。

**⑤ 常用功能库：** tf2(坐标变换)、rclcpp_action(action)、rclcpp_lifecycle(生命周期)、rclcpp_components(组件化)、pluginlib/class_loader(插件)。

> **Note（连接 / 深化）：**
> - 连接：这四层的关系见 [[N011 ROS2分层架构]]；`std_msgs` 的 `String` 用法见 [[N010 订阅者与回调参数]]。
> - 深化：`ros2 pkg list` 能看装了哪些包；`ros2 interface list` 看有哪些消息/服务/动作类型；`ros2 interface show std_msgs/msg/String` 看定义内容。

## 总结

**本质：** ROS2 的包分「代码库」和「消息/接口包」两类；前者提供通信/工具/功能，后者只定义消息格式、由 rosidl 生成跨语言类型。日常写代码接触最多的是 rclcpp + 各类消息包。
