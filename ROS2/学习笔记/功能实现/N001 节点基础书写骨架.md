一个 rclcpp 节点 = 继承 `rclcpp::Node` 的类；构造函数里用 `create_*` 建通信件并保存成成员，`main` 里 `init → spin → shutdown` 驱动。本篇从骨架讲到发布/订阅，再落到 geometry_msgs 与海龟控制。

## 节点七部分骨架

```cpp
#include "rclcpp/rclcpp.hpp"
#include "std_msgs/msg/string.hpp"

class Talker : public rclcpp::Node {                      // ② 继承 Node
public:
  Talker() : Node("talker") {                             // ③ 构造函数 + 节点名
    m_pub = this->create_publisher<std_msgs::msg::String>("topic", 10);   // ④
    m_timer = this->create_wall_timer(1s, std::bind(&Talker::timer_cb, this));
  }
private:
  void timer_cb() {                                       // ⑤ 回调
    std_msgs::msg::String msg;
    msg.data = "hello";
    m_pub->publish(msg);
  }
  rclcpp::Publisher<std_msgs::msg::String>::SharedPtr m_pub;   // ⑥ 成员
  rclcpp::TimerBase::SharedPtr m_timer;
};

int main(int argc, char ** argv) {                        // ⑦ main 四步
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<Talker>());
  rclcpp::shutdown();
  return 0;
}
```

要点：

- **节点名 ≠ 类名**：`Node("talker")` 是运行时注册名，`Talker` 只是 C++ 类名。
- **回调从不手动调**：框架在事件发生时调用（定时器到期、消息到达）。
- **通信件必须是成员**：回调要用，生命周期得和节点一样长；局部变量在构造函数结束就销毁。
- **没有 spin 节点立刻退出**：`spin` 是进入事件循环、阻塞到 Ctrl+C 的关键。

## 订阅端与回调参数

订阅端和发布端是同一套骨架，差别只有通信件：`create_subscription` 替代 publisher + timer，且回调要接收消息。

```cpp
using std::placeholders::_1;

class Listener : public rclcpp::Node {
public:
  Listener() : Node("listener") {
    m_sub = this->create_subscription<std_msgs::msg::String>(
      "topic", 10, std::bind(&Listener::topic_cb, this, _1));
  }
private:
  void topic_cb(const std_msgs::msg::String & msg) const {
    RCLCPP_INFO(this->get_logger(), "I heard: '%s'", msg.data.c_str());
  }
  rclcpp::Subscription<std_msgs::msg::String>::SharedPtr m_sub;
};
```

- `create_subscription` 三参数：话题名、队列深度、callable。话题名靠字符串对上，双方互不知道对方。
- `_1` 是占位符，表示「callable 的第 1 个参数」，框架收到消息时把消息填进去。**`_1` 的个数 = 回调需要框架传入的参数个数**；timer 回调无参，所以 `bind(..., this)` 不带 `_1`。
- 回调形参 `const Msg &`：不拷贝消息、也不修改它；函数末尾 `const` 表示不改 `this` 的成员。
- 另一种常见写法是 `const Msg::SharedPtr msg`（共享指针），见 [[四大通信机制语法速查表]]。

## geometry_msgs：几何消息包

`geometry_msgs` 是几何量的标准消息包（32 个消息），按用途分六类：

| 类别 | 消息 | 用途 |
|---|---|---|
| 基础积木 | `Point` / `Vector3` / `Quaternion` / `Point32` | 点 / 向量 / 四元数 |
| 位姿 | `Pose` / `PoseStamped` / `PoseArray` / `PoseWithCovariance` | 位置 + 朝向 |
| 运动 | `Twist` / `TwistStamped` / `Accel` / `Wrench` | 速度 / 加速度 / 力 |
| 变换 | `Transform` / `TransformStamped` | 坐标系变换（tf 用） |
| 形状 | `Polygon` / `PolygonStamped` | 多边形区域 |
| 惯性 | `Inertia` | 惯性张量 |

命名规律比逐个记更重要：

- **裸类型** `Pose` / `Twist` / `Point`：纯几何量。
- **`Stamped` 后缀** = 加了 `Header`（时间戳 + `frame_id`），即「挂在某个坐标系下」；tf / 导航最常用。
- **`WithCovariance` 后缀** = 加了协方差矩阵，表示不确定性。

`Twist` 是 `Vector3 linear + Vector3 angular`；2D 差速轮/海龟只用 `linear.x` 与 `angular.z`。`Pose` 是 `Point position + Quaternion orientation`，用四元数而非欧拉角是为了避开万向锁；2D 绕 z 转 θ 时 `z = sin(θ/2), w = cos(θ/2)`。

易混：`turtlesim_msgs/msg/Pose` 是 `x, y, theta` 的 2D 简化版，和 `geometry_msgs/msg/Pose` 是**不同类型**。

## 用 Twist / Pose 控制海龟

turtlesim 的海龟是「哑」的：发 `/turtleX/cmd_vel`（`Twist`）驱动，订阅 `/turtleX/pose` 获知状态。

```cpp
geometry_msgs::msg::Twist msg;
msg.linear.x  = 1.0;   // 前进
msg.angular.z = 2.0;   // 左转，rad/s
```

命令是**体坐标系**下的：`linear.x` 沿海龟自身正前方，不是世界 x 轴。

| linear.x | angular.z | 运动 |
|---|---|---|
| 1.0 | 0 | 直线前进 |
| 0 | 1.0 | 原地转圈 |
| 1.0 | 1.0 | 画弧，半径 r = v/ω |

符号：`linear.x` 正前进负后退；`angular.z` 正逆时针（左转）、负顺时针（右转）。cmd_vel 是**持续命令流**，发一次 `linear.x=1` 就一直走，要停须再发 0；`cmd_vel`（意图）与 `pose`（现实）构成「读状态 → 算命令 → 发命令」的闭环。

随机游走 = 固定线速度 + 随机角速度：

```cpp
std::mt19937 m_gen{std::random_device{}()};                    // 真随机播种
std::uniform_real_distribution<double> m_dist{-2.0, 2.0};

msg.linear.x  = 1.0;
msg.angular.z = m_dist(m_gen);    // 每 500ms 一拍
```

`mt19937` 是同种子同序列的伪随机，必须用 `random_device` 播种，否则每次路径一样。

追击 = 朝目标转向（比例控制）：

```cpp
constexpr double kAngular = 1.5;
constexpr double kCatch   = 0.5;

double dx = target_x - m_x, dy = target_y - m_y;
double distance = std::sqrt(dx*dx + dy*dy);
double angle_to_target = std::atan2(dy, dx);
double angle_diff = angle_to_target - m_theta;
// 角度差须归一化到 [-π, π]，否则会转大圈，见 [[N053 角度归一化atan2-sin-cos]]

if (distance < kCatch) { msg.linear.x = 0; msg.angular.z = 0; }
else { msg.linear.x = 1.0; msg.angular.z = kAngular * angle_diff; }
```

转向速度 ∝ 角度差：差越大转得越猛。未归一化时实测出现过 `angular.z = 14.87`。

## 坑

- 话题名有一字之差就收不到，且不会报错。
- 队列深度 `10` 只是 QoS 的一个维度，见 [[N002 QoS队列深度10]]。
- `pose` 是持续广播的状态流，不要当一次性查询用；要「问一次」用 Service，见 [[N017 Service概念与srv接口]]。

> PS：工程上常把参数从构造函数注入（`Talker(rclcpp::NodeOptions)`），通信件统一 `m_` 前缀；固定速度写 `constexpr`，不写成参数。

节点骨架固定七部分，发布/订阅只换通信件，`_1` 负责把框架传入的消息接到回调；`Twist` 管运动、`Pose` 管状态，二者构成海龟控制的闭环。
