# 参数的声明、读写与命令行工具 · 功能实现 · N025

**时间:** 2026-10-06 19:50
**标签:** #功能实现 #Parameter参数 #命令行CLI
**关联:** [[N024 参数概念与四大通信机制全景]] [[N001 节点基础书写骨架]]

## 疑惑点

参数怎么声明、怎么读、怎么改？`ros2 param` 命令怎么用？

## 实际情况

1. **声明 `declare_parameter`**（在构造函数里，先「报名」再使用）：

   ```cpp
   this->declare_parameter("background_r", 30);   // 参数名 + 默认值
   ```

   - 参数必须先声明才能 `get`，否则抛 `ParameterNotDeclaredException`；
   - **默认值同时定下类型**：`30` → 整数类型（内部用 variant 存，运行时才知道类型）；
   - 重复声明同名参数会抛 `ParameterAlreadyDeclaredException`。

2. **读 `get_parameter`**：

   ```cpp
   int r = this->get_parameter("background_r").as_int();  // 先拿 Parameter 对象，再 .as_xxx() 转类型
   ```

   - `get_parameter` 返回 `rclcpp::Parameter` 对象，要用 `.as_int() / .as_double() / .as_string() / .as_bool()` 转成具体类型；
   - 类型对不上会抛异常。

3. **写 `set_parameter`**（改自己）：

   ```cpp
   this->set_parameter(rclcpp::Parameter("background_r", 255));
   ```

   - 自己改自己；或由外部 `ros2 param set` 改（走参数服务，见 [[N024 参数概念与四大通信机制全景]]）。

4. **命令行工具**（以 `turtle_painter` 为例）：

   ```bash
   ros2 param list /turtle_painter                          # 列出有哪些参数
   ros2 param get  /turtle_painter background_r             # 读
   ros2 param set  /turtle_painter background_r 255         # 写（触发参数回调）
   ros2 param describe /turtle_painter background_r         # 看类型 / 描述
   ros2 param dump /turtle_painter > p.yaml                 # 导出配置
   ros2 param load /turtle_painter p.yaml                   # 从文件加载
   ```

5. **实战对照 `turtle_painter`**：本节点声明 `background_r/g/b` 三个参数（默认 `30 / 144 / 255` 蓝色），运行中敲 `ros2 param set /turtle_painter background_r 255` 就能改背景色。

> **Note（连接 / 深化）：**
> - 连接：参数「被外部改」会触发回调，见下一条笔记（`add_on_set_parameters_callback`）；改**别的节点**的参数用参数客户端，见 `turtle_painter` 拆解；`dump`/`load` 导出的就是 YAML 文件，见 [[N033 YAML参数文件与配置分离]]。
> - 深化：`declare_parameter` 的默认值「顺便」定类型——参数是**运行时**才知道类型的，这点和 C++ 编译期定型的普通变量很不一样。

## 总结

**本质：** 参数三步走——`declare` 声明（默认值定类型）、`get` 读（`.as_xxx` 转类型）、`set` 写（自己或经参数服务）；命令行 `ros2 param list / get / set / describe / dump / load` 对应同一套机制。
