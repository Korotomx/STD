## 疑惑点

turtlesim 里的海龟是怎么被「驱动」的？随机游走、追击是怎么实现的？

## 实际情况

### 1. 海龟怎么动 —— 发 `cmd_vel`（Twist）

turtlesim 的海龟是「哑」的，靠外部**发布速度**驱动。消息类型 `geometry_msgs/msg/Twist` 有两个字段：

```cpp
geometry_msgs::msg::Twist msg;
msg.linear.x  = 1.0;   // 线速度（前进）
msg.angular.z = 2.0;   // 角速度（转向，rad/s）
```

- `linear` 是线速度、`angular` 是角速度，各含 x/y/z 三个轴。
- 海龟是 **2D** 的，只用 `linear.x`（前进/后退）和 `angular.z`（左右转）。
- 发布到 `/turtleX/cmd_vel`，turtlesim 持续监听并驱动对应海龟。

### 2. 海龟在哪 —— 订阅 `pose`（Pose）

turtlesim 会**持续广播**每只海龟的位置 `/turtleX/pose`，类型 `turtlesim_msgs/msg/Pose`：

```
float32 x, y, theta          # 位置坐标 + 朝向（弧度）
float32 linear_velocity, angular_velocity
```

订阅它就能「记住自己在哪」——追击几何全靠它。

### 3. 深化：cmd 运动框架的四个关键点

1. **体坐标系（不是世界坐标系）**：`linear.x` 是「沿海龟自己正前方」的速度，不是世界坐标系的 x 轴方向。同一条 `linear.x=1`，海龟朝东就走东、朝北就走北——命令是相对机器人自身（body frame）的，`angular.z` 同理（绕自身竖直轴转，和它在画布哪无关）。

2. **正负号 → 方向**：

   | 字段 | 正 | 负 |
   | ---- | ---- | ---- |
   | `linear.x` | 前进 | 后退 |
   | `angular.z` | 逆时针（左转） | 顺时针（右转） |

3. **linear.x + angular.z → 三种基本运动**：

   | linear.x | angular.z | 运动 |
   | ---- | ---- | ---- |
   | 1.0 | 0 | 直线前进 |
   | 0 | 1.0 | 原地转圈 |
   | 1.0 | 1.0 | 画弧（曲率半径 r = v / ω） |

4. **命令流 + 状态流 = 控制闭环**：`cmd_vel`（命令 = 我要你怎么动）和 `pose`（状态 = 你实际在哪）是一对——命令是意图、状态是现实，控制 = 读状态 → 算命令 → 发命令。且 cmd_vel 是「持续命令流」不是一次性指令：发一次 `linear.x=1` 海龟一直走，要停得再发 `linear.x=0`。

### 4. 随机游走 —— 固定线速度 + 随机角速度

用 `<random>` 库，两个部件分开：

```cpp
std::mt19937 gen_;                                     // 引擎（梅森旋转）
std::uniform_real_distribution<double> dist_{-2.0, 2.0}; // 分布（[-2,2] 均匀）
// 构造函数里播种：gen_(std::random_device{}())
```

每 500ms：

```cpp
msg.linear.x  = 1.0;          // 一直前进
msg.angular.z = dist_(gen_);  // 随机转向 [-2, 2]
```

**效果**：一直前进 + 周期随机转向 = 不规则的「随机游走」轨迹。
**关键**：`mt19937` 是伪随机（同种子同序列），必须用 `std::random_device{}()`（真随机）播种，否则每次路径一样。

### 5. 追击几何 —— 朝目标转向

```cpp
double dx = target_x - self_x_;                  // 横向差
double dy = target_y - self_y_;                  // 纵向差
double distance = std::sqrt(dx*dx + dy*dy);      // 直线距离
double angle_to_target = std::atan2(dy, dx);     // 目标方向角
double angle_diff = angle_to_target - self_theta_; // 需转向的角度

if (distance < 0.5) { 线速度=0, 角速度=0; }        // 到了，停
else { 线速度=1.0; 角速度 = 4.0 * angle_diff; }    // 前进 + 比例转向
```

- `atan2(dy, dx)` 求「目标在我的哪个方向」，减 `self_theta_` 得「该转多少」。
- 转向速度 ∝ 角度差（比例控制），差越大转得越猛。

> **Note（连接 / 深化）：**
> - 连接：`cmd_vel` / `pose` 是 Topic 持续流，`get_target_pose` 是 Service 查询，两者并存见 [[N020 turtle_chase小海龟追击项目架构与代码拆解]]。
> - 深化：`angle_diff` 没归一化到 [-π, π] 时，转向会过猛（实测 `angular.z = 14.87`）；后续可把角度差规整到 [-π, π] 优化。

## 总结

**本质：** 控制海龟运动 = 发 `Twist`（线速度 + 角速度）到 `cmd_vel`；随机游走 = 固定线速度 + `<random>` 随机角速度；追击 = 订阅 `pose` 算距离/方向角，按角度差比例转向。注意 Twist 是**体坐标系**下的速度（相对海龟自身），cmd_vel（命令）与 pose（状态）组成「读状态→算命令→发命令」的控制闭环。
