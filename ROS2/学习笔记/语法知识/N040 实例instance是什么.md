# 实例 instance 是什么 · 语法知识 · N040

**时间:** 2026-10-08 21:11
**标签:** #语法知识 #C++语法 #类Class #对象Object #实例Instance
**关联:** [[N001 节点基础书写骨架]] [[N039 句柄handle是什么]] [[N041 栈和堆的底层实现与区别]]

## 疑惑点

代码里总说「创建实例」「实例化」，实例到底是什么东西？它和「类」「变量」是什么关系？

## 实际情况

1. **一句话：类（class）是「图纸」，实例（instance）是照着图纸造出来的「实物」。** 类是类型定义，描述「这类东西有哪些数据成员 + 能做什么操作」；实例是用这个类造出来的一个具体对象，占一块真实内存，里面有它自己的数据。

2. **类 vs 实例的区别：编译期 vs 运行期。**
   - 类在**编译期**决定「这种对象在内存里长什么样」（哪些字段、什么布局）和「有哪些操作」，但类本身（除 static 成员）**不占运行期数据内存**——像图纸不占车间的地。
   - 实例是**运行期**真正分配出来的一块内存，装着这个对象自己的数据。

   ```cpp
   class Turtle {          // 类 = 图纸
     double x = 0, y = 0;  // 数据成员：海龟的位置
     void move(double dx, double dy) { x += dx; y += dy; }  // 方法：能移动
   };

   Turtle t1;   // t1 是实例 1：一块独立内存，装着 t1 自己的 x、y
   Turtle t2;   // t2 是实例 2：另一块独立内存，装着 t2 自己的 x、y
   t1.move(1, 0);  // 只改 t1 的 x,y，和 t2 无关
   ```

3. **类 → 实例的过程叫「实例化（instantiation）」**，你早就在做：

   ```cpp
   auto node = std::make_shared<rclcpp::Node>("my_node");
   //           └──────── 实例化一个 Node 对象 ────────┘
   ```
   `rclcpp::Node` 是类，`make_shared` 造出来的那个就是 Node 实例。

4. **「实例」和「变量」的关系**：一个类型是类的变量，它就是实例（或实例的引用/指针）。基本类型（int、double）的变量严格说也符合「对象」的宽泛定义，但口语里「实例」专指「类的对象」。

> **Note（连接 / 深化）：**
> - 连接：`make_shared` 造实例见 [[N001 节点基础书写骨架]]；实例（对象）在内存里放栈还是堆见 [[N041 栈和堆的底层实现与区别]]。
> - 深化：实例的本质就是「一块按类定义排布好的内存 + 一组能操作它的方法」。类决定内存布局（sizeof 大小），实例是这份布局的一个具体落点。

## 总结

**本质：** 类 = 图纸（编译期类型定义，决定内存布局与操作），实例 = 照图纸造出的实物（运行期一块真实内存，装着这个对象自己的数据）；类 → 实例叫实例化。
