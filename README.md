- **AI 理论**：MIT 6.S191 为主线——深度学习基础、CNN、RNN/Transformer、生成模型、强化学习、大规模训练。
- **AI 工程**：CUDA / TensorRT 部署实践，从 kernel 到 ONNX → engine 的完整链路。
- **ROS 2**：机器人通信、节点组织与工程结构；课程项目已完结，按需复习。
- **Python**：补齐 C 之外的 Python 特性与 NumPy。
- **英语**：积累 CS 词汇，按天归档。
- **技术写作**：Google Technical Writing One/Two，练 README、设计文档、错误信息与代码注释。
- **阅读**：Sight 收技术文章与长文，保留原文出处。

## 怎么组织

- 每个科目一个目录：`Overview` 是入口，`STDY` 放学习笔记，`Ref` / `Captures` 放原始材料。
- 原始材料只读：不移动、不改正文。
- `Scripts/check_updates.py` 检查各科 Ref/Capture 是否有未处理或过期材料；每天 09:07 自动运行并提醒。
- 本 README 只描述方向和目标，不记录每日进度。
