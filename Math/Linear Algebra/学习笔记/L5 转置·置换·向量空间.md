# 转置·置换·向量空间 Transposes, Permutations, Spaces Rⁿ · 18.06 L5

**时间:** 2026-10-20
**标签:** #线性代数LinearAlgebra #转置Transpose #对称矩阵SymmetricMatrix #置换Permutation #向量空间VectorSpace #子空间Subspace #列空间ColumnSpace
**关联:** [[L4 A=LU 分解]]（置换矩阵）· [[L1 线性方程的几何]]（列组合 → 列空间）

## 必要性（为什么要有这一章）

**要解决的问题**:前半程(消元、LU)都在算,但线性代数的**「大图景」还没展开**——不再只看单个向量,而是看**向量的空间、空间的子空间**。这是「真正线性代数」的开始。

**意义(重点)**:这一讲完成两件事:
1. 收尾两个工具(置换 P、转置 $A^T$)和一族好矩阵(对称矩阵);
2. 开启**向量空间**的视角——尤其是从矩阵「造」出第一个核心子空间:**列空间 C(A)**。L1 埋下的「列的组合」种子,在这里长成正式概念。

## 主要内容

### 1. 置换矩阵(收尾)

- n×n 置换矩阵共 **n!** 个(3×3 六个、4×4 二十四个);每行每列恰一个 1,是 I 的行重排。
- **核心性质:$P^{-1}=P^T$**(即 $P^TP=I$,逆 = 转置)。原因是「把行换回去」正是「转置」。
- 置换矩阵的乘积、逆都仍是置换矩阵——它们构成一个**群**。$PA=LU$ 里 P 负责「先摆好行顺序」。

### 2. 转置与对称矩阵

- **转置**:$(A^T)_{ji}=a_{ij}$,沿主对角线翻转,行列互换。法则(与逆同款「反序」):$(AB)^T=B^TA^T$,以及 $(A^T)^T=A$、$(A+B)^T=A^T+B^T$、$(kA)^T=kA^T$。
- **对称矩阵**:$A^T=A$(翻转后还是自己)。实际中大量出现(协方差、Hessian、图拉普拉斯)。
- **关键事实:$R^TR$ 永远对称**。证:$(R^TR)^T=R^T(R^T)^T=R^TR$(两次转置回到 R,反序一换又变回 $R^TR$)。这是对称矩阵**最自然的来源**——任何矩阵乘自己的转置都对称。
  - 例:$R=\begin{bmatrix}1&3\\2&3\\4&1\end{bmatrix}$,$R^TR=\begin{bmatrix}10&11&7\\11&...&...\end{bmatrix}$ 对称。

### 3. 向量空间(vector space)

- **向量空间 = 一组向量 + 两种运算(加法、数乘),且对这两种运算「封闭」**:
  - 加任意两个仍在空间里;
  - 乘任意数(包括 0、负数)仍在空间里。
- **R²、R³、…、Rⁿ**:所有 n 分量**实数列向量**的全体,是本课最大的例子。R² = 整个 xy 平面。
- 两条必须的运算:$v+w$、$cv$;从而**任何线性组合也在空间里**。
- **零向量必须在里面**:因为要允许乘 0,结果 0 必须还在空间里——所以「挖掉原点的平面」不是向量空间。
- 严格的 8 条公理(结合、交换、分配等)通常不费事,**真正要检查的是「封闭性」**。

### 4. 子空间(subspace)

- **子空间 = 某个向量空间里、自身也构成向量空间的一个子集**(仍封闭)。
- **必须包含零向量**。
- **R² 的子空间只有三类**:① 整个 R²;② 过原点的**直线**;③ 只有零向量 $\{0\}$(最小的子空间 Z)。
- **R³ 的子空间**:① 整个 R³;② 过原点的**平面**;③ 过原点的**直线**;④ 零向量。
- **反例**:第一象限(分量非负)加法封闭、但乘 -1 就出去了 → **不封闭 → 不是子空间**。

### 5. 从矩阵造子空间:列空间 C(A)

- 给一个矩阵 A,把它的列(在 Rⁿ 里的向量)**所有线性组合**收集起来,就是一个子空间——**列空间 column space**,记 **C(A)**。
- 例:$A=\begin{bmatrix}1&3\\2&3\\4&1\end{bmatrix}$ 的两列在 R³ 里,它们的组合**填满一张过原点的平面**——那就是 C(A)。
- **几何**:两列不共线 → 组合填一张平面;若两列共线 → C(A) 只是一条线。
- **C(A) 与 L1 打通**:$Ax=b$ 有解 ⟺ **b 在 C(A) 里**。于是「对每个 b 是否有解」= 「C(A) 是否等于整个 Rⁿ」——L1 的母问题在这里有了正式答案。

## 直观理解（空间视角）

- **转置 = 沿主对角线镜像翻转**;对称矩阵 = 翻完还是自己($A=A^T$)。$R^TR$ 对称,本质是「转置反序 + 两次转置抵消」。
- **向量空间 = 「能自由组合的集合」**:空间不是「一堆向量」,而是「这堆向量能加、能缩放、结果还不出去」。挖掉原点会「漏」(乘 0 掉出去),所以必须含 0。
- **子空间 = 空间里「自身封闭」的一块**:R² 里过原点的直线是子空间(加还在线上、缩放还在线上),不过原点的直线不是(乘 0 掉到原点外)。
- **列空间 = 列的「可到达区域」**:把 A 的列看成几枝箭,所有缩放+相加能到达的地方,就是 C(A)。两列不共线 → 一张平面;共线 → 一条线。$Ax=b$ 可解 = b 落在这个「可到达区域」里。
- **从「单个向量」升级到「空间」**:L1 问「某一组组合能不能到 b」,L5 问「所有组合能到哪」——后者(空间)才是线性代数的正式语言。

## 拓展延伸（与 AI / 计算机的关联）

- **列空间 = 数据「张成」的空间**:设计矩阵 X 的列空间决定模型能拟合什么;若目标 y 不在 C(X) 里,最小二乘就用 y 在 C(X) 上的**投影**逼近(下一单元正交投影/最小二乘)。这是线性回归的几何本质。
- **$R^TR$ 对称 → 正规方程 / 协方差矩阵**:最小二乘的正规方程 $X^TX\beta=X^Ty$ 里 $X^TX$ 就是对称矩阵;协方差矩阵 $\frac1n X^TX$ 对称正定,是 PCA(主成分分析)的输入——**「矩阵乘自己转置」是数据科学最高频的运算之一**。
- **子空间 / 张成(span)是表示学习的地基**:PCA 找数据张成的低维子空间、word embedding 的线性子空间、信号处理里的信号子空间,本质都是「某个列空间 / 子空间」。
- **置换矩阵 = 排序 / 打乱的数学**:深度学习里 shuffle、注意力里位置编码的置换不变量、组合优化里的「重排」,都对应置换矩阵(以及更一般的正交矩阵 $Q^TQ=I$,下一单元)。

## Note（连接 / 深化）

- **连接**:列空间 C(A) 是「四个基本子空间」的第一个,后面的零空间、行空间、左零空间将与之配套([[向量空间]] 后续讲次);对称矩阵的优良性质(实特征值、可正交对角化)是特征值章的主菜,也是 PCA/谱聚类的根基。
- **深化**:$P^{-1}=P^T$ 预示了更一般的**正交矩阵** $Q^{-1}=Q^T$(下单元正交性);$R^TR$ 对称预示了**对称正定**矩阵(特征值全正)——这两条线索都指向后面的大主题。

## 总结

### 本讲新引入的专业术语

| 英文术语 | 中文 | 含义 |
| -------- | ---- | ---- |
| transpose | 转置 | $A^T$,行列互换,沿对角线翻转 |
| symmetric matrix | 对称矩阵 | $A^T=A$ |
| permutation matrix | 置换矩阵 | 换行矩阵,P⁻¹=Pᵀ,共 n! 个 |
| vector space | 向量空间 | 对加法、数乘封闭的向量集合 |
| closed under | 封闭 | 运算结果不跑出集合 |
| scalar multiplication | 数乘 | 向量乘一个数 |
| subspace | 子空间 | 空间里自身封闭的子集,必含 0 |
| column space C(A) | 列空间 | A 的列所有线性组合 |
| zero vector / zero space | 零向量 / 零空间 | 0 / 只含 0 的最小子空间 |

**本质**:收尾置换(P⁻¹=Pᵀ)与转置/对称($R^TR$ 必对称),然后开启**向量空间**视角:空间 = 对加法、数乘封闭的向量集合(必含零向量),子空间 = 空间里自身封闭的子集。从矩阵「造」子空间的关键一步是**列空间 C(A)**——A 的列所有线性组合,$Ax=b$ 可解 ⟺ b ∈ C(A)。这把 L1 的「列组合」升级成正式的空间语言,是后面零空间、秩、四个基本子空间的地基。
