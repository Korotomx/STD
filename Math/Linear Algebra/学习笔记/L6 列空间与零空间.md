# 列空间与零空间 Column Space and Nullspace · 18.06 L6

**时间:** 2026-10-22
**标签:** #线性代数LinearAlgebra #向量空间VectorSpace #子空间Subspace #列空间ColumnSpace #零空间NullSpace #线性组合LinearCombination
**关联:** [[L5 转置·置换·向量空间]]（上一讲：向量空间定义）· [[L7 求解Ax=0主变量与特解]]（下一讲：零空间的系统求法）

## 必要性（为什么要有这一章）

**要解决的问题**:上一讲(L5)给了「向量空间 / 子空间」的定义,这一讲回答**线性代数最中心的问题**——$Ax=b$ 到底对哪些 $b$ 有解?

**意义(重点)**:Strang 用**两个子空间**把这个问题彻底说清:

1. **列空间(column space)$C(A)$** —— 由「列向量的线性组合」生成。它回答:**$b$ 要是列的某个组合,才有解**;也就是说 $Ax=b$ 可解 $\iff$ $b\in C(A)$。
2. **零空间(null space)$N(A)$** —— $Ax=0$ 的所有解 $x$ 的集合。它回答:**解不唯一时,「多出来」的解长什么样**(本讲的例子是一条直线)。

一句话:列空间管「右端 $b$ 能不能被够到」,零空间管「解有多少、往哪飘」。

## 主要内容

### 1. 子空间的两个要求(回顾 + 两个新判断)

- **向量空间** = 对**加法**和**数乘**封闭,等价于「任意线性组合都还在空间里」。
- **子空间** = 大空间内部、自己又是一个向量空间的子集。**所有子空间都必过原点(含零向量)**。
- 两个重要判断(本讲新):
  - **并集不是子空间** ❌:平面 $P$ ∪ 直线 $L$,从 $P$ 取一个、从 $L$ 取一个相加,结果落到两者之外 → 不封闭。
  - **交集是子空间** ✅:若 $v,w\in S\cap T$,则 $v+w\in S$(因 $S$ 是子空间)且 $\in T$,故 $v+w\in S\cap T$;数乘同理。交集「缩小了」但还是子空间。

### 2. 列空间 $C(A)$

对矩阵 $A=\begin{bmatrix}1&1&2\\2&1&3\\3&1&4\\4&1&5\end{bmatrix}$(4×3):

- **定义**:$C(A)$ = A 三列的**所有线性组合** = $\{Ax:x\in\mathbb R^3\}$。这是「给几个向量、取它们的组合」把空间**建出来**。
- **在哪个大空间里**:A 是 $m\times n$,每列有 $m$ 个分量 → $C(A)\subset\mathbb R^m$。本例 4×3 → 在 $\mathbb R^4$。
- **核心结论**:$Ax=b$ 可解 $\iff$ $b\in C(A)$。因为 $Ax$ 就是「用 $x$ 的分量给列配系数的组合」,解存在的意义就是 $b$ 恰好落在这个组合里。
- **这个 $C(A)$ 多大**:三列**不独立**——第 3 列 = 第 1 列 + 第 2 列($2,3,4,5=1,2,3,4+1,1,1,1$),所以第 3 列「贡献不出新东西」。$C(A)$ 是 $\mathbb R^4$ 里的一个**二维平面**(由前两列张成)。Strang 由此预告了「**主元列(pivot column)** / 独立与相关」——第 1、2 列是主元列,第 3 列相关、可以扔掉。

### 3. 零空间 $N(A)$

- **定义**:$N(A)$ = $Ax=0$ 的**所有解 $x$** 的集合(不是右端 $b$,是未知量 $x$)。「null = 零」。
- **在哪个大空间里**:$x$ 有 $n$ 个分量 → $N(A)\subset\mathbb R^n$。本例在 $\mathbb R^3$,和列空间(在 $\mathbb R^4$)是**两个完全不同的空间**。
- **本例求出来**:$Ax=0$ 的解是 $\begin{bmatrix}c\\c\\-c\end{bmatrix}$(因为第 3 列 = 第 1 列 + 第 2 列,取 $1,1,-1$ 正好抵消)。这就是 $\mathbb R^3$ 里**过原点的一条直线**(沿 $(1,1,-1)$ 方向)。
- **它确实是子空间**(用分配律证):若 $Av=0,Aw=0$,则 $A(v+w)=Av+Aw=0$,且 $A(cv)=c\,Av=0$。→ 加法、数乘都封闭。

### 4. 关键对比:描述子空间的两种方式(全课主线)

| | 列空间 $C(A)$ | 零空间 $N(A)$ |
| ---- | ---- | ---- |
| 描述方式 | **给向量**(几列),取组合「**填满**」 | **给方程**(约束),找满足的 $x$「**筛出来**」 |
| 内容 | 右端 $b$ 能取到的集合 | 未知量 $x$ 的集合 |
| 所在的 $\mathbb R$ | $\mathbb R^m$ | $\mathbb R^n$ |

- **重要反例**:把右端从 $0$ 改成 $b=(1,2,3,4)$,解集(如 $x=(1,0,0)$、$(0,-1,1)$ 等)就**不再是子空间**——因为零向量不满足 $Ax=b$,解集「不过原点」。只有 $Ax=0$ 的解才成子空间。

## 直观理解（3Blue1Brown 视角）

把 $A$ 看成**线性变换**(挤压/旋转/拉伸整个空间,见 [[L1 线性方程的几何]] 的列图像):

- **列空间 = 变换的「像(image)」**:空间被变换后,所有向量能落到的那个平面/线。$Ax=b$ 有解,就是问「$b$ 是不是落在变换后的空间里」。
- **零空间 = 变换的「核(kernel)」**:被这个变换**压扁到原点**的那一撮向量。维度越高,「被压没」的方向越多,解的自由度越大。

## 拓展延伸

- **零空间 → 通解结构**:下一讲(L7)用消元系统求 $N(A)$,得到「特解 + 零空间」的完整解。本讲只「看」出直线,消元是通用机械化方法。
- **秩-零化度定理(预告)**:$\dim C(A)+\dim N(A)=n$(列数)。本例 $\dim C(A)=2,\dim N(A)=1,n=3$,正好 $2+1=3$。
- **AI/CS 联系**:零空间非零 = 矩阵「信息有冗余」(列相关);秩衡量「信息量」。数据降维 / 最小二乘里「欠定、多解」的本质就是零空间维数 > 0。

## 总结

**本质:** $Ax=b$ 的两个「家」——**列空间**管右端 $b$(可解 $\iff b\in C(A)$,由列向量组合生成,在 $\mathbb R^m$);**零空间**管解 $x$($Ax=0$ 的解,在 $\mathbb R^n$,是子空间)。描述子空间两种方式:给向量取组合(列空间)vs 给方程做约束(零空间)。$Ax=b(b\neq0)$ 的解不是子空间,因为不过原点。
