$Ax=b$ 对哪些 $b$ 有解、解的自由度有多大，由两个子空间回答：列空间 $C(A)$ 管右端能否被够到，零空间 $N(A)$ 管解往哪飘。

## 子空间的两个判断

- 子空间必含零向量，对加法和数乘封闭。
- **并集一般不是子空间**：平面 $P$ 与直线 $L$ 各取一个向量相加，可能落到两者之外。
- **交集是子空间**：$v,w\in S\cap T$ 时，$v+w$ 同时在 $S$ 和 $T$ 中，数乘同理。

## 列空间 $C(A)$

以

$$
A=\begin{bmatrix}1&1&2\\2&1&3\\3&1&4\\4&1&5\end{bmatrix}
$$

为例：

- $C(A)=\{Ax:x\in\mathbb R^3\}$，是 $A$ 三列的所有线性组合。
- $A$ 是 $m\times n$，每列有 $m$ 个分量，所以 $C(A)\subset\mathbb R^m$；本例在 $\mathbb R^4$。
- **$Ax=b$ 可解 $\iff b\in C(A)$**。
- 第 3 列 = 第 1 列 + 第 2 列，所以只有前两列贡献新方向，$C(A)$ 是 $\mathbb R^4$ 中的二维平面。前两列就是**主元列**。

## 零空间 $N(A)$

- $N(A)=\{x:Ax=0\}$，是未知量 $x$ 的集合，位于 $\mathbb R^n$。
- 本例第 3 列 = 第 1 列 + 第 2 列，取 $(1,1,-1)$ 正好抵消：

$$
N(A)=\operatorname{span}\{(1,1,-1)^{\mathsf T}\},
$$

是 $\mathbb R^3$ 中过原点的一条直线。

- 它确实是子空间：$A(v+w)=Av+Aw=0$，$A(cv)=cAv=0$。

## 描述子空间的两种方式

| | 列空间 $C(A)$ | 零空间 $N(A)$ |
| ---- | ---- | ---- |
| 方式 | 给向量，取组合「填满」 | 给方程，找满足的 $x$「筛出」 |
| 内容 | 右端 $b$ 的集合 | 未知量 $x$ 的集合 |
| 所在空间 | $\mathbb R^m$ | $\mathbb R^n$ |

反例：$Ax=b$（$b\ne0$）的解集不是子空间，因为零向量不满足方程，解集不过原点。

## 直观理解（3b1b）

- 列空间 = 变换的**像**：所有输出能落到的平面/线；$Ax=b$ 有解就是 $b$ 在像里。
- 零空间 = 变换的**核**：被压到原点的那一撮向量；零空间越大，解的自由度越大。

## 拓展延伸

- 下一讲用消元系统求 $N(A)$，得到「特解 + 零空间」的完整解。
- 秩-零化度：$\dim C(A)+\dim N(A)=n$；本例 $2+1=3$。
- 零空间非零 = 矩阵信息有冗余；欠定、多解的本质是零空间维数 > 0。

## 术语

| 英文 | 中文 | 含义 |
| ---- | ---- | ---- |
| column space $C(A)$ | 列空间 | 列的所有线性组合，$\subset\mathbb R^m$ |
| null space $N(A)$ | 零空间 | $Ax=0$ 的所有解，$\subset\mathbb R^n$ |
| pivot column | 主元列 | 贡献新方向的列 |
| image / kernel | 像 / 核 | 列空间 / 零空间的变换视角 |

## 总结

列空间管 $b$：可解 ⟺ $b\in C(A)$，由列组合生成，在 $\mathbb R^m$；零空间管 $x$：$Ax=0$ 的解，在 $\mathbb R^n$，是子空间。给向量取组合 vs 给方程做约束，是描述子空间的两种方式。$Ax=b$（$b\ne0$）的解集不过原点，不是子空间。
