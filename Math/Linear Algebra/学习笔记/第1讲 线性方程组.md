# 线性方程组 Systems of Linear Equations · 第1讲

**时间:** 2026-10-11
**标签:** #线性代数LinearAlgebra #线性方程组LinearSystem #矩阵Matrix #初等行变换ElementaryRowOperations #高斯消元GaussianElimination #行阶梯形RowEchelonForm #高斯约当GaussJordan #行最简形RREF #齐次方程组HomogeneousSystem
**关联:** [[矩阵]] [[行列式]] [[向量空间]]

## 必要性(为什么要有这一章)

**要解决的问题**:给定若干个线性关系,求同时满足它们的未知量。这是人类最早、也是最基础的「用数学描述并求解现实问题」的形式。

**历史渊源**:
- 约 2000 年前,中国《九章算术》的「方程」章就用算筹列方程、按「遍乘直除」法求解——本质上就是今天的高斯消元法。
- 高斯(Carl Friedrich Gauss)在 1809 年为研究天体轨道(最小二乘法)正式系统化了消元法。
- 「线性代数」这个学科名字的源头就是「解线性方程组」这件事:后面的矩阵、行列式、向量空间,几乎都是为了把「解方程组」研究得更清楚而发明出来的。

**意义(重点)**:线性方程组是整个线性代数的**入口和引擎**:
1. 现实世界大量关系在一阶近似下都是线性的(线性的本质 = 「比例 + 叠加」),所以它建模能力极强。
2. 后续所有内容(矩阵、行列式、向量空间、特征值)都在回答同一个母问题:**这个方程组有没有解?解唯一吗?怎么高效地求?**
3. 它是计算机里最常执行的数学运算之一——`numpy`/`torch` 里 `solve()` 的底层就是这一讲的消元。

## 主要内容

### 1. 线性方程与线性方程组

- **线性方程(linear equation)**:形如 $ax+by=c$(a、b 不全为 0)。n 元推广:
  $$a_1x_1 + a_2x_2 + \cdots + a_nx_n = b$$
  其中 $a_1$ 是**首项系数(leading coefficient)**,$x_1$ 是**首变量(leading variable)**。
- **线性方程组(linear system)**:m 个方程、n 个未知量,记作 $m \times n$ 线性方程组。
- **解(solution)**:一组使所有方程同时成立的值。

### 2. 解的三种情况(几何对应)

| 情况 | 几何意义(二元) | 例子 |
| ---- | -------------- | ---- |
| 唯一解(unique) | 两直线交于一点 | $x+y=5,\ 2x-y=4$ → $(3,2)$ |
| 无解(no solution) | 两直线平行 | $-2x+y=3,\ -4x+2y=2$ |
| 无穷多解(many) | 两直线重合 | $4x-2y=6,\ 6x-3y=9$ |

三元方程对应三维空间里的**平面**;三个平面可交于一点(唯一)、无公共点(无解)、或交成一条线(无穷多解)。

### 3. 矩阵表示:把方程组「压缩」成一张表

- **矩阵(matrix)**:数的矩形阵列,每个数叫元素(element)。
- **系数矩阵(coefficient matrix)** $A$:只放系数。
- **增广矩阵(augmented matrix)** $[A\mid b]$:系数 + 常数项拼在一起。
- 实质:方程里的 $x$、$+$、$=$ 都是「重复的包装」,真正有用的只有系数和常数。抽掉它们,消元就变成对一张数字表格做「行操作」。

### 4. 等价变换 → 初等行变换

- **等价方程组(equivalent system)**:解集相同的两个方程组。
- 三种不改变解集的**初等行变换(elementary row operations)**:
  1. 交换两行(swap);
  2. 某行乘非零常数(scale);
  3. 某行的倍数加到另一行(add multiple)。

### 5. 高斯消元法(Gaussian elimination)

- **主元(pivot)/ 主元行(pivotal row)**:当前行的第一个非零元素及其所在行。
- 目标:通过初等行变换,把增广矩阵化成**行阶梯形(row echelon form)**。
- 行阶梯形三条性质:
  1. 全零行在最下面;
  2. 每行第一个非零元素是 1(主元 1);
  3. 上一行的主元 1 比下一行的更靠左。
- **主变量(lead variable)** vs **自由变量(free variable)**:对应主元的变量是主变量;被跳过列对应的变量是自由变量。
- **相容(consistent)/ 不相容(inconsistent)**:阶梯形若出现形如 $[0\ 0\ \cdots\ 0\ |\ 1]$ 的行 → 无解(不相容);否则有解(相容)。

### 6. 高斯-约当消元法(Gauss-Jordan)与行最简形(RREF)

- **行最简形(reduced row echelon form, RREF)**:行阶梯形基础上,每个主元 1 所在列的其余位置全是 0。
- **唯一性(重点)**:一个矩阵的行最简形是**唯一**的。
- 高斯-约当消元 = 在阶梯形基础上继续向上消,把主元 1 上方也清零。

### 7. 齐次线性方程组(homogeneous system)

- 定义:所有常数项为 0。
- **定理 1**:齐次方程组必有解 $x_1=x_2=\cdots=x_n=0$,称为**平凡解(trivial solution)**。
- **定理 2**:若齐次方程组的**变量数 > 方程数**,则有无穷多解(必有非平凡解 nontrivial solution)。

> 🎬 **动画演示**(manim 绘制,3Blue1Brown 风格)——三种解的几何直观:两直线**相交** = 唯一解、**平行** = 无解、**重合** = 无穷多解:

![[线性方程组三种解.mp4]]

- **一个线性方程 = 一张「平」的超平面**:二元是直线,三元是平面,n 元是 $n-1$ 维超平面。线性 = 几何上的「平」。
- **解方程组 = 找这些超平面的公共交点**。三种结果就是几何相交的三种可能:一个点 / 不相交 / 交成低维的一块。
- **初等行变换 = 不移动交点,只换一种「描述」**:交换两行是换方程顺序,乘常数是缩放方程,倍数相加是「用一个方程消掉另一个里的未知量」——每一步都在「换个角度看同一个方程组」,所以解集纹丝不动。
- **高斯消元 = 把交点「一层层钉死」**:先固定一个主元当「锚」,用它消掉下方所有行的这一列,再往下走……最后矩阵变成**阶梯**,从最后一行往上回代(back substitution),每个主元对应一个被「钉住」的变量。
- **自由变量 = 交点所在的「可滑动维度」**:解不唯一时,交点不是孤立点,而是一条线/一张面——自由变量的个数就是这条线/面的维度。

## 拓展延伸(与 AI / 计算机的关联)

- **求解线性方程组是计算机里最基础、最高频的运算之一**,也是「数值线性代数(numerical linear algebra)」这门学科的地基。`numpy.linalg.solve`、`torch.linalg.solve`、LAPACK 的 `dgesv` 底层都是消元法,时间复杂度 $O(n^3)$(n 阶矩阵约 $n^3/3$ 次乘加运算)。
- **消元的「工业版」= LU 分解**:高斯消元每一步用到的「乘数」可以存起来,把矩阵 A 分解成 $A = LU$(下三角 × 上三角)。这样只要 A 不变、只换常数项 b,就只需 $O(n^2)$ 回代,不必每次 $O(n^3)$ 重消——这是「同一个 A、很多个 b」(反复仿真、遍历参数)场景的关键优化。
- **稳定性与「选主元」**:浮点数有舍入误差,若主元恰好是 0 或非常小,直接消元会数值爆炸。所以工业实现几乎都用**部分选主元(partial pivoting)**:每一步挑绝对值最大的元素当主元,把误差放大压到可控范围。这背后是**条件数(condition number)** 的概念——它衡量「解对输入扰动的敏感度」,是判断「算出来的解能不能信」的核心指标。
- **线性回归 / 最小二乘**:拟合数据要求解正规方程 $A^TAx = A^Tb$。几何上,最小二乘解正是 b 在 A 的**列空间上的正交投影**——这一步把「解方程」和「投影 / 几何」打通了(后面向量空间、内积空间会正式展开)。高斯 1809 年研究天体轨道的最小二乘,正是消元法的直接动机。
- **神经网络 = 线性系统的两端**:
  - 前向:全连接层 $y = Wx + b$ 就是「矩阵 × 向量」,是线性方程组的正向版;
  - 训练:反向传播求梯度,本质是在解一个**超大规模**的线性 / 优化问题。但权重矩阵动辄上百万维,$O(n^3)$ 的消元根本跑不动,所以改用**迭代法**(梯度下降)一步步逼近——这就解释了为什么「解方程」在 AI 里被换成了「迭代优化」。
- **PageRank(Google 排序)**:网页间的链接关系构成一个巨大矩阵,PageRank 值是它的主特征向量(后面章节),而求特征值的许多算法第一步仍是消元。
- **计算机图形学**:光线追踪里「光线与三角形是否相交」、3D 变换的逆矩阵(把屏幕坐标还原成世界坐标),都是解线性方程组。

## Note(连接 / 深化)

- **连接**:矩阵是这一讲的「主角」,后面 [[矩阵]] 会展开它的运算与性质;解的集合本质上是 [[向量空间]](无穷多解时的结构由向量空间刻画);判解的唯一性还会用 [[行列式]]。
- **深化**:高斯消元只做到阶梯形(够回代),高斯-约当做到最简形(直接读解);真正在计算机里,消元过程会被保存成 **LU 分解**,这样换一组 $b$ 就能 $O(n^2)$ 重解,不必每次 $O(n^3)$ 重新消元。

**本质**:线性方程组 = 对「线性关系」最直接的刻画;解方程组 = 求一组超平面的公共交点。核心思想是**等价变换**——在**不改变解集**的前提下,把方程组(增广矩阵)通过初等行变换化简成阶梯形 / 最简形,让解「自己浮现出来」。矩阵则是把方程组压缩成一张数字表,使「消元」从代数操作变成机械的**行操作**。解的三种情况(唯一 / 无 / 无穷)、主元与自由变量、齐次方程组,都统一在「阶梯形长什么样」这一个判断之下。
