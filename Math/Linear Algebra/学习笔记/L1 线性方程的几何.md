# 线性方程的几何 Geometry of Linear Equations · 18.06 L1

**时间:** 2026-10-20
**标签:** #线性代数LinearAlgebra #线性方程组LinearSystem #行图像RowPicture #列图像ColumnPicture #线性组合LinearCombination #奇异Singular
**关联:** [[L2 消元]]（下一讲，系统解法）· [[向量空间]]

## 必要性（为什么要有这一章）

**要解决的问题**:线性代数的**根本问题**——解线性方程组 $Ax=b$。n 个方程、n 个未知量是「正常的好情况」。

**历史渊源**:约 2000 年前《九章算术》的「方程」章就在做消元;高斯 1809 年为研究天体轨道(最小二乘)系统化了消元法。但这一讲不是教「怎么算」(那是 L2 消元),而是先回答一个更重要的问题:**这套方程在几何上到底在问什么?**

**意义(重点)**:Strang 把解方程组拆成**两种图景**,这是全课的根基:
1. **行图像(row picture)**——一条方程一条方程地看:二元是直线、三元是平面,解 = 它们的交点。这是你熟悉的、但高维就「看不见」的图景。
2. **列图像(column picture)**⭐——一列一列地看:解 $Ax=b$ = **用 x、y、z 给 A 的列向量配系数,线性组合出 b**。这是整个线性代数的核心运算,高维也能想通。

## 主要内容

### 1. 线性方程组与矩阵形式

- **线性方程**:$a_1x_1+\cdots+a_nx_n=b$;**线性方程组**:m 个方程、n 个未知量。
- **矩阵形式**:$Ax=b$。$A$ 是系数矩阵,把方程组「压缩」成一张数字表;$x$ 是未知量向量;$b$ 是右端向量。例(Strang 的 2×2):

$$\begin{cases}2x-y=0\\-x+2y=3\end{cases}\quad\Longleftrightarrow\quad \begin{bmatrix}2&-1\\-1&2\end{bmatrix}\begin{bmatrix}x\\y\end{bmatrix}=\begin{bmatrix}0\\3\end{bmatrix}$$

### 2. 行图像 row picture（一条方程 = 一条直线 / 一张平面）

- 每条方程单独看:$2x-y=0$ 是过原点的一条直线,$-x+2y=3$ 是另一条;两条直线的**交点 (1,2)** 就是解。
- 三元:每条方程是三维空间里的一张**平面**,三张平面交于一点(若不平行、不特殊)。
- 缺点:高维(四维以上)行图像「看不见」——三个平面怎么交都难画。

### 3. 列图像 column picture（核心，打星号）

把 $Ax=b$ 按**列**重新分组:

$$x\begin{bmatrix}2\\-1\end{bmatrix}+y\begin{bmatrix}-1\\2\end{bmatrix}=\begin{bmatrix}0\\3\end{bmatrix}$$

- 这就是**线性组合(linear combination)**:用 $x$、$y$ 作系数,把两列向量组合成 $b$。**它是全课最基础的运算。**
- 例中解 $x=1,y=2$ 即「1 个第一列 + 2 个第二列」,向量头尾相接正好落到 $b=(0,3)$。
- **列图像问的是**:这两列的各种组合,能不能「够到」$b$?

### 4. 矩阵乘向量 = 列的线性组合

$$\begin{bmatrix}2&5\\1&3\end{bmatrix}\begin{bmatrix}1\\2\end{bmatrix}=1\cdot\begin{bmatrix}2\\1\end{bmatrix}+2\cdot\begin{bmatrix}5\\3\end{bmatrix}=\begin{bmatrix}12\\7\end{bmatrix}$$

- **$Ax$ 永远读作「A 的列的线性组合」**,系数就是 x 的分量。这是 Strang 希望你在后面所有章节都保持的读法。

### 5. 解的三种情况 → 奇异(singular)情况

| 情况 | 几何(列图像) | 例子 |
| ---- | ---- | ---- |
| 唯一解 | 列向量不共线,组合能到达任何 b | 上面 2×2 |
| 无穷多解 / 无解 | **列向量共线(共面)** → 组合只落在一条线/一张面内,大多数 b 够不到 | 若第三列 = 第一列+第二列,则「什么都没新加」 |

- **母问题(贯穿全课)**:对**每一个** b,$Ax=b$ 都有解吗?用列图像说 = **「列的线性组合能否填满整个空间?」**
  - 能填满 → 非奇异(nonsingular)、可逆(invertible),「好矩阵」;
  - 填不满(列共线/共面)→ 奇异(singular),只有落在那个低维空间里的 b 才可解,其余 b 不可达。
- 高维同理:九个列向量若第九列 = 第八列,则组合只填满一个「九维空间里的八维平面」,差一维够不到。

### 6. 解的三种情况(代数判据,详见 L2/L3)

- 唯一解 / 无解 / 无穷多解,代数上由**消元**(L2)的阶梯形长什么样来判定;可逆 ⟺ 唯一解会在 L3 打通。
- 齐次方程组 $Ax=0$ 必有平凡解 $x=0$;若它还有**非零解**,则 A 必奇异(L3 会用它证逆不存在)。

## 直观理解（空间视角）

- **行图像 = 超平面相交**:一个线性方程是一张「平」的超平面(二元直线、三元平面),解方程组 = 找公共交点。直观但高维失效。
- **列图像 = 向量组合**:把每列看成一枝箭,解 = 用「缩放 + 头尾相接」把箭拼到目标 b。这个图景在任意维都成立——九维向量你「假装能看见」,慢慢就习惯了。
- **奇异的本质 = 列「偷懒」**:一旦某列是其他列的线性组合(共线/共面),它就「没贡献新方向」,所有组合被锁在一个低维平面里,自然够不到面外的 b。

## 拓展延伸（与 AI / 计算机的关联）

- **$Ax=b$ 的「列组合」视角 = 特征工程/基展开的雏形**:任何向量写成「若干基向量的线性组合」,就是「表示学习」的数学骨架(傅里叶展开、PCA 的主成分、word embedding 的线性子空间都是它)。
- **「对每个 b 是否有解」= 矩阵是否满秩**:机器学习里「设计矩阵 X 的列是否线性无关」直接决定正规方程 $X^TX$ 是否可逆、最小二乘解是否唯一——列共线(多重共线性)是实际建模里反复遇到的病。
- **解方程组 = 数值线性代数的地基**:`numpy.linalg.solve`、`torch.linalg.solve`、LAPACK 底层都是下一讲(L2)的消元,复杂度 $O(n^3)$。
- **神经网络一层 = 矩阵乘向量**:$y=Wx+b$ 的 $Wx$ 正是「W 的列的线性组合」——每个输出神经元的值,都是输入 x 对各「权重列向量」的组合系数,这一讲是理解全连接层几何含义的关键。

## Note（连接 / 深化）

- **连接**:「怎么系统求 x」是 [[L2 消元]];「列是否线性无关」会在 [[向量空间]]、[[L5 转置·置换·空间]] 用列空间 C(A) 精确刻画;可逆 ⟺ 满秩 ⟺ 唯一解在 L3、行列式章彻底打通。
- **深化**:线性组合 + 「所有组合的集合」= 列空间(column space),这是 L5 引入的第一个核心子空间——L1 埋下的种子。

## 总结

### 本讲新引入的专业术语

| 英文术语 | 中文 | 含义 |
| -------- | ---- | ---- |
| linear equation / system | 线性方程 / 方程组 | $a_1x_1+\cdots+a_nx_n=b$ / 多个方程 |
| coefficient matrix A | 系数矩阵 | 只放系数的矩阵 |
| unknown vector x / RHS b | 未知量向量 / 右端向量 | $Ax=b$ 里的 x 和 b |
| row picture | 行图像 | 一条方程一条方程看(直线/平面相交) |
| column picture | 列图像 | 一列一列看(列的线性组合) |
| linear combination | 线性组合 | 向量乘系数再相加 |
| singular / nonsingular | 奇异 / 非奇异 | 列组合填不满空间 / 能填满 |
| invertible | 可逆 | 非奇异矩阵(有好逆) |

**本质**:解 $Ax=b$ 有两种等价读法——行图像(超平面交点)与**列图像(列的线性组合)**。列图像是全课的地基:$Ax$ = 列的线性组合,「对每个 b 是否有解」= 「列的组合能否填满整个空间」。填得满 = 非奇异(好矩阵),填不满(列共线/共面)= 奇异。这一讲的「组合 + 空间」思维,直接通向后面的列空间、线性无关、秩。
