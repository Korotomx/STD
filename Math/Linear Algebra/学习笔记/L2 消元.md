# 消元 Elimination with Matrices · 18.06 L2

**时间:** 2026-10-20
**标签:** #线性代数LinearAlgebra #高斯消元GaussianElimination #消元矩阵EliminationMatrix #主元Pivot #回代BackSubstitution #置换矩阵Permutation #上三角UpperTriangular
**关联:** [[L1 线性方程的几何]]（上一讲，几何）· [[L3 矩阵乘法与逆]]

## 必要性（为什么要有这一章）

**要解决的问题**:L1 用列图像「看」懂了 $Ax=b$,但「看」不出解——尤其高维。需要一个**系统的、能被软件执行的**解法。

**这就是消元(elimination)**——**每个软件包解方程用的方法**(不是行列式,行列式后面才讲)。而且它一边求解,一边**自动判断矩阵是好是坏**(可逆还是奇异)。

**意义(重点)**:这一讲的真正新东西,是**用矩阵语言表达消元**——把「每一步行操作」写成一个**消元矩阵 E**。因为全课所有关键思想最终都要写成矩阵运算,而不是文字。消元的每一步,本质是「左乘一个初等矩阵」,这把「消元」和「矩阵乘法」彻底打通,也是下一讲 LU 分解的地基。

## 主要内容

### 1. 消元 = 前向消元(forward elimination)到 U

例(Strang 的 3×3):$Ax=b$,即
$$\begin{bmatrix}1&2&1\\3&8&1\\0&4&1\end{bmatrix}\begin{bmatrix}x\\y\\z\end{bmatrix}=\begin{bmatrix}2\\12\\2\end{bmatrix}$$

- **主元(pivot)**:每一步「不动的那个关键数」(第一主元 = 1)。**主元不能是 0**。
- **乘数(multiplier)**:消去下方某列时「乘几倍第一行再减」的那个数(第一步乘数 = 3,消掉 (2,1) 位置的 3)。
- 目标:把 A 化成**上三角 U(upper triangular)**:
$$\begin{bmatrix}1&2&1\\3&8&1\\0&4&1\end{bmatrix}\xrightarrow{\text{消元}}\begin{bmatrix}1&2&1\\0&2&-2\\0&0&5\end{bmatrix}=U$$
  三个主元 = 1、2、5。**行列式 = 主元乘积**(本例 = 10,顺带一提,后面才正式讲)。

### 2. 回代(back substitution)

消完得到上三角方程组 $Ux=c$(右端 b 也一路同步变到 c):
$$x+2y+z=2,\quad 2y-2z=6,\quad 5z=-10$$
从最后一行往上倒着解:$z=-2 \to y=1 \to x=2$。回代之所以简单,正因为 U 是**三角**的。

- **增广矩阵(augmented matrix)**:把右端 b 当一列「拼」在 A 右边,对左右同步做行变换。

### 3. 消元矩阵 E(初等矩阵)—— 本讲核心

每一步「行操作」等价于**左乘一个矩阵 E**:

- 例:把 (2,1) 位置消成 0(减 3 倍第一行)对应
$$E_{21}=\begin{bmatrix}1&0&0\\-3&1&0\\0&0&1\end{bmatrix}$$
  整体消元:$E_{32}E_{21}A=U$。
- **左乘 = 行操作,右乘 = 列操作**:交换列的置换矩阵要放**右边**。
- **单位矩阵 I** = 「什么都不做」(矩阵里的「1」)。
- 把一步消元对应的矩阵统称**初等矩阵 E**(elementary matrix);它对 I 做一次行变换即可得到。
- **E 的逆**:消元「减 3 倍行 1」的逆是「加 3 倍行 1」,对应 $E_{21}^{-1}$ 把 $-3$ 换 $+3$——**初等矩阵极易求逆**。

### 4. 置换矩阵 P(交换行)

- 主元位置出现 0 时,交换两行 → 对应**置换矩阵 P**(把 I 的相应行换一下即可)。
- 例(2×2 交换两行):$P=\begin{bmatrix}0&1\\1&0\end{bmatrix}$。
- 性质(后面 L5 展开):$P^T=P^{-1}$(逆 = 转置)。

### 5. 矩阵乘法的两条铁律(消元全程要用)

- **结合律(可移括号)**:$(E_{32}E_{21})A=E_{32}(E_{21}A)$——矩阵顺序不能乱,但可以先算哪两个乘法。
- **不可交换**:$AB\ne BA$——消元矩阵必须保持「高斯给定的顺序」,不能颠倒。

### 6. 失败的两类:临时 vs 永久

- **临时失败(可救)**:主元位置是 0,但**下方有非零** → 换行(置换 P)即可继续。
- **永久失败(奇异)**:主元位置是 0 且**下方全是 0** → 凑不出第三个主元,矩阵**不可逆**。(例:第一行减 4 倍消到第三行恰为 0)
- 一句话:**消元要么一路顺利得 n 个主元(非奇异),要么在某处 0 且无行可换(奇异)**。

### 7. 高斯-约当消元与行最简形(合并自原课程)

- **行阶梯形(row echelon form)**:全零行在最下、主元 1 依次右移——够回代了。
- **行最简形(RREF)**:继续向上消,让每个主元 1 所在列其余位置全 0。**RREF 唯一**。
- **齐次方程组 $Ax=0$**:必有平凡解 $x=0$;变量数 > 方程数 → 必有非平凡解。

## 直观理解（空间视角）

- **消元 = 不移动交点,只换「描述」**:初等行变换(交换/倍乘/倍加)每一步都在「换个角度看同一个方程组」,解集纹丝不动。几何上交点/交线没动,只是把它「一层层钉死」成阶梯。
- **前向消元 = 自上而下「钉主元」**:先固定第一主元当锚,消掉下方整列,再往下……最后矩阵变阶梯,从下往上回代,每个主元钉住一个变量。
- **消元矩阵 E = 「行操作的封装」**:E 的每一行就是「用 A 的哪些行、按什么系数组合出新行」——`-3 1 0` 就念作「-3×行1 + 1×行2」。
- **主元 = 矩阵的「骨架」**:主元非零且个数够,矩阵就「站得住」(非奇异);缺一个主元,矩阵就「塌成低维」(奇异)。行列式 = 主元乘积,正是这个骨架的「体积」。

## 拓展延伸（与 AI / 计算机的关联）

- **消元是数值线性代数的地基**:`numpy.linalg.solve`、LAPACK `dgesv`、`torch.linalg.solve` 底层都是「消元 + 回代」,复杂度 $O(n^3)$。
- **工业实现要「选主元」**:浮点有舍入误差,主元太接近 0 会数值爆炸,所以真实软件(Matlab 也如此)会用**部分选主元**——挑绝对值最大的元素当主元(下一讲 LU 分解、条件数会正式展开)。
- **消元矩阵 E → LU 分解**(下一讲主题):把每次的乘数存起来,消元就写成 $A=LU$,于是「同一个 A、很多个 b」只需 $O(n^2)$ 回代,不必每次 $O(n^3)$ 重消——仿真、遍历参数场景的关键优化。
- **「解方程」在 AI 里被「迭代」取代**:权重矩阵上百万维,$O(n^3)$ 消元跑不动,改用梯度下降一步步逼近(见 [[PyTorch 五步训练循环与核心语法]])——这是「直接解」与「迭代优化」两条路线的分野,而消元是「直接解」的代表。

## Note（连接 / 深化）

- **连接**:消元的矩阵形式 $E_{32}E_{21}A=U$ 反解即得 **A = LU**([[L4 A=LU 分解]]);「消元何时失败」的判据(主元个数)会在 [[L3 矩阵乘法与逆]] 与「可逆」挂钩;初等矩阵/置换矩阵的性质在 [[L5 转置·置换·向量空间]] 完整收束。
- **深化**:把每一步的 $E$ 记下来、并把它们的**逆**按反序叠起来,就得到 L(下三角,乘数直接填进去)——「消元记录乘数」这件事,是 L4 的核心洞察,这里先埋下。

## 总结

### 本讲新引入的专业术语

| 英文术语 | 中文 | 含义 |
| -------- | ---- | ---- |
| elimination | 消元 | 系统解方程组的方法 |
| pivot | 主元 | 每一步的关键数(不能为 0) |
| multiplier | 乘数 | 消去某列时「乘几倍再减」的数 |
| forward elimination | 前向消元 | 消到上三角 U |
| back substitution | 回代 | 从最后一行往上倒着解 |
| upper triangular U | 上三角矩阵 | 主对角线下全 0 |
| augmented matrix | 增广矩阵 | 把 b 拼在 A 右边 |
| elementary / elimination matrix E | 初等矩阵 / 消元矩阵 | 对 I 做一次行变换得到 |
| permutation matrix P | 置换矩阵 | 交换 I 的行 |
| row operation / column operation | 行操作 / 列操作 | 左乘 / 右乘矩阵 |
| singular | 奇异 | 消元凑不出 n 个主元(不可逆) |
| row echelon form / RREF | 行阶梯形 / 行最简形 | 阶梯状 / 主元列其余全 0 |
| homogeneous system | 齐次方程组 | 右端全 0 |

**本质**:消元 = 通过「不改变解集的初等行变换」把 A 化成上三角 U,再回代求解。矩阵语言下,每一步行操作 = **左乘一个消元矩阵 E**,整体 $E_{32}E_{21}A=U$;主元位置出 0 用置换 P 换行。消元一边求解,一边用「主元个数」判定矩阵**可逆还是奇异**——这是它比「看交点」高明的地方。
