消元（elimination）是软件解 $Ax=b$ 的标准方法：用不改变解集的初等行变换把 $A$ 化成上三角 $U$，再回代。每一步行操作都可以写成左乘一个消元矩阵 $E$。

## 前向消元与回代

以 $3\times3$ 为例：

$$
\begin{bmatrix}1&2&1\\3&8&1\\0&4&1\end{bmatrix}
\begin{bmatrix}x\\y\\z\end{bmatrix}
=\begin{bmatrix}2\\12\\2\end{bmatrix}
$$

- **主元**：每一步不动的关键数，不能为 0（本例 $1,2,5$）。
- **乘数**：消去下方元素时「乘几倍再减」的数（本例 $3,2$）。
- 前向消元得到上三角：

$$
U=\begin{bmatrix}1&2&1\\0&2&-2\\0&0&5\end{bmatrix}.
$$

- **回代**：从最后一行往上解，$z=-2\to y=1\to x=2$。$\det A$ 等于主元乘积（本例 $10$）。
- **增广矩阵** $[A\mid b]$：右端作为额外一列，行变换同步作用。

消元只用三种**初等行变换**：交换两行、某行乘非零常数、某行倍数加到另一行。它们给出**等价方程组**（解集相同）。行阶梯形的要求是全零行在最下、主元依次右移；若出现 $[0\ \cdots\ 0\mid\text{非零}]$ 则**不相容**（无解）。

## 消元矩阵 $E$ 与置换矩阵 $P$

把 (2,1) 位置的 3 消掉，等价于左乘

$$
E_{21}=\begin{bmatrix}1&0&0\\-3&1&0\\0&0&1\end{bmatrix},
\qquad E_{32}E_{21}A=U.
$$

- **左乘 = 行操作，右乘 = 列操作**；交换列要把置换矩阵放在右边。
- 单位矩阵 $I$ 是「什么都不做」。初等矩阵对 $I$ 做一次行变换即可得到。
- $E_{21}^{-1}$ 只需把 $-3$ 换成 $+3$——初等矩阵极易求逆。
- 主元位置为 0 时交换两行，对应**置换矩阵 $P$**；$P^{\mathsf T}=P^{-1}$。
- 乘法满足结合律（可移括号），但**不可交换** $AB\ne BA$，消元矩阵顺序不能颠倒。

## 失败的两类

- **临时失败**：主元位置为 0，但下方有非零 → 换行（$P$）继续。
- **永久失败**：主元为 0 且下方全 0 → 凑不出 $n$ 个主元，矩阵奇异、不可逆。

## 高斯-约当与行最简形

- **行阶梯形**：够回代。
- **行最简形（RREF）**：主元为 1，且主元所在列其余位置全 0；**RREF 唯一**。
- 齐次方程 $Ax=0$ 必有零解；变量数 > 方程数时必有非零解。

## 直观理解

- 消元 = 不移动交点，只换描述；前向消元自上而下钉住主元，回代从下往上解开。
- $E$ 的每一行就是「用 $A$ 的哪些行、按什么系数组合出新行」。
- 主元是矩阵的骨架：主元够且非零则非奇异，缺主元则塌成低维。

## 拓展延伸

- `numpy.linalg.solve`、LAPACK `dgesv`、`torch.linalg.solve` 底层都是消元 + 回代，$O(n^3)$。
- 浮点运算要**部分选主元**：挑绝对值最大的元素当主元，避免小主元放大误差。
- 把乘数存下来就是下一讲的 $A=LU$：同一个 $A$、很多个 $b$ 时，每个 $b$ 只需 $O(n^2)$。
- 上百万维的 AI 权重矩阵用迭代法（梯度下降）而非直接消元。

## 术语

| 英文 | 中文 | 含义 |
| ---- | ---- | ---- |
| elimination | 消元 | 系统解方程组的方法 |
| pivot / multiplier | 主元 / 乘数 | 关键数 / 消去某列时乘的倍数 |
| forward elimination / back substitution | 前向消元 / 回代 | 化上三角 / 从下往上解 |
| augmented matrix | 增广矩阵 | $[A\mid b]$ |
| elementary matrix $E$ | 初等矩阵 / 消元矩阵 | 对 $I$ 做一次行变换 |
| permutation matrix $P$ | 置换矩阵 | 交换行，$P^{-1}=P^{\mathsf T}$ |
| row echelon form / RREF | 行阶梯形 / 行最简形 | 阶梯状 / 主元列其余全 0 |
| singular | 奇异 | 凑不出 $n$ 个主元，不可逆 |

## 总结

消元用初等行变换把 $A$ 化成 $U$，再回代；矩阵语言下 $E_{32}E_{21}A=U$，主元为 0 时用 $P$ 换行。主元个数同时判定可逆与奇异，乘数保存下来就是 LU 分解。
