# 矩阵的逆 The Inverse of a Matrix · 第3讲

**时间:** 2026-10-11
**标签:** #线性代数LinearAlgebra #矩阵Matrix #逆矩阵InverseMatrix #可逆矩阵InvertibleMatrix #奇异矩阵SingularMatrix #高斯约当GaussJordan #线性方程组LinearSystem

## 必要性(为什么要有这一章)

**要解决的问题**:第 1 讲我们用消元法解方程组,第 2 讲学会了矩阵乘法。但有没有一个「**直接套公式**」的解法——不用每次都从头消元,而是像「数里除以 a」那样,一步得出答案?

**矩阵的逆就是「除法」**:数里有 $a\cdot\frac1a=1$,矩阵里希望有 $AA^{-1}=I$。一旦有了 $A^{-1}$,解方程组 $Ax=b$ 就变成一步乘法 $x=A^{-1}b$,而且还能用它表示「变换的撤销」。

**历史渊源**:「逆」的概念来自群的抽象代数;凯莱(Cayley)在 19 世纪建立矩阵代数时,把「倒数」推广成「逆矩阵」,从而让矩阵也能「做除法」。

**意义(重点)**:
1. **判据**:矩阵可逆 ⟺ 方程组 $Ax=b$ 有**唯一解**——这把「解的唯一性」翻译成了「矩阵有没有逆」。
2. **撤销**:逆矩阵 = 一个线性变换的「undo」按钮,在图形学、机器人、控制里无处不在(把世界坐标变回局部坐标、逆运动学)。
3. **贯穿后续**:后面行列式、特征值、最小二乘,「求逆」是反复出现的核心操作。

## 主要内容

### 1. 定义:可逆与奇异

- **可逆(非奇异 nonsingular / invertible)**:若 $n$ 阶方阵 $A$ 存在矩阵 $B$ 使 $AB=BA=I$,则称 $A$ 可逆,$B$ 是 $A$ 的**乘法逆(multiplicative inverse)**。
- **奇异(singular / noninvertible)**:没有乘法逆的方阵。
- **Remark**:可逆矩阵**必须是方阵**。

### 2. Theorem 1:逆的唯一性

若 $A$ 可逆,则其逆唯一,记作 $A^{-1}$。证明思路:设 $B,C$ 都是逆,则
$$B=IB=(CA)B=C(AB)=CI=C$$
(关键是用到**结合律**把括号换位)。所以 $AA^{-1}=A^{-1}A=I$。

### 3. 求逆:高斯-约当消元法

对 $n$ 阶方阵 $A$,构造**双增广矩阵** $[A\ |\ I]$,对它做初等行变换:

1. 把 $I$ 拼到 $A$ 右边,得 $[A\ |\ I]$(叫 adjoining)。
2. 用行变换把左半的 $A$ 化成 $I$,右边**自动变成 $A^{-1}$**:
   $$[A\ |\ I]\ \xrightarrow{\text{行变换}}\ [I\ |\ A^{-1}]$$
3. 验算 $AA^{-1}=I=A^{-1}A$。

> **判据**:若 $[A\ |\ I]$ 的左半部分化出了一个**全零行**,则 $A$ 不可逆(奇异)。(Example 4)

### 4. Theorem 2:乘积的逆(要反序!)

若 $A,B$ 都是 $n$ 阶可逆矩阵,则
$$(AB)^{-1}=B^{-1}A^{-1}$$
注意**顺序颠倒**——「先脱最晚穿的那件」。推广:$(A_1A_2\cdots A_k)^{-1}=A_k^{-1}\cdots A_2^{-1}A_1^{-1}$。

### 5. 幂扩展到全体整数

若 $A$ 可逆,定义 $A^0=I$,$A^{-k}=(A^{-1})^k$。则对任意整数 $\lambda,\mu$:
$$A^{\lambda}A^{\mu}=A^{\lambda+\mu},\qquad (A^{\lambda})^{\mu}=A^{\lambda\mu}$$

### 6. 可逆矩阵的 6 条性质

1. $(kA)^{-1}=\dfrac1k A^{-1}$($k\ne0$)
2. $(A^{-1})^{-1}=A$
3. $(A^k)^{-1}=(A^{-1})^k=A^{-k}$
4. 若 $P$ 可逆,则 $PA=PB\iff A=B$,$AP=BP\iff A=B$——**消去律对可逆矩阵成立!**(第 2 讲的「无消去律」是因为那些矩阵不可逆)
5. $A^T$ 也可逆,且 $(A^T)^{-1}=(A^{-1})^T$
6. $(AB)^{-1}=B^{-1}A^{-1}$

### 7. 用逆矩阵解方程组

**Theorem 3**:若 $A$ 可逆,则 $Ax=b$ 有**唯一解**
$$x=A^{-1}b$$

(Example 6:同一个系数矩阵 $A$、不同的 $b$,只需算一次 $A^{-1}$ 就能分别得到解。)

## 直观理解(空间视角)

> 🎬 **动画演示**(manim 绘制,3Blue1Brown 风格)——**可逆 vs 奇异矩阵**:可逆矩阵的基向量仍不共线、平面保持二维、变换可撤销;奇异矩阵把两个基向量压到同一方向、平面被压成一条线、信息丢失、无法撤销:

![[可逆与奇异矩阵.mp4]]

- **逆 = 变换的「撤销(undo)」**:矩阵 $A$ 把平面做一个变换,$A^{-1}$ 把它原样变回来($A^{-1}A=I$ = 「做了再撤销,等于没做」)。
- **可逆 ⟺ 基向量不共线**:$2\times2$ 矩阵的两列 = 基向量 $i,j$ 的像。只要它们还不共线,平面就没被压扁,信息还在,就能撤销。这正是「可逆」的几何含义。
- **奇异 ⟺ 平面被压扁**:若两列共线(或某列被压到原点),整个平面被压成**一条线甚至一个点**,无数不同的点被压到同一个点——信息丢失,自然无法撤销,所以没有逆。
- **$(AB)^{-1}=B^{-1}A^{-1}$ 反序**:复合变换「先穿袜子再穿鞋」,撤销时要「先脱鞋再脱袜子」——倒着来。

## 拓展延伸(与 AI / 计算机的关联)

- **数值上「求逆」其实是坏习惯,却无处不在**:工程里真正解 $Ax=b$ 几乎从不显式算 $A^{-1}$(求逆慢、且数值不稳定),而是用 LU/QR 分解直接解。但**理论上**求逆是所有「闭式解」的来源,比如最小二乘 $x=(A^TA)^{-1}A^Tb$——理解推导必须先懂逆。
- **奇异矩阵 = 秩亏(rank deficiency)**:把平面压成线,就是「降秩」。降维(PCA 主成分分析)、低秩分解、压缩感知,本质都是「故意让矩阵变奇异/降秩」来压缩信息——奇异性在机器学习里是被主动利用的工具。
- **协方差矩阵求逆**是高斯分布、卡尔曼滤波、高斯过程的数学核心:$x\sim\mathcal N(\mu,\Sigma)$ 的密度函数里是 $\Sigma^{-1}$(信息矩阵),滤波每一步都要解/求逆协方差矩阵。
- **归一化流(normalizing flows)**:一类生成模型要求每层变换都是**可逆**的(这样概率密度能精确算),「可逆矩阵/可逆变换」是它的硬性前提。
- **图形学 / 机器人**:把世界坐标变到相机局部坐标 = 乘一个**逆变换矩阵**;机械臂「逆运动学(inverse kinematics)」的 inverse,根源就是矩阵的逆。
- **机器学习里「不可逆」的麻烦**:正规方程 $A^TA$ 当特征共线(多重共线性)时会变得奇异/病态,需要加正则项(岭回归 $A^TA+\lambda I$)来「救回」可逆性——这就是正则化与奇异性直接相关的一个例子。

## Note(连接 / 深化)

- **连接**:求逆用的正是第 1 讲的**高斯-约当消元**;第 2 讲的「无消去律」在可逆矩阵上**恢复成立**(性质 4)——奇异矩阵才是破坏消去律的元凶。可逆 ⟺ 行列式 $\ne0$ ⟺ 满秩 ⟺ 唯一解,这一串等价关系会在 [[行列式]]、[[向量空间]] 两章彻底打通。
- **深化**:每个初等行变换对应左乘一个**初等矩阵**,它们都可逆;于是高斯消元 $[A|I]\to[I|A^{-1}]$ 可写成 $E_k\cdots E_2E_1 A = I$,故 $A^{-1}=E_k\cdots E_2E_1$——**「对 A 做过的行变换,原样对 I 做一遍,就得到 A 的逆」**,这就是求逆算法的本质。

## 总结

### 本讲新引入的专业术语

| 英文术语 | 中文 | 含义 |
| -------- | ---- | ---- |
| inverse (of a matrix) | 矩阵的逆 | $A^{-1}$,满足 $AA^{-1}=A^{-1}A=I$ |
| invertible / nonsingular | 可逆 / 非奇异 | 存在乘法逆 |
| singular / noninvertible | 奇异 / 不可逆 | 不存在乘法逆 |
| multiplicative inverse | 乘法逆 | 矩阵版的「倒数」 |
| adjoint / adjoin | 增广(拼接) | 把 $I$ 拼到 $A$ 右边 |
| doubly augmented matrix | 双增广矩阵 | $[A\ |\ I]$ |
| invertible matrix | 可逆矩阵 | 有逆的方阵 |
| trivial solution | 平凡解 | 全零解(第 1 讲已引入) |

**本质**:逆矩阵是「矩阵的倒数」,是**「除法」和「撤销变换」的载体**。判断与求法都归结到第 1 讲的高斯-约当消元:$[A|I]\to[I|A^{-1}]$。**可逆 ⟺ 基向量不共线(平面没被压扁)⟺ 有唯一解**;奇异 = 把平面压成低维、丢信息、不可撤销。乘积求逆要**反序**$(AB)^{-1}=B^{-1}A^{-1}$,这是「复合变换要倒着撤销」的代数体现。
