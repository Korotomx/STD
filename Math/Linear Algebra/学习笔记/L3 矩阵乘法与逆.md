# 矩阵乘法与逆 Multiplication and Inverse Matrices · 18.06 L3

**时间:** 2026-10-20
**标签:** #线性代数LinearAlgebra #矩阵乘法MatrixMultiplication #逆矩阵InverseMatrix #可逆Invertible #奇异Singular #高斯约当GaussJordan
**关联:** [[L2 消元]]（消元矩阵）· [[L4 A=LU 分解]]（乘积逆反序的应用） · [[Matrix multiplication as composition  Chapter 4, Essence of linear algebra]]（3b1b 直观）

## 必要性（为什么要有这一章）

**要解决的问题**:L2 里消元每步都靠「左乘一个 E」,但矩阵乘法到底有几种理解?以及,有没有「直接套公式」解方程的办法——像数里「除以 a」那样一步得 $x$?

**矩阵乘法的多种视角**(Strang 强调):同一个 $AB=C$ 有**四五种等价算法**,每种都重要,因为「从整体看列/看行」是后面所有证明(结合律、逆、LU)的语言。**逆矩阵**就是「矩阵的除法」:有了 $A^{-1}$,$Ax=b$ 一步变 $x=A^{-1}b$。

**意义(重点)**:
1. 逆矩阵是**判据**:可逆 ⟺ $Ax=b$ 有唯一解 ⟺ 满秩 ⟺ 行列式 $\ne0$——这串等价关系是全课主线。
2. 逆 = 线性变换的**「撤销」按钮**,在图形学/机器人/控制里无处不在。
3. 奇异矩阵的判断(尤其 **$Ax=0$ 有非零解**)是理解「信息丢失」的钥匙。

## 主要内容

### 1. 矩阵乘法的标准定义(行 × 列)

- $A(m\times n)\cdot B(n\times p)=C(m\times p)$,其中 $c_{ij}=\sum_k a_{ik}b_{kj}$ = **A 的第 i 行点乘 B 的第 j 列**。
- 形状要求:**A 的列数 = B 的行数**(中间的 n 匹配),结果是 m×p。

### 2. 矩阵乘法的四种视角(本讲核心)

同一个 $AB=C$,四种算法结果相同:

1. **行 × 列(点积)**:每个元素 $c_{ij}$ 单独算——最标准的机械算法。
2. **列视角**:$C$ 的第 j 列 = $A$ 乘 $B$ 的第 j 列。**C 的每一列都是 A 的列的线性组合**,组合系数就是 B 那一列的数字。
3. **行视角**:$C$ 的第 i 行 = $A$ 的第 i 行乘 $B$。**C 的每一行都是 B 的行的线性组合**。
4. **列 × 行(外积之和)**:$AB=\sum_k (\text{A 的第 k 列})(\text{B 的第 k 行})$——每项是一个「满秩为 1」的大矩阵,再加起来。
   - 例:$\begin{bmatrix}2\\3\\4\end{bmatrix}\begin{bmatrix}1&6\end{bmatrix}=\begin{bmatrix}2&12\\3&18\\4&24\end{bmatrix}$,各行都是 $(1,6)$ 的倍数、各列都是 $(2,3,4)$ 的倍数——**秩 1 矩阵**。

- **第五种:分块乘法(block multiplication)**——把矩阵切成块,按「块行 × 块列」乘,结果和逐元素乘一致。大矩阵 / 并行计算常用。

### 3. 矩阵的分类与乘法三「反常」性质(合并自原课程)

- **分类**:方阵(square)、上/下三角(triangular)、对角(diagonal)、单位(identity $I$)、零(zero $O$)、对称(symmetric)。
- **乘法三条反直觉性质**:
  1. **不可交换**:$AB\ne BA$ 一般成立;
  2. **有零因子**:$AB=O$ 但 $A,B$ 都可能非零;
  3. **无消去律**:$AC=BC$ 推不出 $A=B$。
- 这三条与「数的乘法」完全不同,是矩阵乘法的「性格」;根源是**信息会丢**(降秩)。

### 4. 逆矩阵:定义与唯一性

- **可逆(nonsingular / invertible)**:方阵 $A$ 存在 $B$ 使 $AB=BA=I$;否则**奇异(singular)**。
- 可逆矩阵**必须是方阵**;方阵的**左逆 = 右逆**(这是方阵特有的,矩形矩阵左右逆不同、形状都不允许)。
- **唯一性**:逆唯一,记 $A^{-1}$(证明用结合律换括号:$B=IB=(CA)B=C(AB)=CI=C$)。

### 5. 奇异矩阵的判断(Strang 最喜欢的理由)

$A=\begin{bmatrix}1&3\\2&6\end{bmatrix}$ 为什么没有逆?

- **列视角**:两列在同一方向(共线),任何组合都落在一条线上,凑不出 $I$ 的列 $(1,0)$、$(0,1)$。
- **关键方程 $Ax=0$ 有非零解**(最重要):$A\begin{bmatrix}3\\-1\end{bmatrix}=\begin{bmatrix}0\\0\end{bmatrix}$。若 $A^{-1}$ 存在,左乘得 $x=0$,矛盾。**结论:奇异 ⟺ $Ax=0$ 有非零解**——「某组合的列给出 0(信息被压掉)」。

### 6. 高斯-约当求逆

把 $I$ 拼在右边做**双增广矩阵**,行变换把左半化成 $I$,右半**自动变成 $A^{-1}$:
$$[A\ |\ I]\xrightarrow{\text{行变换}}[I\ |\ A^{-1}]$$
- 原理:所有行变换合成一个矩阵 $E$,满足 $EA=I$,故 $E=A^{-1}$;同一套 $E$ 作用在右边的 $I$ 上就得到 $A^{-1}$。
- **判据**:左半若化出全零行 → A 奇异。

### 7. 乘积的逆与 6 条性质(合并自原课程)

- **乘积逆反序**:$(AB)^{-1}=B^{-1}A^{-1}$(「先穿袜子再穿鞋,脱的时候先脱鞋再脱袜子」);推广 $(A_1\cdots A_k)^{-1}=A_k^{-1}\cdots A_1^{-1}$。
- 6 条:① $(kA)^{-1}=\frac1k A^{-1}$ ② $(A^{-1})^{-1}=A$ ③ $(A^k)^{-1}=(A^{-1})^k$ ④ 可逆矩阵上**消去律恢复成立**($PA=PB\Rightarrow A=B$) ⑤ $(A^T)^{-1}=(A^{-1})^T$ ⑥ $(AB)^{-1}=B^{-1}A^{-1}$。
- **用逆解方程**:$Ax=b$ 可逆时有唯一解 $x=A^{-1}b$。

## 直观理解（空间视角）

- **四种乘法视角 = 同一个变换的四种描述**:列视角「C 的列是 A 的列的组合」= 把 A 的列空间「搬」成 C;行视角对称;列×行 = 把矩阵拆成「一根根秩 1 的柱子」再叠加。看清这些,后面理解秩、子空间、特征值都水到渠成。
- **逆 = 变换的「撤销」**:$A$ 把平面做个变换,$A^{-1}$ 原样变回。可逆 ⟺ 基向量不共线(平面没被压扁);奇异 ⟺ 把平面压成线/点,信息丢失、不可撤销(旧课程 manim:[[可逆与奇异矩阵.mp4]] 仍适用)。
- **$Ax=0$ 有非零解 = 「有非零向量被压到原点」**:一旦如此,多个输入映射到同一个 0,逆无法「区分」它们——这是奇异性的最本质图景。
- **乘积逆反序 = 倒着撤销**:复合变换「先 A 后 B」,撤销要「先 $B^{-1}$ 再 $A^{-1}$」。
- **矩阵乘法不可交换 = 变换顺序不可颠倒**(旧课程 manim:[[矩阵乘法不可交换.mp4]] 仍适用)。

## 拓展延伸（与 AI / 计算机的关联）

- **列 × 行(秩 1 分解)是矩阵理论的万能积木**:任意矩阵 = 若干秩 1 矩阵之和,这正是 SVD(奇异值分解)、低秩近似、推荐系统(矩阵分解)、LoRA 微调背后的思想——「把大矩阵看成若干小柱子的叠加」。
- **矩阵乘法 = AI 算力核心**:神经网络 $y=Wx$ 就是矩阵乘;GPU 算力(FLOPS)基本在衡量「每秒多少次矩阵乘」,核心算子 GEMM 是 cuBLAS/oneDNN 优化到极致的那一个。分块乘法正是 GEMM 高效实现的基础。
- **转置法则 $(AB)^T=B^TA^T$ 在反向传播里无处不在**:backprop 每步都伴随权重矩阵的转置,「乘积转置要反序」是理解梯度的数学根基。
- **「可逆」是生成模型/概率模型的前提**:归一化流要求每层可逆;高斯分布密度含 $\Sigma^{-1}$(协方差求逆是卡尔曼滤波/高斯过程的核心);岭回归 $A^TA+\lambda I$ 就是为了「救回」多重共线性下 $A^TA$ 的可逆性。
- **数值上「显式求逆」是坏习惯**:工程解 $Ax=b$ 几乎从不真算 $A^{-1}$(慢且不稳),用 LU/QR 分解——但**理论上**求逆是一切闭式解的来源(如最小二乘 $x=(A^TA)^{-1}A^Tb$)。

## Note（连接 / 深化）

- **连接**:乘积逆反序 $(AB)^{-1}=B^{-1}A^{-1}$ 直接用于 [[L4 A=LU 分解]](把消元矩阵的逆按反序叠成 L);奇异 ⟺ $Ax=0$ 有非零解 ⟺ 列线性相关,会在 [[L5 转置·置换·向量空间]] 用「列空间/零空间」正式命名;满秩 ⟺ 可逆在行列式、向量空间章彻底打通。
- **深化**:四种乘法视角里,「列视角」和「行视角」对应后面两个基本子空间(列空间、行空间);「列×行(秩1)」对应秩与 SVD——这三条是理解矩阵最深的钥匙。

## 总结

### 本讲新引入的专业术语

| 英文术语 | 中文 | 含义 |
| -------- | ---- | ---- |
| dot product | 点积 | 行×列求和 |
| column picture of AB | 乘法的列视角 | C 的列 = A 的列的组合 |
| row picture of AB | 乘法的行视角 | C 的行 = B 的行的组合 |
| outer product | 外积(列×行) | 秩 1 矩阵 |
| block multiplication | 分块乘法 | 按块行×块列 |
| invertible / singular | 可逆 / 奇异 | 有逆 / 无逆 |
| multiplicative inverse | 乘法逆 | 矩阵的「倒数」 |
| Gauss-Jordan | 高斯-约当消元 | [A\|I]→[I\|A⁻¹] 求逆 |
| rank-1 matrix | 秩 1 矩阵 | 列×行得到的矩阵 |

**本质**:矩阵乘法有四五种等价视角(点积 / 列组合 / 行组合 / 列×行外积 / 分块),它们是理解后面所有概念的共同语言。逆矩阵是「除法」与「撤销」的载体,求法归结为高斯-约当 $[A|I]\to[I|A^{-1}]$;**可逆 ⟺ 列不共线 ⟺ $Ax=0$ 只有零解 ⟺ 满秩**;奇异 = 有非零向量被压到 0、信息丢失。乘积逆反序 $(AB)^{-1}=B^{-1}A^{-1}$ 是「复合变换倒着撤销」。
