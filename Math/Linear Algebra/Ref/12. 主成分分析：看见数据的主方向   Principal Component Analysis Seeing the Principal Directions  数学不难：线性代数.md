What does PCA look like geometrically?  
Why are eigenvectors the principal components of data?  
  
In this video, we present a geometric interpretation of Principal Component Analysis (PCA).  
We begin by viewing a dataset as a rotated ellipse and examine how projecting the data onto different directions produces different amounts of variance.  
  
By computing the mean, centering the data, and standardizing each feature, we obtain the covariance matrix,  
which captures the shape, orientation, and correlation structure of the data cloud.  
The eigenvalue decomposition (EVD) of this matrix reveals the principal components —  
a set of orthogonal directions along which the data variance is ordered from largest to smallest.  
  
Through ellipses, projections, and variance curves, the video shows why PCA can be understood  
as a clear geometric process:  
compute the centroid → center the data → standardize features → covariance matrix  
→ eigenvalue decomposition → rotate the axes → principal components

PCA 在几何上究竟在做什么？  
为什么特征向量就是主成分？  
  
本视频从几何角度系统讲解主成分分析（Principal Component Analysis, PCA）。  
我们将数据视为一朵“旋转的椭圆云”，并观察其在不同方向上的投影方差如何变化。  
  
通过计算质心、对数据去均值、并对特征进行标准化，  
我们得到刻画数据形状、方向与相关性的协方差矩阵（或相关系数矩阵）。  
对该矩阵进行特征值分解后，可以得到一组相互正交、并按方差大小排序的方向，  
这正是 PCA 所寻找的主成分。  
  
视频通过椭圆、投影和方差曲线，直观展示了 PCA 的完整几何流程：  
计算质心 → 去均值 → 标准化 → 协方差矩阵  
→ 特征值分解 → 坐标轴旋转 → 主成分
