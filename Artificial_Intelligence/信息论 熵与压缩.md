# 信息与熵 Information & Entropy · 3b1b「Compression is Intelligence」Part 1

**时间:** 2026-10-20 观看 · 2026-10-20 整理
**来源:** 3Blue1Brown《Reinventing Entropy》(Part 1/3，YouTube `l6DKRf-fAAM`)
**标签:** #信息论 #熵Entropy #信息Information #无损压缩 #香农Shannon #交叉熵CrossEntropy
**关联:** [[L1 深度学习基础]]（交叉熵损失）· [[N005 前向传播与损失函数]] · Part 2（交叉熵 / 蒸馏 / GZIP，待看）

## 一句话

「信息」把一个事件量化成 **-log₂p 比特**——越意外信息越多；「熵」是分布里每个符号的**平均信息量 H = -Σ p·log₂p**，物理意义是无损压缩的**理论下限**。而 LLM 预训练那句「下一 token 预测」，数学上等价于「找一个最会压缩文本的模型」——预测与压缩是同一枚硬币的两面，这就是「压缩即智能」这句话的数学出处。

## 实际情况

### 0. 为什么从「压缩」讲起：压缩即智能？

- 香农 1940s 为回答「文本能被压到多小」开创了**信息论**；他发明的这套数学，意外地成了现代机器学习的核心语言。
- 今天 LLM 预训练的目标函数是**交叉熵损失 cross-entropy loss**（做「下一 token 预测」），而「交叉熵」这个词的根就在信息论。
- 信息论的一条结论是：**预测 与 压缩 在数学上等价**。于是 LLM 预训练可以换个说法——不是在「预测下一 token」，而是在「造一个最会压缩文本的机器」。
- 「**压缩即智能**」这句口号太糙（智能定义不清），安全的说法是：**压缩的数学理论惊人地贴合人工智能**。本片是三部曲的第一部，先讲清压缩的下限，引出「信息」和「熵」两个定义。

### 1. 热身：月球机器人指令编码（前缀码）

机器人在月球上只发 4 种指令，概率**不均匀**且**彼此独立**：

| 指令 | 概率 p |
| ---- | ---- |
| up（上） | 1/2 |
| down（下） | 1/4 |
| left（左） | 1/8 |
| right（右） | 1/8 |

- **朴素编码**：4 种指令各用 2 bit（00/01/10/11），固定 2 bit/条。
- **聪明编码**：按频率给不同长度——`0`=up、`10`=down、`110`=left、`111`=right。平均长度 = 0.5×1 + 0.25×2 + 0.125×3 + 0.125×3 = **1.75 bit/条**，比 2 bit 省。
- 为什么能无歧义解码？关键约束：**没有任何一个码字是另一个码字的前缀**（否则读流时分不清边界）。这类编码叫**前缀码 prefix-free code**。
- **二叉树图**：所有二进制串画成一棵无限二叉树，每个码字「吃掉」树上自己那一整片后代空间——长度为 L 的码字正好吃掉 **2⁻ᴸ** 的概率空间。上例中 1/2、1/4、1/8、1/8 恰好把空间瓜分干净。
- ⭐ **核心洞察**：码字长度 ↔ 概率的对应关系，就是整个信息论的种子。

### 2. 完美压缩长什么样：随机噪声 → 不可压缩

- 完美压缩算法，输出应该**和随机噪声无法区分**（每位 50/50、彼此独立）。
- 随机噪声为什么不可压缩？从接收端看：一段 n bit 的压缩结果，对应 2ⁿ 个等可能的「原消息」；若想把其中一条压得更短（在图里往下移），它就会撞到别人，逼得别的好几条**往上多占一层、各多花 1 bit**——省 1 bit、亏 2 bit，像按地毯鼓包。
- 结论：**等可能的 2ⁿ 条消息，最优就是每条都给 n bit**。所以完美压缩 → 每条消息概率 = **2⁻ⁿ**。

### 3. 定义「信息」：-log₂p

- 由「完美压缩下 n bit 对应概率 2⁻ⁿ」，取 `log₂` 再取负，得到 **比特数 = -log₂p**。这个「负对数」是全信息论的基本公式。
- **直觉**：`-log₂p` 问的是「把可能性空间**砍半多少次**才能切到这件事」。
- Shannon 把它定义为**事件的信息 information**：
  - 越不可能发生（p→0）→ 信息越多（柱子越高）；
  - 越确定发生（p→1）→ 信息越少。
- 允许**小数比特**（概率不是 2 的幂次时）。信息量给出「这条消息**平均**能压到多小」的**下界**（对单条可以过拟合，但对全体消息取平均是硬下限）。

### 4. 语言的信息：上下文依赖 + 香农的实验

语言和机器人例子的两大不同：
1. **强上下文依赖**——每个新字母的概率都取决于前面所有字符（**链式法则**，概率相乘）；
2. 概率不再是 2 的幂次 → 信息是**小数比特**。

- 整条消息的信息 = 每个字母信息的**相加**（log 把乘法变加法）。
- **怎么知道每个字母的概率？** 香农当年的做法（远在语言模型之前）：
  - **n-gram**：统计「th 后面跟什么字母」→ 但长串字符在语料里根本搜不到，直接失效；
  - **妻子 Betty 猜字**：猜对记 dash、猜错写正字 → 定性说明「可预测 = 可压缩」；
  - **1950 论文《Prediction and Entropy of Printed English》**：记录「猜几次才猜对」→ 由猜测次数反推人类赋予该字母的隐式概率。
- ⭐ 香农在干的不是纯数据统计，而是**探测语言背后的模型（人脑这个黑箱）**。2020 年代，我们从「盘问黑箱」变成了「设计黑箱」——语言模型。

### 5. 定义「熵」：H = -Σ p·log₂p（无噪声编码定理）

- **熵 entropy** = 每个符号的**平均信息量** = 压缩的理论下限：

```
H = -Σᵢ pᵢ · log₂ pᵢ
```

- **可视化**：分布画成一排横条（宽度 = 概率 p，总宽 = 1），每条上面立一根高 = -log₂p 的柱子，**所有柱子总面积 = 熵**。
- **直觉**：分布越均匀 → 熵越高（不确定性大）；越偏斜（某事件独大）→ 熵越低；符号种类越多 → 熵越高。
- 命名轶事：冯·诺依曼建议叫「entropy」——一方面像统计力学里的熵，另一方面「没人真懂熵是啥，吵架时你永远占优势」（多半是段子，但有点影子）。
- **无噪声编码定理**（Shannon 1948）：任何编码都不可能比这个下限更高效，而且**总能无限逼近**这个下限。
- **熵率 entropy rate**：推广到「每个符号分布都不一样」的情形（自然语言），无法精确算，只能靠观测估计。香农估出：在有 ≥100 字符上下文时，**英语的熵约 1 bit/字符**——理论上每个字符压到只剩一个「是/否」。第三部会给出一个用高质量语言模型逼近这个极限的实际算法。
- 顺带引出 **交叉熵 cross-entropy**（熵的变体，即 LLM 训练用的那个 loss）→ **Part 2**。

## 总结

**本质：** 信息 = -log₂p（事件有多意外）；熵 = 平均信息量 -Σ p·log₂p（分布有多不确定）= 无损压缩的理论下限。二者都由「完美压缩 = 随机噪声」这一洞察反推而来，而非拍脑袋的定义。这套信息论是 LLM 预训练「交叉熵损失」的数学地基：预测下一 token = 找最优压缩，所以「压缩即智能」。
