## 环境现状

- GPU：**RTX 5060 8GB**（WSL2）· Python：`dl_env`（PyTorch 2.11 + cu128）
- **nvcc 已就绪**：CUDA **12.8.93**（`/usr/local/cuda-12.8`，默认），另装 **13.1.115** 对照；`nvidia-smi` 正常
  - 本机 Ubuntu 25.10 有两处不兼容：系统 **gcc 15** 超出 CUDA 12.8 支持 → 装 `g++-14`；**glibc 2.42** 的 C23 `cospi/sinpi/rsqrt` 与 CUDA 头文件冲突 → nvcc 加 `-U_GNU_SOURCE`
  - 已做 `~/.local/bin/nvcc` wrapper，自动加 `-ccbin g++-14 -U_GNU_SOURCE -arch=sm_120`；直接 `nvcc xxx.cu -o xxx` 即可
  - 只装 toolkit，**不要在 WSL2 里装 Linux 显卡驱动**（用 Windows 驱动 + WSL 自带的 `libcuda`，否则会坏）；`/usr/local/cuda` 默认指 12.8，与 torch cu128 对齐
  - 验收三件套：`nvidia-smi` ✅ → `nvcc --version` ✅ → hello kernel ✅（见 [[C01 Introduction]]）
- 8GB 显存：练习规模控制在 1024³ float 以内，够用且不 OOM

## 学习路线（三阶段，按周推进）

### 阶段 0 · 第 1 章 Introduction（2026-10-24 完成）

- **读**：GPU 为什么快（吞吐 vs 延迟）/ CUDA 平台 / compute capability / PTX · cubin · fatbin 是什么
- **做**：装好 toolkit，跑通第一个 kernel
- **验收**：能一句话讲清「CUDA 程序 = host 管数据搬运、device 管并行计算」；`nvcc` 与 `nvidia-smi` 都正常

### 阶段 1 · 编程模型 + 第一个 kernel（第 1 周）

- **章节**：Programming Model → The CUDA platform → Intro to CUDA C++ → Writing SIMT Kernels
- **核心**：grid / block / thread 三层索引、warp 与 SIMT、内存层次（global / shared / register）、`<<<grid, block>>>` 启动、`cudaMalloc / cudaMemcpy`、host-device 同步、错误检查、越界防护
- **项目**：① 向量加法 → ② 朴素矩阵乘 → ③ 图像灰度化（读图 → kernel → 写回）
- **验收**：能不看笔记画出线程索引的维度关系；能自己定位越界和「kernel 静默失败」

### 阶段 2 · 性能与异步（第 2 周）

- **章节**：Asynchronous Execution → Unified and System Memory → NVCC；配套性能章节（memory coalescing / shared memory / occupancy）
- **核心**：streams 重叠、事件计时、统一内存的迁移语义、编译选项（`-arch=sm_120`、`-lineinfo`）、用 `ncu` 看一个 kernel
- **项目**：④ 双线性插值 resize kernel（和 `cv2.resize` 比时间）→ ⑤ 共享内存版矩阵乘（对比朴素版加速比）
- **验收**：有一张实验表（规模 / 时间 / 加速比 / 带宽利用率），能说出「慢在哪一层」

### 阶段 3 · 落到自己的链路（第 3 周起）

- **章节**（按需选读）：CUDA Graphs / Cooperative Groups / Asynchronous Data Copies / Pipelines
- **项目**：⑥ 给 groundzero 写预处理 kernel（letterbox + 归一化 + HWC→CHW）→ ⑦（可选）后处理 kernel（NMS）或 TensorRT 自定义 plugin
- **验收**：端到端对比「CPU 预处理 vs CUDA 预处理」的延迟

> 阶段 3 不追求把 Advanced CUDA 读完：**用到哪个 feature 再翻哪一章**。

## 每日节奏（30~90 分钟）

1. **读 1 节**（20~30 min）：只抓「是什么 / 为什么这样设计 / 一句能复述的话」
2. **写代码**（20~40 min）：每章至少一个能跑的程序，不许只读不写
3. **记 1 条笔记 + 实验数据**（10 min）：时间、规模、加速比——不记数字，后面没法比较

> 原则：**不以「读完」为目标，以「跑通 + 能讲清」为目标。** 读不懂的先记问题，别死磕；CUDA 的概念要写代码才落地。

## 笔记约定

- 按章一篇，文件名 `C01 Introduction.md`、`C02 Programming Model.md`…
- 结构沿用 AI 栏目：**一句话 → 实际情况（要点 + 代码）→ 实验数据 → 相关**
- 术语中英并列；代码片段放正文，完整程序放 `Ref/` 或随笔记附代码块
- **每篇至少配 1~2 张图**：层级 / 流程优先用 **Mermaid**；线程索引、分支、内存层次等用 **PNG**（放 `attachments/`，图内标签用英文避免字体问题），并带图注
- **先对照中文图解站**：读对应章节译文 + [PDF 图版](https://okazaki-yumemi.github.io/CUDA_PROGRAMMING_GUIDE_simplified-Chinese/figures.html)的「图上内容 / 编程含义」，用自己的话写进笔记，再补本机实验数据
