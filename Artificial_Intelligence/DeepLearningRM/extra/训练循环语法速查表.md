# 训练循环语法速查表：Python / PyTorch / matplotlib

**时间:** 2026-10-18
**标签:** #语法速查 #Python #PyTorch #训练循环 #matplotlib
**关联:** [[N001 张量基础dtype-shape-device与GPU]]（`.to(DEVICE)` / `.item()` / `.shape`）· [[N002 自动求导autograd]]（`backward` / `no_grad`）· [[N015 数据加载Dataset与DataLoader]]（Dataset / DataLoader / transforms）· [[E001 matplotlib无显示环境Agg后端与中文字体]]（Agg 后端 / 字体 fallback）

> 速查表：把 `task0_basic/model_train.py` 训练循环里出现的不熟悉语法，按 **Python 通用 → PyTorch → matplotlib** 三块归类。每行给出四样：**作用 / 接收参数 / 结果 / 变体**。

## 一、Python 通用语法（和 PyTorch 无关，换任何库都这么写）

| 语法 | 作用 | 接收参数 | 结果 | 变体 |
| ---- | ---- | ---- | ---- | ---- |
| `import torch.nn as nn` | 导入模块并起短别名 | 模块名 + 别名 | `nn` 指向该模块 | `import copy`（不取别名）；`from X import Y`（只取某个名字，之后直接用 `Y`） |
| `f"...{x}..."` | 把变量/表达式嵌进字符串 | `{表达式}` 可带格式符 | 拼好的字符串 | `{epoch+1:2d}` 整数占2位；`{acc*100:5.2f}` 总宽5、2位小数；`{x:.4f}`；旧式 `"{}".format(x)` |
| `"cuda" if cond else "cpu"` | 一行选值（三元表达式） | 一个条件 | 真→`"cuda"` 假→`"cpu"` | 多行 `if/else` 语句块 |
| `def set_seed(seed=42)` | 给参数默认值，不传就用默认 | 可选 | 函数 | 按关键字传 `set_seed(seed=7)` |
| `return a, b` / `x, y = f()` | 一次返回多个值 / 一次解包接收 | — | 元组 tuple | 返回任意多个 `return a,b,c` |
| `_, preds = torch.max(...)` | `_` 表示「不关心的值」，接收后丢弃 | — | `_` 只是普通变量名 | 不接第一项：`torch.max(...)[1]` |
| `if __name__ == "__main__":` | 被 import 时不跑主逻辑，直接运行才跑 | — | — | 无（固定写法） |
| `@torch.no_grad()`（装饰器） | 把整个函数体包进 no_grad 上下文 | 一个函数 | 换皮后的函数 | `with torch.no_grad():`（02_autograd 用的写法） |
| `(preds == labels)` | 逐元素比较 | 两个同形状张量 | 布尔张量 True/False | `.sum()` 数 True 个数 → `.item()` 变 Python int |
| `list.append(x)` | 往 list 末尾加元素 | 一个元素 | `None`（原地改） | `dict[k]=v`；`.extend([..])` 一次加多个 |

## 二、PyTorch

### 张量与设备

| 语法 | 作用 | 接收参数 | 结果 | 变体 |
| ---- | ---- | ---- | ---- | ---- |
| `torch.device("cuda")` | 造一个「设备」对象 | 字符串 `"cuda"`/`"cpu"`/`"cuda:0"` | device 对象 | 直接 `x.to("cuda")` |
| `.to(DEVICE)` | 把张量/模型搬到指定设备 | device 或字符串 | 搬到那边的副本 | `.cpu()` `.cuda()` |
| `torch.max(outputs, 1)` | 沿某维取最大值 | `(张量, dim)`；dim=1 每张图内比，dim=0 跨样本 | `(values, indices)` 元组 | `torch.argmax(x, dim=1)` 只取下标；`x.max(1)` |
| `x.size(0)` | 取第 0 维大小（此处=batch数） | 维度下标 | int | `x.shape` 取整个形状 `[64,1,28,28]` |
| `x.item()` | 标量张量 → Python 数 | 无 | float/int | 只能用于 0 维张量 |
| `(preds==labels).sum()` | 对布尔张量求和（数 True） | 可 `dim=` | 0 维张量 | 接 `.item()` 得 Python 数 |

### 数据（transform / Dataset / DataLoader）

| 语法 | 作用 | 接收参数 | 结果 | 变体 |
| ---- | ---- | ---- | ---- | ---- |
| `transforms.Compose([...])` | 把多个 transform 串成流水线，按序执行 | transform 列表 | 一个可调用对象 | 单个 `transforms.ToTensor()` 直接赋给 transform |
| `transforms.ToTensor()` | PIL图/numpy → 张量；`[0,255]→[0,1]`，HWC→CHW | 无 | 张量 | `transforms.ToPILImage()` 反向 |
| `transforms.Normalize((mean,),(std,))` | `(x-mean)/std` 归一化 | mean 元组 + std 元组，每通道一个 | 归一化张量 | 彩色 3 通道写 3 个数：`((0.485,0.456,0.406),(0.229,0.224,0.225))`（ImageNet） |
| `datasets.MNIST(root=, train=, download=, transform=)` | 加载 MNIST 数据集 | root 目录 / train=True 训练集·False 测试集 / download 自动下载 / transform 预处理 | Dataset（有 `__len__`/`__getitem__`） | `datasets.CIFAR10`；自己的图用 `datasets.ImageFolder(root=)` |
| `random_split(dataset, [50000,10000])` | 把数据集随机切成几段 | 数据集 + 每段长度列表 | 若干子 Dataset | 按比例先 `len(dataset)` 算长度 |
| `DataLoader(ds, batch_size=, shuffle=, num_workers=)` | 打包 batch + 打乱 + 多进程读 | batch_size 每批数 / shuffle 每轮打乱 / num_workers 子进程数 | 可迭代对象，每次 `yield (images, labels)` | 验证集 `shuffle=False`；`drop_last=True` 丢最后不足一批的 |

### 模型

| 语法 | 作用 | 接收参数 | 结果 | 变体 |
| ---- | ---- | ---- | ---- | ---- |
| `model.train()` / `model.eval()` | 切训练/评估模式（影响 Dropout/BatchNorm） | 无 | — | LeNet 没这些层暂时无感，ResNet 有 |
| `model(images)` | 调 `forward`，即前向传播 | 输入张量 | 输出张量 `[64,10]` | 别写 `model.forward(images)`（会绕过钩子） |
| `model.parameters()` | 取所有可训练参数 | 无 | 参数迭代器（交给优化器） | `model.named_parameters()` 带名字 |
| `model.state_dict()` | 取参数字典（用于存/拷） | 无 | OrderedDict | 加载：`model.load_state_dict(torch.load(p))` |
| `model.to(DEVICE)` | 把模型搬到设备 | device | 模型本身（原地） | — |

### 训练三件套（损失 / 优化器 / 反向）

| 语法 | 作用 | 接收参数 | 结果 | 变体 |
| ---- | ---- | ---- | ---- | ---- |
| `nn.CrossEntropyLoss()` | softmax+交叉熵，输入是**原始分数**（不含softmax） | 可选 `weight=`（类不平衡时） | 损失函数对象；调用 `criterion(out,label)` 得标量 | `nn.MSELoss`（回归）、`nn.BCELoss` |
| `torch.optim.Adam(model.parameters(), lr=)` | 优化器：负责更新权重 | params 要更新的参数 / lr 学习率（还有 betas、weight_decay） | optimizer 对象 | `optim.SGD(params, lr=, momentum=)` |
| `optimizer.zero_grad()` | 清上一步残留梯度（否则累加） | 无 | — | `zero_grad(set_to_none=True)` 更省内存 |
| `optimizer.step()` | 按梯度更新权重（真正的「学」） | 无 | — | — |
| `loss.backward()` | 反向传播，自动求所有梯度 | 可 `retain_graph=True`（同一图要算两次时） | 梯度写进各参数 `.grad` | — |
| `loss.item()` | 标量损失 → Python float | 无 | float | 打印/记录用，别在计算里用它 |

### 随机种子 / 保存

| 语法 | 作用 | 接收参数 | 结果 | 变体 |
| ---- | ---- | ---- | ---- | ---- |
| `torch.manual_seed(seed)` | 固定 CPU 随机种子（可复现） | 整数 seed | — | `torch.cuda.manual_seed_all(seed)` 固定 GPU |
| `copy.deepcopy(x)` | 深拷贝（完全独立副本） | 任意对象 | 独立副本 | `copy.copy(x)` 浅拷贝（内层仍共享）；存最佳权重必须 deepcopy |
| `torch.save(obj, path)` | 序列化保存到磁盘 | 对象 + 路径 | 文件 | 存整个模型 `torch.save(model, p)`；读回 `torch.load(p)` |

| ---- | ---- | ---- | ---- | ---- |
| `matplotlib.use("Agg")` | 选无窗口后端，只存图不弹窗 | 后端名 `"Agg"` | — | 本机 xrdp 连不上必须用它 |
| `plt.rcParams["font.family"]=[...]` | 设字体及回退顺序 | 字体名列表 | — | 列表写法才会按字形 fallback（见 E001） |

| `ax.plot(x, y, "b-", label=)` | 画折线 | x, y, 格式串, 图例名 | Line 对象 | `"r-"` 红实线、`"b--"` 蓝虚线 |

## 最容易踩的点

- **`loss.item()` vs `loss`**：`loss` 是张量、还连着计算图，拿去计算会拖慢/占内存；`.item()` 摘下来变纯数字，只用来打印记录。所以统计用 `loss.item()`，`backward()` 用的是 `loss`（张量）。
- **`torch.max(x, 1)` 返回两个值**，所以用 `_, preds` 接：第一个 `_` 是最大分数本身（不需要），第二个 `preds` 是下标（=预测的数字）。
- **`state_dict()` 存的是「参数→张量」的字典，不是模型对象**：所以拷贝要 `copy.deepcopy`，保存用 `torch.save(best_wts, ...)` 而不是 `torch.save(model, ...)`（后者也能存但重、不推荐）。

## 总结

**本质：** 训练循环的语法分三层——Python 通用（import/f-string/三元/装饰器/`_` 占位/`__main__` 守卫）、PyTorch（张量设备 `.to/.item/.size/torch.max` → 数据 transforms/Dataset/DataLoader → 模型 `.train/.eval/.parameters/.state_dict` → 训练三件套 Loss/Optimizer/backward）、matplotlib（Agg 后端/字体/绘图）。每一行都可拆成「作用 / 接收参数 / 结果 / 变体」四维去记。
