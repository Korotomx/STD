## 实际情况

参考视频第四章 4.1~4.13 全部内容的收尾总结（LeNet + AlexNet 理论线）。手写笔记总图：![[DLC2.jpg]]

### 1. 一句话定位

AlexNet = **深度学习在计算机视觉里「破圈」的里程碑**——2012 年 ImageNet 大规模图像识别竞赛（ILSVRC）冠军，把 top-5 错误率从 ~26% 打到 ~15.3%，证明了「深 CNN + 大数据 + GPU」这条路走得通，从此 CV 全面转向深度学习。

### 2. 结构回顾（一条线）

- **5 卷积 + 3 全连接，共 8 层，约 6000 万参数**（连接 [[N011 AlexNet架构与各层参数]]）
- 骨架和 LeNet 一模一样：卷积提特征 → 池化压缩 → 全连接分类，只是**更深、更宽、图更大**
- 参数大头在**全连接层（~95%）**，卷积靠权值共享参数很少

### 3. 五大技术贡献（要能一句话说清）

| 技术 | 一句话作用 | 对应笔记 |
| ---- | ---- | ---- |
| **ReLU** | 缓解梯度消失、收敛更快 | [[N004 激活函数sigmoid-tanh-relu-leakyrelu]] |
| **重叠池化** | 略提精度、缓一点过拟合 | [[N010 卷积与池化的作用及对图像的侧重]] |
| **Dropout** | 随机丢神经元，抗过拟合 | [[N012 过拟合与Dropout]] |
| **数据增强** | 翻转/旋转/PCA 造样本，抗过拟合 | [[N013 数据增强图像增强与LRN]] |
| **LRN** | 通道侧抑制，提泛化（后被 BN 取代） | [[N013 数据增强图像增强与LRN]] |

一条主线：**深了 → 参数多 → 容易过拟合 → 用 Dropout + 数据增强 + LRN 顶住。**

### 4. 对任务一（ResNet + MNIST）的启示

- LeNet / AlexNet 是「经典 CNN」的地基，任务一的主角 **ResNet** 是在它们之上再加**残差连接**（第七章重点），把网络堆得更深还不退化
- AlexNet 的「数据增强抗过拟合」思路，任务一训 MNIST、任务二训 ZLLC（仅 280 张）都要用
- 下一步：从「看网络」转到「写训练」——**Dataset/DataLoader → 训练循环 → 套 ResNet**（第四章实战 4.14 起的训练模板正好复用）

### 5. 常见误区（第四章整体回顾）

- ✗ 把 LeNet/AlexNet 的「层数」数错（7 层 / 8 层）
- ✗ 以为参数大头在卷积（实际在全连接）
- ✗ 测试时还开 Dropout（要关）
- ✗ 数据增强随便翻（有方向性含义的类别要斟酌）

## 总结

**本质：** AlexNet 是 LeNet 的放大加强版（8 层 6000 万参数），2012 ImageNet 冠军点燃深度学习；核心贡献是「更深 + ReLU + Dropout + 数据增强 + LRN」的抗过拟合组合拳；它是经典 CNN 的高点，也是走向 ResNet（残差）的跳板。
