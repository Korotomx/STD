# AlexNet 架构与各层参数 · 概念原理 · N011

**时间:** 2026-10-17 20:30
**标签:** #概念原理 #AlexNet #卷积Convolution #池化Pooling #全连接FC #ReLU #特征提取
**关联:** [[N009 LeNet-5架构与各层参数]]（架构来源，AlexNet 是它的「放大加强版」）· [[N004 激活函数sigmoid-tanh-relu-leakyrelu]]（首次大规模用 ReLU）· [[N012 过拟合与Dropout]]（Dropout）· [[N013 数据增强图像增强与LRN]]（数据增强 + LRN）

## 实际情况

参考视频第四章 4.5~4.12（AlexNet 理论）。AlexNet（Krizhevsky 等，2012）拿下 ImageNet 图像分类冠军，**深度学习爆发的那一炮**。它的架构、特征提取、各层参数思路和 LeNet **完全同理，只是更大、更深、更强**。

### 1. 整体架构：5 卷积 + 3 全连接（共 8 层）

```mermaid
flowchart LR
    IN["输入 224×224×3"] --> C1["Conv1 96@55×55"] --> P1["MaxPool"]
    P1 --> C2["Conv2 256@27×27"] --> P2["MaxPool"]
    P2 --> C3["Conv3 384@13×13"] --> C4["Conv4 384@13×13"] --> C5["Conv5 256@13×13"] --> P3["MaxPool"]
    P3 --> F6["FC6 4096"] --> F7["FC7 4096"] --> F8["FC8 1000 类"]
```

和 LeNet 对比，结构骨架一模一样（卷积提特征 → 池化压缩 → 全连接分类），区别是**层更多、通道更多、图更大、类别更多**。

### 2. 各层参数表（重点：全连接才是「大头」）

| 层 | 类型 | 核/单元 | 输出 | 参数量 |
| ---- | ---- | ---- | ---- | ---- |
| 输入 | — | — | 224×224×3 | 0 |
| Conv1 | 卷积 | 96 个 11×11，s=4 | 55×55×96 | (11×11×3+1)×96 ≈ **3.5 万** |
| MaxPool1 | 最大池化 | 3×3，s=2 | 27×27×96 | 0 |
| Conv2 | 卷积 | 256 个 5×5，p=2 | 27×27×256 | (5×5×96+1)×256 ≈ **61 万** |
| MaxPool2 | 最大池化 | 3×3，s=2 | 13×13×256 | 0 |
| Conv3 | 卷积 | 384 个 3×3，p=1 | 13×13×384 | (3×3×256+1)×384 ≈ **89 万** |
| Conv4 | 卷积 | 384 个 3×3，p=1 | 13×13×384 | (3×3×384+1)×384 ≈ **133 万** |
| Conv5 | 卷积 | 256 个 3×3，p=1 | 13×13×256 | (3×3×384+1)×256 ≈ **88 万** |
| MaxPool3 | 最大池化 | 3×3，s=2 | 6×6×256 | 0 |
| FC6 | 全连接 | 9216→4096 | 4096 | (9216+1)×4096 ≈ **3775 万** |
| FC7 | 全连接 | 4096→4096 | 4096 | (4096+1)×4096 ≈ **1678 万** |
| FC8 | 全连接 | 4096→1000 | 1000 | (4096+1)×1000 ≈ **410 万** |

总参数量 ≈ **6000 万**。关键洞察：

1. **全连接层吞掉了绝大部分参数**——FC6 一层 3775 万，三个全连接加起来占总量 ~95%+
2. **卷积层参数其实很少**——因为权值共享（连接 [[N007 卷积层运算步幅填充多卷积核]]）
3. 这也是后来 VGG/ResNet 尽量「少用全连接、甚至用全局平均池化替代」的动机

### 3. 特征提取：同理但更深

和 LeNet 一样：**前端卷积逐层从边缘→纹理→形状抽象，后端全连接综合决策**（连接 [[N010 卷积与池化的作用及对图像的侧重]]）。区别只是更深更宽，能学更复杂的特征。

### 4. AlexNet 比 LeNet 强在哪（四点新东西）

| 新点 | 作用 |
| ---- | ---- |
| **ReLU** 替代 sigmoid/tanh | 缓解梯度消失、收敛更快（连接 [[N004 激活函数sigmoid-tanh-relu-leakyrelu]]） |
| **重叠池化**（3×3、s=2，窗口有重叠） | 略提精度、缓一点过拟合 |
| **Dropout**（全连接层 p=0.5） | 缓解过拟合（连接 [[N012 过拟合与Dropout]]） |
| **数据增强 + LRN** | 扩数据、通道间归一化，提泛化（连接 [[N013 数据增强图像增强与LRN]]） |

另：当年受限于 GPU 显存，用**两块 GPU 并行**（模型分半），这是工程细节，不是核心思想。

### 5. 常见误区

- ✗ 「AlexNet 只有 5 层」→ 是 **8 层**（5 卷积 + 3 全连接）
- ✗ 「参数主要花在卷积」→ 恰恰相反，**全连接才是大头**
- ✗ 把重叠池化、双 GPU 当成核心创新 → 核心是「更深 + ReLU + Dropout + 数据增强」的组合拳

（留白 —— 全连接层占了 95% 参数，那「把全连接砍掉、只留卷积」会怎样？想想为什么后面的网络要往这个方向走。）

## 总结

**本质：** AlexNet = LeNet 的「放大加强版」，5 卷积 + 3 全连接共 8 层约 6000 万参数；参数大头在全连接（~95%），卷积靠权值共享参数很少；真正的贡献是「更深 + ReLU + Dropout + 数据增强 + LRN」的组合拳，一举拿下 ImageNet 冠军、点燃深度学习。
