# 过拟合与 Dropout · 概念原理 · N012

**时间:** 2026-10-17 20:30
**标签:** #概念原理 #过拟合Overfitting #Dropout #正则化Regularization
**关联:** [[N005 前向传播与损失函数]]（训练/验证 loss）· [[N006 反向传播与梯度下降]]（训练迭代）· [[N011 AlexNet架构与各层参数]]（Dropout 首次成名）· [[N013 数据增强图像增强与LRN]]（另一类缓解过拟合的手段）

## 实际情况

参考视频第四章 AlexNet 部分。AlexNet 之所以上 Dropout + 数据增强，核心就是为了打**过拟合**。这是训练任务一（ResNet + MNIST）时一定会撞上的问题。

### 1. 什么是过拟合

模型在**训练集上表现很好、在没见过的数据（验证/测试集）上表现差**：
- 它没学会「规律」，而是**死记硬背**了训练样本（连噪声都背下来）
- 判断信号：**训练 loss 一路降，验证 loss 却反过来升**（连接 [[N005 前向传播与损失函数]] 里的「验证集」）

```
        loss
          │  验证loss ↗（过拟合发生点）
          │      ╱
          │  ___╱
          │ ╱ 训练loss ↘
          └──────────────→ epoch
```

### 2. 为什么会过拟合

1. **模型容量过大**：6000 万参数的 AlexNet 去记几千张图，游刃有余，自然「背题」
2. **数据太少**：样本不够模型学「规律」，只能学「特例」
3. **训练太久**：迭代过多，把噪声也拟合进去

### 3. 缓解手段全家桶

| 手段 | 思路 |
| ---- | ---- |
| 更多数据 | 最根本，但数据贵 |
| **数据增强** | 从已有数据「造」新样本（连接 [[N013 数据增强图像增强与LRN]]） |
| **Dropout** | 随机丢神经元，逼模型别依赖个别神经元 |
| L1/L2 正则化 / weight decay | 惩罚过大权重 |
| 早停 | 验证 loss 开始升就停 |
| BatchNorm | 稳定训练、自带一点正则（后面 ResNet 会讲） |

### 4. Dropout：训练时「随机断电」

训练时，以概率 `p` 把某一层神经元的**输出随机置 0**（丢弃），每个 mini-batch 丢的都不一样：

```
全连接层(带 Dropout, p=0.5):

  每次前向，随机一半神经元"失活"
  ┌─●─┐     ┌─○─┐   ● = 正常
  │ ● │  →  │ ● │   ○ = 被丢弃(输出置0)
  └─●─┘     └─○─┘
```

- **为什么有效**：神经元不能「指望」某个特定搭档一定在场，被迫各自学出更独立、更鲁棒的特征 → 等效于**每次训练一个「瘦身」子网络**，最终集成了一大堆子网络的共识
- **AlexNet 用法**：只在最后两个全连接层加，`p = 0.5`

### 5. 一个必须记住的坑：训练/推理行为不一致

Dropout **只在训练时开启**，推理（测试/部署）时**关闭**——否则每次都随机丢，结果不稳定：

- PyTorch 里由 `model.train()` / `model.eval()` 自动切换（任务一训练代码会碰到）
- 逻辑：训练时「丢一半」是为了逼网络学得鲁棒；测试时要用「完整网络」的力量

### 6. 常见误区

- ✗ 「Dropout 是丢弃权重」→ 是丢弃**神经元的输出**（置 0），不是删权重
- ✗ 「测试时也开着 Dropout」→ 测试要关
- ✗ 「过拟合 = 训练 loss 也高」→ 恰恰相反，过拟合时训练 loss 很低，是**验证 loss 高**

## 思考

（留白 —— 一个神经元 p=0.5 被丢，相当于 2 个神经元都「活着」时，平均每次训练只用到一半。那推理时开着/关着 Dropout，输出尺度要不要调整？想想 `model.eval()` 内部做了什么。）

## 总结

**本质：** 过拟合 = 训练好、泛化差（验证 loss 升）；根因是模型太大 / 数据太少 / 训太久；Dropout = 训练时以概率 p 随机丢神经元输出，逼网络学独立鲁棒特征、等效集成子网络，只在训练时开、测试时关（`train()`/`eval()` 控制）。
