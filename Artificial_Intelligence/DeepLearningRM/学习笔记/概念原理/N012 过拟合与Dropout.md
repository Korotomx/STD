模型在训练集上很好、在没见过的数据上变差，就是过拟合。AlexNet 时代的三件套——Dropout、数据增强、LRN——都是为它准备的；数据少时（MNIST、ZLLC 280 张）几乎绕不开。

## 过拟合的判定与成因

判断信号：**训练 loss 一路降，验证 loss 却反过来升**。

```
        loss
          │  验证loss ↗（过拟合发生点）
          │      ╱
          │  ___╱
          │ ╱ 训练loss ↘
          └──────────────→ epoch
```

三个常见成因：

1. **模型容量过大**：6000 万参数的 AlexNet 去记几千张图，游刃有余
2. **数据太少**：样本不够学「规律」，只能学「特例」
3. **训练太久**：迭代过多，把噪声也拟合进去

### 缓解手段

| 手段 | 思路 |
| ---- | ---- |
| 更多数据 | 最根本，但数据贵 |
| **数据增强** | 从已有数据「造」新样本 |
| **Dropout** | 随机丢神经元，逼模型别依赖个别神经元 |
| L1/L2 正则 / weight decay | 惩罚过大权重 |
| 早停 | 验证 loss 开始升就停 |
| BatchNorm | 稳定训练、自带一点正则（ResNet 会讲） |

## Dropout

训练时以概率 `p` 把某层神经元的**输出随机置 0**，每个 mini-batch 丢的都不一样。

```
全连接层(带 Dropout, p=0.5):

  每次前向，随机一半神经元"失活"
  ┌─●─┐     ┌─○─┐   ● = 正常
  │ ● │  →  │ ● │   ○ = 被丢弃(输出置0)
  └─●─┘     └─○─┘
```

- **为什么有效**：神经元不能「指望」某个搭档一定在场，被迫学出更独立、更鲁棒的特征 → 等效于每次训练一个「瘦身」子网络，最终集成大量子网络的共识
- **AlexNet 用法**：只在最后两个全连接层加，`p=0.5`

**训练/推理行为不一致**：Dropout 只在训练时开启，推理时关闭，否则每次随机丢、结果不稳定。PyTorch 里由 `model.train()` / `model.eval()` 自动切换；`eval()` 同时会按比例缩放输出，保持期望一致。

## 数据增强

对已有图像做**保类别**的随机变换，凭空造出「新」样本。

| 操作 | 做法 | 作用 |
| ---- | ---- | ---- |
| 水平翻转 flip | 左右镜像 | 扩样本、抗「左右依赖」 |
| 旋转 / 平移 / 缩放 / 裁剪 | 随机转角度、挪位置、放大裁 | 抗位置/角度/大小变化 |
| PCA 颜色增强（Fancy PCA） | 对训练集 RGB 做 PCA，沿主方向加扰动 | 改变颜色/光照，提升光照鲁棒性 |

PCA 颜色增强的直觉：把整批图的 RGB 当数据做 PCA，找到「颜色变化最剧烈」的方向（往往对应亮度、色调），沿这些方向随机加减一点，相当于同一张图换了几种光照。AlexNet 用它把 top-5 错误率降了 1%+。

**注意类别语义**：MNIST 的 6/9 水平翻转会变义，常用小角度旋转、平移、缩放；ZLLC 装甲板只有 280 张，翻转、HSV 抖动、随机裁剪几乎是必须的。交通标志「左/右/上/下」这类方向任务，翻转和 90° 旋转等于改标签。

## LRN（局部响应归一化）

对同一像素位置、不同通道做归一化，模拟生物神经元的「侧抑制」——响应强的压过弱的：

```
bⁱ_{x,y} = aⁱ_{x,y} / ( k + α · Σ_{j=max(0, i−n/2)}^{min(N−1, i+n/2)} (aʲ_{x,y})² )^β
```

- `aⁱ_{x,y}`：位置 (x,y) 第 i 通道的激活
- 分母 = `k` + **相邻 n 个通道**在同一位置的激活平方和，再取 `β` 次方
- AlexNet 超参数：`k=2, n=5, α=10⁻⁴, β=0.75`

作用：某通道响应特别大时把邻居压下去，形成「赢者通吃」的对比增强，小幅提泛化。后来基本被 **BatchNorm** 取代（按批归一化、加速收敛、自带正则），LRN 现在只需知道公式和「侧抑制」意图。

## 坑与边界

- ✗ 「Dropout 是丢弃权重」→ 是丢弃**神经元的输出**（置 0），不是删权重
- ✗ 「测试时也开着 Dropout」→ 测试要关（`model.eval()`）
- ✗ 「过拟合 = 训练 loss 也高」→ 过拟合时训练 loss 很低，是**验证 loss 高**
- ✗ 「水平翻转永远安全」→ 数字 6/9、文字、左右灯条等有方向语义的类别要斟酌
- ✗ 「LRN 现在还常用」→ 已被 BatchNorm 取代
- ✗ 数据增强在预处理阶段一次性生成很多张存起来 → 正确做法是训练时在线随机变换，每个 epoch 看到的都不同，也不占额外磁盘

## 总结

过拟合 = 训练好、泛化差（验证 loss 升），根因是模型太大 / 数据太少 / 训太久。Dropout 训练时以概率 p 随机丢神经元输出，等效集成子网络，只在训练时开、测试时关。数据增强对图像做保类别随机变换扩数据，是数据少时最实用的一招；LRN 做通道间侧抑制，公式 `a/(k+αΣa²)^β`，已被 BatchNorm 取代。三者都指向同一个目标：泛化。
