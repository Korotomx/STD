# 数据增强（图像增强）与 LRN · 概念原理 · N013

**时间:** 2026-10-17 20:30
**标签:** #概念原理 #数据增强DataAugmentation #图像增强 #LRN #数据集Dataset #过拟合Overfitting
**关联:** [[N012 过拟合与Dropout]]（增强是缓解过拟合的核心手段）· [[N011 AlexNet架构与各层参数]]（增强 + LRN 是 AlexNet 的成名招）· [[N001 张量基础dtype-shape-device与GPU]]（图像 = 张量）

## 实际情况

参考视频第四章 AlexNet 部分。**这一条是任务一（MNIST）乃至任务二（ZLLC 装甲板，仅 280 张）都绕不开的重点——数据是深度学习的燃料，燃料不够就靠「增强」造。** 重点讲图像增强 + LRN 的操作、公式与作用。

### 1. 数据增强（图像增强）：无中生有扩数据

**动机**：数据少 → 过拟合（连接 [[N012 过拟合与Dropout]]）。增强 = 对已有图像做**保类别**的随机变换，凭空造出「新」样本，让模型见过更多变体。

| 增强操作 | 做法 | 作用 |
| ---- | ---- | ---- |
| **水平翻转 flip** | 左右镜像 | 物体左右颠倒了仍是同一类，扩样本、抗「左右依赖」 |
| **旋转 / 平移 / 缩放 / 裁剪** | 随机转角度、挪位置、放大裁 | 抗「位置 / 角度 / 大小」变化 |
| **PCA 颜色增强（Fancy PCA）** | 对训练集 RGB 做主成分分析，沿主方向加扰动 | 改变**颜色 / 光照**，让模型对光照鲁棒 |

**PCA 颜色增强的直觉**：把整批图的 RGB 当数据做 PCA，找到「颜色变化最剧烈」的几个方向（往往对应亮度、色调），沿这些方向随机加减一点 → 相当于同一张图换了几种光照/配色。AlexNet 用它让 top-5 错误率降了 1%+。

> 对任务一的启示：MNIST 数字，**水平翻转要小心**（6 和 9、某些手写体翻转会变义），常用的是小角度旋转、平移、缩放。而对任务二 ZLLC 装甲板只有 280 张，**增强几乎是必须的**（翻转、HSV 抖动、随机裁剪等）。

### 2. LRN（局部响应归一化）：通道间「侧抑制」

LRN 对**同一像素位置、不同通道**做归一化，模拟生物神经元的「侧抑制」——响应强的压过弱的：

```
bⁱ_{x,y} = aⁱ_{x,y} / ( k + α · Σ_{j=max(0, i−n/2)}^{min(N−1, i+n/2)} (aʲ_{x,y})² )^β
```

- `aⁱ_{x,y}`：位置 (x,y) 第 i 通道的激活值
- 分母 = `k` 加上**相邻 n 个通道**在同一位置 (x,y) 的激活值平方和，再取 `β` 次方
- AlexNet 的超参数：`k=2, n=5, α=10⁻⁴, β=0.75`

**作用**：同一位置，某通道响应特别大时，会把邻居通道的响应压下去 → 形成「赢者通吃」的对比增强，小幅提泛化。

> 但 LRN 后来基本被 **BatchNorm 批归一化**取代（BN 按「批」归一化、还能加速收敛，且自带正则；后面 ResNet 会重点讲）。现在 LRN 主要是「历史名场面」，知道公式和「侧抑制」意图即可。

### 3. 增强 vs LRN：都是「让模型更鲁棒」

- **数据增强**：在**数据侧**动手——喂更多变体，让模型「见多识广」
- **LRN**：在**特征侧**动手——让响应有对比、更分明

两者（再加 Dropout）都是 AlexNet 时代「深网络还不够多数据」时顶过拟合的组合拳，本质都指向同一个目标：**泛化**。

### 4. 常见误区

- ✗ 「数据增强只是把图随机改改，没用」→ 它是**缓解过拟合最实用的一招**，尤其数据少时
- ✗ 「水平翻转永远安全」→ 有方向性含义的类别（数字 6/9、文字、装甲板左右灯条）要斟酌
- ✗ 「LRN 现在还常用」→ 已被 BatchNorm 取代，属历史方法
- ✗ 记公式只记字母 → 记住分母是「相邻通道 + 平方和 + k」再开 β 次方

## 总结

**本质：** 数据增强 = 对训练图像做保类别随机变换（水平翻转 / 旋转平移缩放 / PCA 颜色扰动）无中生有扩数据、抗过拟合——数据少时（ZLLC 仅 280 张）几乎是必须；LRN = 通道间侧抑制归一化，公式 `a/(k+αΣa²)^β`，增强响应对比，后被 BatchNorm 取代。
