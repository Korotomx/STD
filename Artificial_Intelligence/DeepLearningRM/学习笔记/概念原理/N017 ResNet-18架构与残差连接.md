ResNet 用残差连接解决「网络越深反而越差」的退化问题。任务一从零搭 ResNet-18（11,172,810 参数），MNIST 最佳验证准确率 99.14%。

## 要解决的问题：退化 + 梯度消失

直觉以为越深越好，实验发现单纯堆层，深了反而**在训练集上都变差**（不是过拟合，叫「退化」）。根源是**梯度消失**：反向传播时梯度一层层传回，越传越弱，前面几层几乎学不动。

## 残差连接

让每块不学完整映射 H(x)，而是学**残差** F(x)：

```
H(x) = F(x) + x        # x 是输入，原样抄过来加在结果上
```

两个作用：

1. **深了不会变差**：若这几层没用，网络让 F(x)→0 即可，块退化成恒等 x，最坏「白加一层」
2. **梯度有高速公路**：反向时梯度沿 +x 这条短路直接传回、不衰减

## BasicBlock

```python
def forward(self, x):
    identity = x                       # 先抄一份
    out = self.relu(self.bn1(self.conv1(x)))
    out = self.bn2(self.conv2(out))
    out += self.shortcut(identity)     # F(x) + x
    out = self.relu(out)
    return out
```

- 两条 3×3 卷积 + BN + ReLU，`F(x) = conv2(bn(relu(conv1(x))))`
- 加完残差**再**过最后一个 ReLU
- `bias=False`：卷积后紧跟 BatchNorm，偏置被 BN 吸收

### shortcut 的维度匹配

`F(x)+x` 要求两边形状一致，但 stage 之间通道翻倍、尺寸减半：

| 情况 | shortcut 做什么 |
| ---- | ---- |
| stride=1 且通道不变 | 恒等（x 原样） |
| stride≠1 或通道变 | 1×1 卷积（改通道 + 改尺寸） |

例（layer2 第一个块）：输入 `[64,64,28,28]` → F(x) 路径 stride=2 变成 `[64,128,14,14]`，identity 还是 `[64,64,28,28]`，shortcut 用 1×1 卷积 stride=2 对齐后再相加。

## 四个 stage

| stage | 通道 | stride | 尺寸 | block 数 |
| ---- | ---- | ---- | ---- | ---- |
| stem(conv1) | 1→64 | 1 | 28×28 | — |
| layer1 | 64→64 | 1 | 28×28 | 2 |
| layer2 | 64→128 | 2 | 14×14 | 2 |
| layer3 | 128→256 | 2 | 7×7 | 2 |
| layer4 | 256→512 | 2 | 4×4 | 2 |

「18」= 1(stem) + 8 块×2 层卷积(16) + 1(fc)。**ResNet-34 = 每层 block 数 [2,2,2,2] 换成 [3,4,6,3]**，其它不动。

## MNIST 适配

标准 ResNet 给 ImageNet（3 通道 224×224）设计：stem 7×7 stride=2 + maxpool。MNIST 只有 1 通道 28×28，照原样会一下压没。改三点：

1. 输入通道 3 → **1**
2. stem 7×7 stride=2 → **3×3 stride=1**
3. 去掉 **maxpool**

## 实测

train_acc 到 99.46%，val_acc 在 98.4~99.1 之间走平——1117 万参数记 5 万张手写数字，容量过剩，轻微过拟合。最佳验证准确率取「验证集最高」那轮（99.14%，第 9 轮），不是最后一轮。

## 坑与边界

- 「退化」和「过拟合」是两码事：退化是训练集都变差，过拟合是训练集好、验证集差。
- shortcut 只在形状不一致时用 1×1 卷积；全部加会白白增加参数。
- 残差相加后还要过一次 ReLU，漏了等于少半层非线性。
- MNIST 上不必迷信 ImageNet 的 stem 配置，输入太小会直接被 stride/maxpool 压没。

## 总结

ResNet 用 `F(x)+x` 解决深层退化和梯度消失：网络学残差、深了不退化、梯度有短路。BasicBlock = 两条 3×3 卷积 + shortcut（形状对不上时 1×1 卷积对齐）；四个 stage 通道翻倍、尺寸减半；ResNet-18 是 [2,2,2,2] 块，换成 [3,4,6,3] 即 ResNet-34。
