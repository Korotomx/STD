# 训练循环：把模型、数据、损失、优化器串起来跑 · 功能实现 · N016

**时间:** 2026-10-18
**标签:** #功能实现 #训练循环 #损失函数Loss #优化器Optimizer #epoch #梯度Gradient #反向传播Backprop
**关联:** [[N002 自动求导autograd]]（backward 求梯度）· [[N015 数据加载Dataset与DataLoader]]（数据从哪来）· [[N005 前向传播与损失函数]]（loss 怎么算）· [[N006 反向传播与梯度下降]]（反向 + 更新）

## 实际情况

对应代码 `task0_basic/model_train.py`（LeNet 教学版）和 `task1_resnet_mnist/train_resnet.py`（ResNet 任务一正式版），本机实测跑通（LeNet 98.40% / ResNet 99.14%）。

### 1. 训练 = 一个五步闭环

把前面学的张量(N001)、自动求导(N002)、数据(N015)、损失(N005)、反向(N006)全部串起来，每喂一批图重复一次：

```
① optimizer.zero_grad()   清空上一步残留的梯度
② outputs = model(images) 前向：算出预测
③ loss = criterion(outputs, labels)  算损失：错得有多离谱
④ loss.backward()         反向：自动求每个权重的梯度
⑤ optimizer.step()        更新：按梯度把权重往 loss 变小的方向挪一步
```

对应代码（`train_one_epoch` 里的一轮）：

```python
for images, labels in loader:
    images, labels = images.to(DEVICE), labels.to(DEVICE)
    optimizer.zero_grad()               # ①
    outputs = model(images)             # ②
    loss = criterion(outputs, labels)   # ③
    loss.backward()                     # ④
    optimizer.step()                    # ⑤
```

五步顺序不能乱：不清零梯度会累加（N002 第 5 节）；先 forward 才有 loss 可 backward；backward 算出梯度后 step 才更新。

### 2. 损失函数 CrossEntropyLoss

- 输入是网络的**原始分数**（logits），所以网络最后一层**不加 softmax**
- 内部自动做 softmax + 交叉熵，返回一个标量 loss
- 任务一用它做 10 分类；`loss.item()` 把标量张量摘成 Python float 用于打印统计

### 3. 优化器 Adam

`optimizer.step()` 这行真正改权重，执行 `权重 = 权重 - 学习率 × 梯度`：
- `lr=0.001` 学习率 = 每步挪多大（**超参数**，需人工定，太大发散、太小学得慢）
- Adam 给每个参数自适应步长 + 动量，新手默认用它几乎不踩坑
- `optimizer.zero_grad()` 每轮必须调，否则 `.grad` 累加发散

### 4. epoch 与 batch 的关系

| 概念 | 含义 | 本实验 |
| ---- | ---- | ---- |
| batch | 一次喂进网络的图数 | 64 |
| 一个 epoch | 把 50000 张训练图完整看一遍 | 50000/64 ≈ 782 个 batch |
| 10 epoch | 完整看 10 遍 | 7820 次更新 |

一遍不够——网络要反复看同一批数据，才能把参数慢慢调到位。

### 5. 训练 vs 验证：三个开关

- `model.train()` / `model.eval()`：切模式（影响 Dropout/BatchNorm，LeNet 无感、ResNet 有感）
- `@torch.no_grad()`：验证只前向不算梯度，省显存更快（N002 第 6 节）
- 验证集不参与更新，只看「没见过的数据上表现如何」→ 防过拟合（N012）

### 6. 记 loss/acc 曲线 + 存最佳权重（评分点）

- 每个 epoch 记录 `train_loss / train_acc / val_loss / val_acc`，最后画两条曲线（「可视化」评分点）
- 存「验证集最高」那版权重 `best_wts = copy.deepcopy(model.state_dict())`——防训练后期过拟合导致 val 反而变差
- `set_seed(42)` 固定随机种子，保证可复现（「训练可复现」评分点）

## 总结

**本质：** 训练 = 反复执行「清梯度 → 前向 → 算 loss → 反向 → 更新」五步闭环；CrossEntropyLoss 吃原始分数、内部做 softmax；Adam 按 `权重-lr×梯度` 更新；epoch 是「完整看一遍训练集」；训练用 train()+backward、验证用 eval()+no_grad；记曲线 + 存最佳权重 + 固定种子，对应任务一的「准确率+可视化」「训练可复现」评分点。
