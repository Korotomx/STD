前馈网络是“失忆的专家”：只看当前输入，没有时间概念。给状态加一个**回响 echo**项（当前状态 = 前馈项 + 过去状态的回响）就得到 RNN；“回响用什么函数”依次推出 **vanilla RNN（健忘）→ 泄漏积分（自然界的默认）→ 门控记忆（GRU/LSTM）**。

> 原文：[[Most AI has amnesia. Here's the fix]]（Artem Kirsanov）

## 前馈网络没有时间

AlexNet 一次只看一帧，把电影的所有帧随机打乱，它毫无察觉。每个输入完全独立，像重度逆行性失忆的专家：能说出图里是什么，图一消失就全忘。人脑看视频则是当前帧被前一帧塑造。给机器装上记忆，就是 RNN 的动机。

## 前馈网络的一条方程

神经元是“证据加权器”：输入 × 权重 → 求和 → 内部状态，再用激活函数 σ 转成输出。一层打包成向量 `h`，层间用权重矩阵 `W` 连接：

```
h_L = W_L · σ(h_{L-1})     # fire(σ) and project(W)
```

这是前馈网络的基本公式：静态、单向、无记忆。

## 加回响：vanilla RNN

让状态带上过去的回响：

```
h_t = W_in · σ(x_t) + M(h_{t-1})
```

最自然的选择是照抄前馈的“fire and project”，只换一组递归权重：

```
M(h_{t-1}) = W_rec · σ(h_{t-1})
h_t = W_in · σ(x_t) + W_rec · σ(h_{t-1})
```

这就是 vanilla RNN，但**记不住长程依赖**。

## 为什么 vanilla RNN 健忘

信息沿时间轴每走一步，就过一次 σ、乘一次 `W_rec`，被改写一次；走 100 步就被改写 100 次，像电话游戏里每个人不是复述而是改写。

根源在于 `M` 抄自前馈路径，而前馈路径天生为了**丢信息**：把千姿百态的猫压成同一个输出。**前馈 = 压缩，不是保存。**

要跨时间可靠地存信息，需要一条**信息能原样流过、只做受控修改**的通路。视觉网络里的对应物是**残差连接**：绕过层变换的直达捷径。vanilla RNN 缺的正是“跨时间的残差”。

## 泄漏积分：α 旋钮

最简单的保存型回响是只保留上一状态的 α 比例：

```
h_t = W_in · σ(x_t) + α · h_{t-1}
```

- `α = 0`：回响消失，退回失忆的前馈网络。
- `α = 1`：状态完全保留、新输入往上叠，等价于残差连接。但展开后是“所有历史输入的运行总和”：什么都不丢，也什么都翻不出来。这是囤积，不是记忆。
- `0 < α < 1`：近期输入强、旧输入指数衰减，像一个**漏水桶**。

漏水桶正是自然界最爱的记忆机制：神经元膜电压就是突触输入充电、离子通道漏电，计算神经科学里的**泄漏积分-放电神经元 leaky integrate-and-fire** 就是这条方程。但单个 α 不够：一个角色名要记一整部电影，而每一帧的取景细节下一秒就没用。

## 门控记忆：LSTM / GRU

把标量 α 换成**每个神经元一个、每步按上下文重算**的门控向量：

```
h_t = W_in · σ(x_t) + f(t) ⊙ h_{t-1}
f(t) = σ(W_f · [x_t, h_{t-1}] + b_f)     # 门 = 一个小 sigmoid 网络
```

遗忘门同时看当前状态和新输入，为每个神经元输出 0~1：门≈1 时状态原样通过，门≈0 时旧值被擦掉、给新信息腾地方。这种**按上下文的选择性遗忘**就是门控 RNN 的核心。

- **GRU**：遗忘门 + 互补的更新门。
- **LSTM**：用两个状态向量，把“cell state（知道什么）”和“hidden state（对外输出什么）”分开。

工程细节不同，核心都是**回响上的自适应阀门**。与 6.S191 的对应见 [[L2 循环神经网络与Transformer]]。

## 总结

RNN 全家桶只是“回响用什么函数”的三种回答：照抄前馈的 fire-and-project → vanilla RNN（健忘，因为前馈路径在压缩信息）；固定标量衰减 → 泄漏积分（自然界的漏水桶，但无法选择该记什么）；按上下文学习的逐神经元门 → GRU/LSTM（选择性遗忘，能学长程依赖）。
