信息把一个事件量化为 **-log₂p 比特**，熵是分布的平均信息量 **H = -Σ p·log₂p**，等于无损压缩的理论下限。LLM 预训练的“下一 token 预测”数学上等价于“找最会压缩文本的模型”，这是“压缩即智能”的出处。

## 前缀码：月球机器人

机器人只发 4 种指令，概率不均匀且彼此独立：

| 指令 | 概率 p |
| --- | --- |
| up | 1/2 |
| down | 1/4 |
| left | 1/8 |
| right | 1/8 |

- 朴素编码：每种 2 bit，固定 2 bit/条。
- 聪明编码：`0`=up、`10`=down、`110`=left、`111`=right。平均长度 = 0.5×1 + 0.25×2 + 0.125×3 + 0.125×3 = **1.75 bit/条**。
- 能无歧义解码的约束是**没有任何码字是另一个码字的前缀**，即**前缀码 prefix-free code**。

把所有二进制串画成无限二叉树，每个码字吃掉自己那一整片后代空间：长度 `L` 的码字正好占 **2⁻ᴸ** 的概率空间。上例的 1/2、1/4、1/8、1/8 恰好把空间瓜分完。码字长度与概率的这层对应，是整个信息论的种子。

## 完美压缩 = 随机噪声

完美压缩的输出应与随机噪声无法区分：每位 50/50、彼此独立。从接收端看，`n` bit 的压缩结果对应 `2ⁿ` 个等可能原消息；把其中一条压得更短，就会撞到别人，逼其他消息各多花 1 bit。省 1 bit 亏 2 bit，像按地毯鼓包。所以等可能的 `2ⁿ` 条消息，最优就是每条 `n` bit；完美压缩要求每条消息概率 = **2⁻ⁿ**。

## 信息 = -log₂p

由“n bit ↔ 概率 2⁻ⁿ”取 log 再取负，得到 **比特数 = -log₂p**。它问的是“把可能性空间砍半多少次才能切到这件事”。

Shannon 把它定义为事件的**信息**：

- 越不可能（p→0）→ 信息越多；
- 越确定（p→1）→ 信息越少。

允许小数比特（概率不是 2 的幂时）。信息量给出“这条消息平均能压到多小”的下界：对单条消息可以过拟合，对全体消息取平均是硬下限。

## 语言的信息

语言与机器人例子的两个区别：

1. **强上下文依赖**：每个新字母的概率取决于前面所有字符，概率按链式法则相乘；
2. 概率不是 2 的幂，信息是小数比特。

整条消息的信息 = 每个字母信息相加。香农当年如何得到字母概率：

- **n-gram**：统计“th 后面跟什么”，但长串在语料里搜不到，直接失效；
- **妻子 Betty 猜字**：猜对记 dash、猜错记正字，定性说明“可预测 = 可压缩”；
- **1950 论文《Prediction and Entropy of Printed English》**：由“猜几次才猜对”反推人类赋予该字母的隐式概率。

这实际上是在探测语言背后的模型（人脑这个黑箱）；今天的语言模型则是主动设计这个黑箱。

## 熵

**熵**是每个符号的平均信息量，也是压缩的理论下限：

```
H = -Σᵢ pᵢ · log₂ pᵢ
```

可视化：把分布画成一排宽度为 `p`、总宽为 1 的横条，每条上立一根高 `-log₂p` 的柱子；**所有柱子总面积 = 熵**。

- 分布越均匀，熵越高；越偏斜，熵越低；符号种类越多，熵越高。
- **无噪声编码定理**（Shannon 1948）：没有编码能比这个下限更高效，而且总能无限逼近。
- **熵率 entropy rate**：推广到每个符号分布都不同的情形（自然语言），只能估计。香农估计，在 ≥100 字符上下文时**英语约 1 bit/字符**，理论上每个字符可压到只剩一个是/否。

## 与 LLM 的关系

LLM 预训练用的**交叉熵损失 cross-entropy** 正是熵的变体：预测下一 token 越准，编码这段文本所需 bit 越少。预测与压缩是同一件事，Part 2 展开交叉熵、蒸馏与 GZIP，Part 3 给出逼近 1 bit/字符的压缩算法。

## 总结

信息 = `-log₂p`（事件有多意外），熵 = `-Σ p log₂p`（分布有多不确定）= 无损压缩下限。两者都由“完美压缩 = 随机噪声”反推而来。预测下一 token 就是找最优压缩，所以压缩的数学理论与人工智能高度贴合。
