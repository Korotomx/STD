量化把每个参数从 16 bit 压到 8/4 bit：70B 模型从 140 GB 降到 70/35 GB，代价是数值分辨率。实现上按层选范围、映射到离散档位；部署时在 PTQ（训练后量化）和 QAT（训练中模拟量化）之间选。

## 为什么值得做

- 显存账本：`参数量 × 每参数字节`。70B × 2 B = 140 GB，超过多数单卡；INT8 → 70 GB，INT4 → 35 GB。
- 推理还要放激活和 KV cache，权重之外仍有开销；权重越小，留给上下文和并发的空间越大。
- 带宽也是瓶颈：每生成一个 token 都要把权重从显存搬一遍，位数减半约等于访存减半，延迟常明显下降。
- 训练和推理不是一回事：训练要梯度、优化器状态、master weights，量化主要发生在推理部署；QAT 是例外。

| 格式 | 字节/参数 | 70B 权重 | 相对 FP16 |
| ---- | ---- | ---- | ---- |
| FP16 / BF16 | 2 | 140 GB | 1× |
| FP8 | 1 | 70 GB | 2× |
| INT8 | 1 | 70 GB | 2× |
| INT4 | 0.5 | 35 GB | 4× |

## 格式与精度

| 格式 | 特点 |
| ---- | ---- |
| FP16 / BF16 | 2 字节，通常不做校准，作为 baseline |
| FP8 | 1 字节，保留指数位、动态范围好；较新的 GPU 支持 |
| INT8 | 1 字节，256 个均匀档位；需要校准集定 scale，精度通常接近原模型 |
| INT4 | 0.5 字节，16 个档位；常见 weight-only，精度风险最大 |

- 模型名常直接写精度：`...-FP8` 表示权重 FP8；`...-W8A16` 表示权重 8 bit、激活仍 16 bit，别把两者混为一谈。
- 口语把 FP16 也叫量化，但严格说「降精度」是换浮点格式，INT8/INT4 才是定点量化；浮点结构、INT8 映射公式和校准细节见 [[N027 数值精度与量化 FP32-FP16-BF16-TF32-INT8]]。
- 视频的经验值：INT8 多数模型保持精度、延迟明显改善；INT4 风险更大，但映射做得好仍可接近原模型，精度通常保持在 90% 以上，损失在 0.1%–1% 量级。
- 不能只砍位：浮点数由 sign / exponent / mantissa 组成，砍错段会变成另一个数；所以需要 scale + round 的完整映射流程。

## PTQ vs QAT

| | PTQ | QAT |
| ---- | ---- | ---- |
| 时机 | 训练后 | 训练中 |
| 做法 | 校准集统计范围 → 定 scale → 量化 | 前向模拟低精度（fake quant），反向用 STE |
| 成本 | 低，最常用 | 高，要重新训练或微调 |
| INT8 | 通常够 | 通常够 |
| INT4 | 可能掉点 | 更稳 |

- PTQ 的校准集要覆盖真实输入分布；分布偏移会让 scale 失准。
- QAT 让模型在训练时就适应 rounding，激进量化（INT4）更可靠。

## 部署时怎么选

1. 先跑 FP16 baseline，记录 accuracy / latency / memory。
2. 显存或延迟不够 → FP8/INT8 PTQ；优先 weight-only 或 per-channel。
3. 还不够 → INT4（weight-only / group-wise），必须跑任务指标，不只看 perplexity。
4. 精度敏感且能重训 → QAT；否则回退 INT8。
5. 分开看权重、激活、KV cache：长上下文时 KV cache 量化收益很大；TensorRT 的 INT8 校准见 [[TensorRT 部署学习路径]]。

## 术语

| 英文 | 中文 | 含义 |
| ---- | ---- | ---- |
| quantization | 量化 | 把连续数值存成更少比特的离散档位 |
| post-training quantization (PTQ) | 训练后量化 | 训练完再压缩，靠校准集定 scale |
| quantization-aware training (QAT) | 量化感知训练 | 训练中模拟低精度，让模型适应误差 |
| calibration | 校准 | 用一批真实输入统计每层的数值范围 |
| scale | 缩放因子 | 原始浮点与整数档位之间的换算比例 |
| zero-point | 零点 | 非对称量化中整数 0 对应的浮点值 |
| weight-only quantization | 仅权重量化 | 只压权重，激活仍用 FP16；INT4 常用 |
| activation | 激活 | 前向传播中的中间张量，也可量化 |
| KV cache | 键值缓存 | 自回归推理缓存的 K/V，长上下文时占显存大头 |

## 总结

量化 = 用更少比特存数，按层把浮点范围映射到离散档位；70B 模型 FP16 140 GB → INT8 70 GB → INT4 35 GB。INT8 通常精度损失小、收益稳；INT4 更省但需要更细的 scale/分组或 QAT。PTQ 快、QAT 稳，选择取决于目标精度和是否还能训练。
