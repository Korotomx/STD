这门课刻意不提供现成框架，而是让每个开发者自己迭代出一套**七阶段流程**；核心动作是让编码代理在实现阶段**离线跑**，人同时去做规划、原型和调研。

## 立场：不要直接套别人的框架

- 作者点名反对 GSD、Spec Kit、BMAD 这类“围绕 AI 编码代理搭的复杂框架”。
- 理由：**开发者应当掌控自己的流程**，流程要能迭代、能长成自己的方法。
- 方法的地基是真实工程技能——三十年行业积累的启发式，课程里会引用实体书和资深开发者的建议。

## 七阶段流程

转录里明确点名的环节：

1. 需求分析 / 技术调研
2. 原型开发
3. 写推进项目所需的文档
4. 文档转成任务
5. 执行任务
6. 成果复盘

> 他说“七阶段”但只点名了六个，第七个在后面的课里补，这里不做推测。

## 核心原则：AFK

- **实现阶段完全离线**，离开键盘。
- 常见误区是一路盯着代理干活，“太烦人了”；正确做法是并行做别的事。
- 前提条件：代理在优质代码库里表现最好——想让代理稳定产出，得先把代码库弄健康。

## 练习形式

- 官方 playground 约 **2 万行**，TypeScript + Node + React；不需要精通这些技术。
- 也可以把练习套到自己的仓库（技术支持更少，适合有把握的人）。
- 课程目标：结束时能把**任何 CLI 编码代理**封装进自己的流程。

## 环境搭建（第 3 集）

```bash
git clone <ai-hero cohort-04 仓库>
node -v                 # 用 LTS，当前 22 或 24
corepack enable         # 装 pnpm（比 npm 快、省磁盘）
pnpm -v
pnpm install
pnpm db:seed            # 初始化本地数据库
pnpm dev                # 起本地站点，端口约 575x
```

- 数据库里有：用户、分类、测验、选课、课程进度、答题记录、观看事件。
- 代理用 Claude Code，但课程内容适用于任何基于 CLI 的代理；首次要登录并信任文件夹。
- 第 2 集是 Discord 使用说明，没有技术内容，可跳过。

## 一个反直觉的设计

课程**故意不让你先熟悉代码库**：别用肉眼看，让代理去读。探索陌生代码库本身是要教的能力，不是课前作业。

## 术语

| 词 | 含义 |
