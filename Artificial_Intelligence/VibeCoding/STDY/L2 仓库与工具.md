三条命令管分支，五个操作管上下文。

## 仓库三命令

| 命令 | 作用 | 保留你的改动 |
|---|---|---|
| `pnpm reset` | 整个分支重置到课程某个提交 | 否，破坏性 |
| `pnpm cherry-pick` | 叠加一课的提交 | 是 |
| `pnpm pull` | 拉上游 main 的更新 | 是 |

- reset 在 `main` 上会要求新建分支（课程用 `dev`）。
- cherry-pick 冲突：让 Claude 修，或 `git cherry-pick --abort` 放弃，自己的工作还在。
- pull 冲突同样交给 Claude。

## 操作技巧

- `@路径`：补全、Tab 选中、可连加多个，内容自动进上下文。
- `Ctrl+S`：暂存写了一半的提示词，先做别的，回来提交时自动恢复；`Ctrl+C` 丢弃。
- 粘贴图片：模型能看图；WSL 当时不支持。
- `/ide`：查 IDE 连接；连上后 diff 在编辑器里并排、可接受或拒绝，否则只有终端文本 diff。
- `!命令`：直接执行，输出进上下文。
- `Ctrl+B`：长任务转后台，`x` 停止。
- `Ctrl+Z` / `fg`：挂起 Claude，跑完命令再恢复。

选择：想让它看到结果 → `!`；长时间跑 → `Ctrl+B`；完全不想让它知道 → `Ctrl+Z`。
