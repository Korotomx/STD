几个不写在文档首页、但明显提高效率的操作：`@` 引用文件、`Ctrl+S` 暂存提示词、`!` 进 bash 模式、`Ctrl+B` 转后台、`Ctrl+Z` 暂停。

## @ 引用文件

- 输入 `@`，接着打路径，上下键补全，Tab 选中；可以连续加多个文件。
- 系统会把文件内容直接读进上下文，不用再说"请先读一下 xxx"。
- 一次加载稍慢，但比让模型自己翻代码库便宜得多。

## Ctrl+S 暂存提示词

长提示词写到一半，发现得先补充别的东西：

1. `Ctrl+S` 把当前输入暂存；
2. 先提交别的命令；
3. 处理完再提交时，暂存内容自动恢复。

不想要了就 `Ctrl+C` 丢掉。

## 粘贴图片

- 剪贴板里的图可以直接粘贴进对话，模型能看图（作者用它猜照片拍摄地点）。
- 作者的 WSL 环境当时不支持，Windows 下正常。

## IDE 集成

- `/ide` 查看连接状态；IDE 没装 Claude 扩展时会提示安装。
- 连上之后 diff 在编辑器里并排显示，可以逐块接受或整文件保存；没连时只能在终端看文本 diff。
- 这就是"VS Code 里跑 Claude"和"纯终端跑 Claude"最实质的差别。

## bash 模式与后台任务

- 行首 `!` 直接执行命令，输出进入上下文。例：`!npm run typecheck`，报错当场让 Claude 修。
- 正在跑的命令按 `Ctrl+B` 转后台，输出存到本地文件；下箭头查看、`x` 停止。
- 适合 dev server 这类长任务：Claude 能读日志，也能自己发 curl 请求验证。
- `Ctrl+Z` 把 Claude Code 挂起（shell 的 job control），期间随便跑命令、结果不进上下文；`fg` 恢复。

## 选择依据

| 想让 Claude 看到结果 | `!命令` |
|---|---|
| 长任务、需要边跑边看 | `Ctrl+B` |
| 完全不想让它知道 | `Ctrl+Z` + `fg` |
