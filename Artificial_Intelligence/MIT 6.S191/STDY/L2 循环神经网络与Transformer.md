序列数据（文本、音频、视频、时间序列）里“当前”依赖“过去”。RNN 用内部状态 `h` 把历史带下去，但存在编码瓶颈且串行慢；Transformer 用**注意力**一次看全序列、挑出重要部分，既并行又能处理长程依赖。

## 序列建模

前向网络处理的是一次性输入；序列在时间上展开。只给球当前的位置猜下一步是瞎猜，给一串历史轨迹才能预测。

| 形态 | 例子 |
| --- | --- |
| 多 → 一（分类） | 一条推文 → 情感标签 |
| 一 → 多（生成） | 一张图 → 描述文字 |
| 多 → 多（翻译） | 英文句 → 中文句 |

## RNN：内部状态即记忆

前向网络按时间步反复套用时，各时间步互相隔离。RNN 引入内部状态 `h_t`，把上一次计算的结果接回下一次：

```
h_t = f(h_{t-1}, x_t)        # 当前状态 = f(过去记忆, 当前输入)
ŷ_t = g(h_t)                 # 用当前状态做预测
```

关键：**同一个网络、同一套权重**，不是每个时间步一个新网络。展开后就是 L1 的“乘权重 + 加和 + 过非线性”用两次：

```
h_t = tanh(W_h · h_{t-1} + W_x · x_t + b)   # 状态更新
ŷ_t = W_y · h_t                              # 输出
```

`W_h`、`W_x`、`W_y` 都要学；每个时间步**复用同一套权重**，记忆才能累积；损失 = 各时间步损失之和。**next-word prediction** 是所有语言模型的底层任务：逐词过 RNN、更新状态，最后一个词后取输出预测下一个词。

## 序列数据的四个设计准则

1. **数值化**：one-hot 简单但捕捉不到语义；**embedding** 把语义相近的词映到更近的位置。
2. **变长序列**：前向网络输入维度固定，RNN 逐时间步处理天然适配。
3. **长程依赖**：句首信息可能影响句尾预测。
4. **顺序敏感**：RNN 逐步处理，天然保留词序。

## 训练：BPTT 与两个坑

训练用反向传播的时序版 **BPTT**：误差从当前时间步一路传回时间步 0。问题出在反复乘 `W_h`：

- **梯度爆炸**：`|W_h|` 大 → 梯度暴涨。解法是**梯度裁剪 clip**。
- **梯度消失**：`|W_h|` 小 → 梯度趋近 0 → 只学得到短程依赖，越往前的信息消失越厉害。

**LSTM** 就是为解决“如何控制状态更新、留住长程信息”而生的，把内部计算改复杂以控制信息流。

## RNN 的三个瓶颈

1. **编码瓶颈**：所有历史都塞进固定大小的 `h_t`，序列越长越挤。
2. **串行**：必须一步步处理，无法并行。
3. **长记忆差**：梯度消失导致长程依赖抓不住。

把整条序列拼成超长向量喂前向网络也不行：网络爆炸式变大、丢失顺序、无法挑重点。于是有了注意力。

## 注意力：Query / Key / Value

用 YouTube 搜索类比：

- **Query**：想找什么，如 “deep learning”；
- **Key**：每个条目的标签，如视频标题；
- **Value**：条目本身，即视频。

流程：算 query 与每个 key 的相似度 → softmax 成 0~1 权重 → 加权提取 value。self-attention 的计算：

```
1. 位置编码 positional embedding：喂整条序列，同时保留词的位置
2. 用三个可学习的层把同一份 embedding 变换成 Q、K、V
3. 注意力分数 = softmax(Q·Kᵀ / √d_k)   # 点积 = 相似度，缩放 + softmax → 权重
4. 输出 = 注意力权重 · V                 # 按重要性提取 value
```

`Q·Kᵀ` 的点积衡量向量对齐程度，本质是余弦相似度；注意力矩阵对角线分数最高（词与自身最像），语义相关的词之间也高（如 ball 与 tossed）。把“算权重 → 提取特征”打包成一块，就是一个 **attention head**。

## Transformer 与多头注意力

- **Transformer** 是以注意力为骨架的架构，GPT / BERT 里的 “T” 就是它。
- **多头注意力**：堆叠多个 attention head，各自学不同的重要模式。
- 相比 RNN 的最大优势是**高度可并行**，能处理超长序列。
- 应用不限于文本：蛋白质 / DNA 序列、Vision Transformer（下一讲 L3）。

## 识别信号

- 输入带顺序（文本、时间序列、语音）→ RNN 或 Transformer，别用全连接。
- 依赖跨度很长 → RNN 梯度消失，换 LSTM/GRU 或用注意力。
- 问注意力怎么算 → `softmax(QKᵀ/√d)V`，Q 查询、K 匹配、V 取值。
- 问为什么 Transformer 能并行 → 没有递归依赖，整句一次性算完，靠位置编码补顺序。
- 训练序列很长 → BPTT 展开代价大，用截断或换 Transformer。

## 易错点

- RNN 的权重在时间步间共享，不是每步一套。
- 梯度消失的根源是反复乘 `W_h`，不是“网络不够深”。
- attention 不除以 `√d_k` 时，点积方差随维度增大，softmax 过度尖锐、梯度变小。
- 位置编码不能省：self-attention 本身对词序不敏感。

## 总结

RNN 用 `h_t = tanh(W_h h_{t-1} + W_x x_t)` 把历史带下去，权重共享、BPTT 训练，但受困于编码瓶颈、串行和梯度消失。Transformer 抛弃循环：Q/K/V 变换 → `Q·Kᵀ` 算相似度 → softmax 得权重 → 加权提取 value，可并行、长记忆，多头堆叠就是 GPT/BERT 的骨架。
