# 循环神经网络、Transformer 与注意力 · 6.S191 · L2

**时间:** 2026-10-19 观看 · 2026-10-20 整理
**标签:** #6.S191 #循环神经网络RNN #序列建模 #注意力Attention #Transformer
**关联:** [[L1 深度学习基础]]（上一讲）

## 一句话

序列数据（文本/音频/视频/时间序列）里「当前」依赖「过去」。RNN 用一个**内部状态 h** 把过去信息一步步带下去；但 h 有「编码瓶颈」且串行慢，于是 Transformer 用**注意力 attention** 一次性看全序列、挑出重要部分，既并行又长记忆。

## 实际情况

### 1. 序列建模：数据在时间上有关联

L1 的前向网络处理的是「一次性」输入；序列数据是**在时间上展开**的。核心动机：只给「球现在的位置」猜下一步是瞎猜，但给「球过去一串轨迹」就能预测下一步——**预测 t 时刻的状态，要用到 t-1、t-2… 的历史**。

三类任务形态（按输入/输出数量分）：

| 形态 | 例子 |
|---|---|
| 多 → 一（分类） | 一条推文 → 情感标签 |
| 一 → 多（生成） | 一张图 → 描述文字（image captioning） |
| 多 → 多（翻译） | 英文句 → 中文句 |

### 2. RNN 的直觉：内部状态 = 记忆

前向网络若按时间步反复套用，各时间步是**互相隔离**的（t=0 和 t=1 之间没联系）。要建立联系，RNN 引入一个**内部状态 h_t**（网络自己维护、一步步往下传的「记忆」）：

```
h_t = f(h_{t-1}, x_t)        # 当前状态 = f(过去记忆 + 当前输入)
ŷ_t = g(h_t)                 # 用当前状态做预测
```

关键：**还是同一个网络、同一套权重**，不是每个时间步一个新网络；只是把上一次计算的结果接回下一次。所以「循环 recurrence」= 把过去的信息连到当前。这一步最绕，务必记住：**h 是「网络的记忆」，每走一步就更新一次，再交给下一步。**

### 3. RNN 的数学（拆开看，和 L1 一样不神秘）

就是把 L1 那套「乘权重矩阵 + 加和 + 过非线性」用两次：

```
h_t = tanh( W_h · h_{t-1} + W_x · x_t + b )   # 状态更新：旧状态 + 当前输入
ŷ_t = W_y · h_t                                # 输出：用状态做预测
```

- 三组权重矩阵 **W_h（旧状态）、W_x（输入）、W_y（输出）都是要学的**，初始化后靠梯度下降更新；
- **每个时间步复用同一套权重**（权重共享）——这让「记忆随时间累积」成为可能；
- 损失 = 各时间步损失之和。

**next-word prediction（下一个词预测）** 是所有语言模型的底层任务：句子「this morning I took my cat for a」→ 逐词过 RNN、更新状态，走到最后一个词后取输出，预测下一个词「walk」。

### 4. 序列数据要满足的四个设计准则

1. **数值化**：网络只吃数字，词要转成数字。朴素做法是 one-hot（第 i 个词 = 第 i 位为 1 的向量），但**捕捉不到语义**；更好的做法是 **embedding 嵌入**——把语义相近的词（learning / education）映到嵌入空间里更近的位置。语言模型会把「常一起出现的词块」映到相近位置。
2. **变长序列**：句子可长可短。前向网络输入维度固定、天然不行；RNN 逐时间步处理、天然适配。
3. **长程依赖**：句首的信息可能影响句尾的预测。
4. **顺序敏感**：「The food was good, not bad」调换词序意思完全反转，同词不同序不同义。RNN 逐步处理天然有顺序。

### 5. RNN 怎么训练：BPTT + 两个坑

训练用反向传播的时序版——**BPTT（BackPropagation Through Time，沿时间反向传播）**：误差从当前时间步一路传回时间步 0。

问题出在「反复乘 W_h」：

- **梯度爆炸**：|W_h| 大 → 反复相乘 → 梯度暴涨。解法：**梯度裁剪 clip**（把梯度值压到一个上限）。
- **梯度消失**：|W_h| 小 → 反复相乘 → 梯度趋近 0 → 几乎没有学习信号。后果：**只学得到短程依赖，抓不住长程**（越往前的信息经过越多次相乘、消失越厉害）。

> 衍生架构：**LSTM（长短期记忆）** 就是为解决「如何更好地控制状态更新、留住长程信息」而生的——把内部计算改复杂以控制信息流。

### 6. RNN 的三个瓶颈（为什么还要往前走）

1. **编码瓶颈**：所有历史都要塞进一个固定大小的 h_t，序列越长越挤不下；
2. **串行、无法并行**：必须一步步处理，慢；
3. **长记忆差**：梯度消失导致长程依赖抓不住。

理想：没有编码瓶颈、能**并行**、能**长记忆**。→ 能不能干脆**不要循环**？天真的做法是把整条序列拼成一个巨长向量喂进前向网络，但（a）序列变长网络爆炸式变大、（b）**丢了顺序信息**、（c）无法「挑出重要部分」。→ 于是有了注意力。

### 7. Attention：让网络学会「挑重点」

**直觉**：注意力 = 网络学会「这条输入里，哪些部分对表达这条输入最重要」。像人看一张图，不会逐像素扫，而是一眼锁定关键物体。

**三步走（Query / Key / Value）**，用「YouTube 搜索」类比最好懂：

- **Query（查询）**：你想找什么，比如「deep learning」；
- **Key（键/索引）**：数据库里每个条目的标签，比如视频标题；
- **Value（值）**：条目本身（视频）。

流程 = ① 算「query 和每个 key 的相似度」→ ② 相似度过 softmax 变成 0~1 的**注意力权重** → ③ 用权重去加权提取 value。

**数学（self-attention 自注意力，看序列内部关系）**：

```
1. 位置编码 positional embedding：喂进「整条序列」的同时保留词的位置信息
2. 用三个「可学习的层」把同一份 embedding 变换成 Q、K、V
3. 注意力分数 = softmax( Q·Kᵀ / √d_k )    # Q 与 K 的点积 = 相似度，缩放 + softmax → 0~1 权重
4. 输出 = 注意力权重 · V                    # 按重要性提取 value
```

- **Q·Kᵀ 的点积**就是「两个向量在空间里有多对齐」（即相似度，本质是余弦相似度）；
- 注意力矩阵的**对角线**分数最高（词和自己最像），语义相关的词之间也高（如 ball 和 tossed）；
- 把「注意权重 → 提取特征」打包成一块，叫一个 **attention head 注意力头**，可插进更大的网络。

### 8. Transformer 与多头注意力

- **Transformer** = 以注意力为骨架的架构。GPT / BERT 里的「T」就是 Transformer。
- **多头注意力 multi-head**：堆叠多个 attention head，各自学不同的「重要模式」（像一张图里既看到 Iron Man、又看到楼和飞船）。
- 相比 RNN 的最大优势：**高度可并行**（不用一步步走），所以能处理超长序列。
- 应用不限于文本：**蛋白质 / DNA 序列**（生物）、**Vision Transformer**（视觉，下一讲 L3 的主角）。

## 总结

**本质：** RNN 用内部状态 `h_t = tanh(W_h h_{t-1} + W_x x_t)` 把历史一步步带下去（权重共享、BPTT 训练），但受困于编码瓶颈 + 串行 + 梯度消失（→ LSTM 缓解）。Transformer 用**注意力**抛弃循环：Query/Key/Value 三变换 → Q·Kᵀ 算相似度 → softmax 得权重 → 加权提取 Value，一次性看全序列、可并行、长记忆，多头堆叠就是 GPT/BERT 的骨架。
