神经网络最基本的构件是单个神经元：**点积、加偏置、过非线性**。把神经元堆成层、层堆成网络，再用“损失函数 + 梯度下降 + 反向传播”训练，就是深度学习的骨架。

## 从 AI 到深度学习

AI 造算法处理信息并指导决策；ML 不做显式编程，让机器从数据中学到处理步骤；DL 是用深层神经网络做 ML 的子集。核心算法 1950s~1970s 已有，这一轮爆发靠**大数据**、**GPU 并行算力**和**框架**。DL 与传统 ML 的关键区别是**特征从数据里分层学出来**：人脸检测从“线 → 角 → 眼鼻口 → 脸”逐层抽象，不再靠人手设计。

## 感知机：唯一的构件

单个神经元的前向传播就是三步：

```
y = g(W·X + b) = g(Σ wᵢxᵢ + w₀)
```

1. **点积**：每个输入 `xᵢ` 乘对应权重 `wᵢ`，求和；
2. **加偏置** `b`（即 `w₀`），让函数能上下平移；
3. **过非线性** `g`（激活函数）。

**激活函数为什么必须非线性？** 否则再深的网络也只是线性变换的堆叠，画不出曲线决策边界。sigmoid 输出 `[0,1]`，适合概率；ReLU 输出 `[0,+∞)`。训练好的神经元是一个**决策边界**：`W·X+b` 的正负决定点在边界哪一侧，过 sigmoid 后变成概率。

## 从感知机到深度网络

- **一层**：多个神经元共享输入、各有权重，`W` 的形状是“输入维度 × 输出维度”。
- **多层**：`输入 → 隐藏层 → 输出`，中间必须夹非线性，否则两层线性等价于一层。
- **深度网络**：很多“线性层 + 层间非线性”堆叠，通常超过 3 层叫 deep。

TensorFlow 的 `Dense`、PyTorch 的 `Linear` 本质都是“矩阵乘 + 加偏置 + 过非线性”。

## 损失函数

训练目标是最小化整个数据集上的平均损失：

```
J(W) = (1/N) Σ L(f(xᵢ; W), yᵢ)
```

- **分类**（输出概率）→ **交叉熵 cross-entropy**；
- **回归**（输出连续值）→ **MSE** 或 **L1**。

## 梯度下降

目标是找使 `J(W)` 最小的权重：

```
W ← W - η·∇J(W)
```

随机初始化 → 算当前梯度 `∇J`（局部上坡方向）→ 沿反方向走一小步 `η` → 重复到收敛。`η` 太小会卡在局部最小值附近，太大可能越过最小点、损失爆炸。

## 反向传播

梯度用**反向传播 backprop** 计算，本质是链式法则：

```
∂J/∂W2 = ∂J/∂ŷ · ∂ŷ/∂W2
∂J/∂W1 = ∂J/∂ŷ · ∂ŷ/∂z1 · ∂z1/∂W1    （z1 是中间层激活前的值）
```

从输出端往回逐层传梯度，就得到每个权重对最终损失的影响。损失地形高度非凸，实践中常配自适应优化器：**Adam / AdaGrad / AdaDelta / RMSProp** 会按梯度大小调步长、带动量冲过局部谷底。

## 实用考量

**批量大小**

| 方式 | 每次用多少数据 | 特点 |
| --- | --- | --- |
| full-batch | 整个数据集 | 梯度最准，极慢 |
| SGD | 一个点 | 极快，噪声大 |
| mini-batch | 一小批（常见 32） | 速度与精度的折中，最常用 |

**过拟合与欠拟合**：欠拟合是模型太简单；过拟合是模型太复杂，把训练集噪声也背下来，训练 loss 变好、测试 loss 变差。

**正则化**：**Dropout** 每轮以概率 `p` 随机把部分隐藏层输出置 0，逼神经元不依赖固定通路；**Early stopping** 在测试 loss 开始回升时停下，用拐点处的 checkpoint。

## 易错点

- 层间忘了非线性，整个网络退化成线性模型。
- 学习率过大导致 loss 爆炸，过小导致训练几乎不动。
- 训练 loss 下降不代表泛化变好，必须同时看验证/测试曲线。
- 回归用交叉熵、分类用 MSE 都是错配；full-batch 也不一定更好。

## 总结

单神经元 = 点积 + 偏置 + 非线性；堆成层与深度网络。损失函数量化误差，梯度下降沿负梯度更新，反向传播用链式法则算梯度。mini-batch 折中速度与精度，自适应优化器调步长，dropout / early stopping 抑制过拟合。
