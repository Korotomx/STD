## 一句话

神经网络最基础的构件是单个神经元（感知机），它只做三件事——**点积、加偏置、过非线性**。把神经元堆成层、层堆成深度网络，再用「损失函数 + 梯度下降 + 反向传播」训练它，就是深度学习的全部骨架。

## 实际情况

### 1. AI ⊃ ML ⊃ DL，以及为什么是现在

- **AI** = 造算法「处理信息 → 指导未来决策」；
- **机器学习 ML** = 不做显式编程、让机器**从数据学**到处理信息的步骤（这是和传统 AI 的分界）；
- **深度学习 DL** = 用（深层）神经网络来做这件事的 ML 子集。

核心算法 1950s~1970s 就有了，现在重新爆发靠三样：**大数据**（算法靠数据喂）、**硬件**（GPU 并行算力）、**软件**（框架让训练部署平民化）。

深度学习相比传统 ML 的关键：**特征从数据里分层学出来**，不再靠人手设计。像人脸检测，人从「线 → 角 → 眼鼻口 → 脸」逐层组合，深度网络也从低级特征（边/线）逐层抽象到高级特征（对象）。

### 2. 感知机：唯一的构件

单个神经元（perceptron）的前向传播就是三步：

```
y = g( W·X + b ) = g( Σ wᵢxᵢ + w₀ )
```

1. **点积**：每个输入 xᵢ 乘对应权重 wᵢ，求和；
2. **加偏置** b（= w₀，让函数能上下平移）；
3. **过非线性** g（激活函数）。

写成向量形式 `y = g(X·W + b)`，简洁很多。**这三步是整个深度学习的核心方程。**

**激活函数为什么必须是非线性？** 因为真实世界高度非线性。二维里「红线绿点」都画不出一条直线分开，何况高维真实数据。没有非线性，再深的网络也只是线性变换的堆叠、等价于一个线性函数——没法拟合曲线边界。sigmoid 输出 [0,1]，适合概率（分类）；ReLU 输出 [0,+∞)，引入非负约束。

一个训练好的神经元可以看作一个**决策边界**（二维里就是一条线）：`W·X+b` 的正负决定点在线的哪一边，过 sigmoid 后变成 0/1 之间的概率。参数越多，边界维数越高（现代网络是十亿维空间）。

### 3. 从感知机到深度网络

- **一层**：多个神经元共享同一输入、各有各的权重，`W` 是「输入维度 × 输出维度」的矩阵；
- **多层**：`输入 → 隐藏层 → 输出`，两个权重矩阵 W1、W2；**中间必须夹非线性**，否则两层线性等价于一层；
- **深度网络**：就是「很多层线性层 + 层间非线性」堆叠（通常 >3 层叫 deep）。

框架里这一层已内置：TensorFlow 叫 `Dense`、PyTorch 叫 `Linear`，本质都是「矩阵乘 + 加偏置 + 过非线性」。

### 4. 损失函数：衡量错得多离谱

每次前向得到一个预测 ŷ，和真实 y 有差距，**损失 loss = 这个差距**。训练 = 最小化整个数据集上的**平均损失** J(W)：

```
J(W) = (1/N) Σ L(f(xᵢ; W), yᵢ)
```

按任务选损失：
- **分类**（输出概率，0~1）→ **交叉熵 cross-entropy**（比较两个概率分布）；
- **回归**（输出连续值，如温度/分数）→ **MSE 均方误差** 或 **L1**（比预测值和真实值的绝对差）。

### 5. 梯度下降：怎么找到最优权重

目标：找让 J(W) 最小的权重 W。J(W) 是「权重 → 损失」的函数（二维参数就能画成一片高低起伏的地形）。

```
W ← W - η·∇J(W)
```

1. 随机初始化权重；
2. 算当前点的**梯度** ∇J（= 局部的「上坡方向」）；
3. 沿梯度的**反方向**（下坡）走一小步 η；
4. 重复直到收敛。

**η = 学习率**：步子大小。太小 → 卡在局部最小值出不来；太大 → 越过最小点、损失爆炸。理想是「大到能跳过假谷底、又小到能停进全局谷底」。

### 6. 反向传播：梯度怎么算

梯度 ∇J(W) 是关键，但怎么算？用**反向传播 backprop**——本质就是**链式法则**：

```
∂J/∂W2 = ∂J/∂ŷ · ∂ŷ/∂W2
∂J/∂W1 = ∂J/∂ŷ · ∂ŷ/∂z1 · ∂z1/∂W1    （z1 是中间层激活前的值）
```

从输出端一路往回，把梯度逐层传回输入端，就得到「每个权重对最终损失的影响」。越深就多套一层链式法则。实践中损失地形是**高度非凸**的（很多谷底、依赖初始化），所以常配自适应优化器。

### 7. 优化技巧

vanilla SGD（`W ← W - η∇J`）很少直接用，一般用**自适应学习率**优化器（**Adam / AdaGrad / AdaDelta / RMSProp**）——它们会根据当前位置梯度大小自动调步长、带动量冲过局部谷底。

### 8. 实用考量

**（a）批量大小的三种粒度**：算梯度有三种——
- **full-batch**：整个数据集算一次梯度，最准但极慢；
- **SGD（随机）**：一次只看**一个点**，极快但噪声大；
- **mini-batch**：看一小批（常见 batch=32，大模型可到百万），**速度和精度的折中**，最常用。

**（b）过拟合 vs 欠拟合**：
- 欠拟合：模型太简单（如线性拟合非线性），没学到规律；
- 过拟合：模型太复杂，把训练集的噪声细节都背下来，**训练集越来越好、测试集越来越差**，泛化不了；
- 理想在中间。

**（c）正则化**：约束模型复杂度、抑制过拟合的手段。
- **Dropout**（架构层）：每轮以概率 p（如 0.5）**随机把部分隐藏层神经元的输出置 0**，同一 mini-batch 内固定、下个 batch 重抽。逼着每个神经元不依赖任何一条固定通路 → 促进泛化。
- **Early stopping**（通用，不挑架构）：训练时同时监控**训练集 + 测试集**两条 loss 曲线；当测试集 loss 开始回升（= 开始过拟合）就停，用拐点处的 checkpoint。原理：「训练持续变好但测试变差」正是过拟合的定义。

## 总结

**本质：** 单神经元 = 点积 + 偏置 + 非线性；堆成层、层堆成深度网络。训练三件套——损失函数（分类用交叉熵、回归用 MSE/L1）量化误差，梯度下降沿负梯度方向更新权重，反向传播用链式法则算梯度。实用上：mini-batch 折中速度精度，自适应优化器（Adam）调学习率，正则化（dropout / early stopping）防过拟合。
