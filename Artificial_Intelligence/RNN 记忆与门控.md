# RNN 记忆与门控 Memory & Gating · Kirsanov「Most AI has amnesia」

**时间:** 2026-10-20 观看 · 2026-10-20 整理
**来源:** Artem Kirsanov《Most AI has amnesia. Here's the fix》(YouTube `PAoe7mmmvp0`)
**标签:** #RNN #循环神经网络 #LSTM #GRU #门控记忆 #泄漏积分
**关联:** [[L2 循环神经网络与Transformer]]（6.S191 RNN 主线）· [[L1 深度学习基础]]（前馈网络 / 激活函数）

## 一句话

前馈网络是「失忆的专家」——只看当前输入、没有时间概念。给它加一个**「回响 echo」**项(当前状态 = 前馈项 + 过去状态的回响),就得到 RNN 全家桶;而「回响用什么函数」这一个问题,依次推出 **vanilla RNN(健忘)→ 泄漏积分(自然界的默认)→ 门控记忆(GRU/LSTM)** 三代答案,最后一种才是真正能学长程依赖的关键。

## 实际情况

### 0. 问题:前馈网络没有时间

- AlexNet 一次只看一帧,输出 1000 类概率;把一部电影的所有帧**随机打乱**,它毫无察觉——每个输入完全独立,没有上下文。
- 像得了重度逆行性失忆的专家:能告诉你图里是什么,图一消失就忘得一干二净。
- 人脑看视频是「当前帧被前一帧深刻塑造」——建立上下文、预判下一步、理解时间的箭头。**怎么给机器装上记忆?这就是 RNN 的动机。**

### 1. 前馈网络的最小回顾:一条方程

- 神经元 = 「证据加权器」:输入信号 × 权重 → 求和 → 内部状态(类比膜电压);再用激活函数 σ 把内部状态转成**发出去的下游信号**。
- 一层里的所有神经元用**线性代数**打包成向量 h(层的状态),层间连成权重矩阵 W。整层更新压成一条方程:

```
h_L = W_L · σ(h_{L-1})     # 「fire(σ) and project(W)」
```

- 这是**前馈网络的基本公式**:静态、单向、无记忆——新状态只依赖上一层此刻的信号,**不知道 5 分钟前发生了什么**。

### 2. 加回响:vanilla RNN

- 让状态带上**过去自己的回响**:当前状态 = 前馈项(上一层现在发的信号)+ 时间项(过去状态经「记忆函数 M」传来的回响)。

```
h_t = W_in · σ(x_t)  +  M(h_{t-1})
```

- **最自然的 M 怎么选?** 1980s 研究者的第一个选择:照抄前馈路径的「fire and project」,让时间方向的箭头和层方向的箭头对称,只不过换一组**递归权重 W_rec**:

```
M(h_{t-1}) = W_rec · σ(h_{t-1})
h_t = W_in · σ(x_t) + W_rec · σ(h_{t-1})
```

- 这就是 **vanilla RNN**。但它有个致命问题:**记不住长程依赖**——记忆只能撑几步。

### 3. 为什么 vanilla RNN 健忘:选错了操作

- 信息沿时间轴每走一步,就过一次 σ、乘一次 W_rec,被「压缩、旋转、投影」一次;走 100 步就被加工 100 次,像电话游戏里每传一人不是复述而是**改写**。
- 根源:这个 M 是**从前馈路径抄来的,而前馈路径天生就是为了「丢信息」**——把千姿百态的猫(姿态/光照/背景)全部压成同一个输出。**前馈 = 压缩,不是保存。**
- ⭐ **关键洞察**:要跨时间可靠地存信息,得有一条**信息能原样流过、只做受控修改**的通路。视觉网络早就撞到同一个洞察——**残差连接 residual connection**(绕过层变换的直达捷径),它让超深网络可训练。vanilla RNN 缺的正是「跨时间的残差」。

### 4. 泄漏积分:α 旋钮(自然界的默认)

- 最简单的「保存型」回响:回响 = 只保留上一状态的 **α 比例**:

```
h_t = W_in · σ(x_t) + α · h_{t-1}
```

- 旋钮 α 三种情况:
  - **α=0** → 回响消失,退化成失忆的前馈网络;
  - **α=1** → 状态完全保留、新输入往上叠 = 残差连接。但序列长度不固定(几个帧到 50 万帧),展开后是「所有历史输入的运行总和」——什么都不丢,但**什么都翻不出来**,像从不扔信、桌子被埋、每封信同样够不着。**这不是记忆,是囤积。**
  - **0<α<1** → 近期输入强、旧输入**指数衰减**——一个**漏水桶**,信息灌进来、慢慢漏出去。
- ⭐ 意外的巧合:漏水桶正是**自然界最爱的记忆机制**——神经元的膜电压就是这么工作的(突触输入充电、离子通道漏电);计算神经科学最常用的模型「**泄漏积分-放电神经元 leaky integrate-and-fire**」就是这个方程。

### 5. 门控记忆:LSTM / GRU

- 单个 α 不够:一个角色名(片头提一次)要记一整部电影,而每一帧的取景细节下一秒就没用了——**同一个 α 无法两头兼顾**。
- 解法:把标量 α 换成**每个神经元一个、每步按上下文重算**的门控向量 **f(t)**:

```
h_t = W_in · σ(x_t) + f(t) ⊙ h_{t-1}
f(t) = σ( W_f · [x_t, h_{t-1}] + b_f )     # 门 = 一个小 sigmoid 网络
```

- **遗忘门 f(t) 从哪来?** 一个小神经网络(sigmoid 激活),同时看「当前持有的状态」和「新来的输入」,给每个神经元输出一个 0~1 的数:门≈1 状态原样通过,门≈0 旧值被擦掉、给新信息腾地方。
- 这个「**受控的、按上下文的选择性遗忘**」就是**门控 RNN**的核心,让它终于能学长程依赖。
- 两大代表:**GRU**(遗忘门 + 互补的更新门)、**LSTM**(用两个状态向量,把「神经元知道什么 cell state」和「对外喊什么 hidden state」分开)。这些都是工程细节,核心都是同一个东西——**回响上的自适应阀门**。

## 总结

**本质:** RNN 全家桶只是「回响 echo 用什么函数」这一个问题的三种回答——照抄前馈的 fire-and-project → vanilla RNN(健忘);固定标量衰减 α → 泄漏积分(自然界的漏水桶,但记不住「该记的」);按上下文学习的逐神经元门 f(t) → 门控 RNN(GRU/LSTM,选择性遗忘,能学长程依赖)。全程一条推理链:存信息需要「信息原样流过」的通路(残差连接的精神),而「选择性遗忘」正是生物神经元膜电压的原理。
