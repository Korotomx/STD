Python 的对象模型只有一条主线：**变量是贴在对象上的标签，赋值不复制对象**。由此推出可变/不可变、别名、浅/深拷贝和可变默认参数四个坑；对象本身动态类型，并通过鸭子类型、迭代协议和魔法方法接入语言。

## 引用、身份与相等

`x = [1,2,3]` 先创建列表对象，再把名字 `x` 贴上去；`y = x` 给同一对象再贴一个标签，没有复制。

```python
x = [1, 2, 3]
y = x
y.append(4)
print(x)        # [1, 2, 3, 4]
x is y          # True
```

- `is` 比身份（等价 `id(a) == id(b)`），`==` 比内容。
- 改 `y` 影响 `x`，因为只有一个列表对象。

## 可变与不可变

| 类型 | “修改”的行为 | 修改后 `id` |
| --- | --- | --- |
| `list` / `dict` / `set` | 原地改 | 不变 |
| `int` / `str` / `tuple` | 新建对象、重新贴标签 | 变 |

所以 `s = s + " world"` 是造新串。不可变且内部元素都可哈希的对象（如 `tuple` of `int`）可作 dict 键或 set 元素；可变对象不行（见 [[N002 dict 常用语法]]）。

ML 里的对应：numpy 切片 `b = a[2:5]` 是 view（别名），改 `b` 会改 `a`，`.copy()` 才独立；PyTorch `x + 1` 新建张量，`x.add_(1)` 原地修改，后者可能破坏 autograd 的梯度计算。

## 别名、浅拷贝与深拷贝

`a[:]`、`a.copy()`、`list(a)` 只复制外层，内层对象仍共享；`copy.deepcopy(a)` 递归复制，嵌套结构才完全独立。

```python
import copy
a = [[1], [2]]

b = a.copy()
b[0].append(9)          # a[0] 也变成 [1, 9]

c = copy.deepcopy(a)
c[0].append(7)          # a[0] 不变
```

## 默认参数：定义时只求值一次

`def f(item, target=[])` 里的 `[]` 在 `def` 执行时创建一次，之后每次调用都用同一个对象。默认值应改用不可变哨兵，在函数体内创建容器。

```python
def add(item, target=None):
    if target is None:
        target = []
    target.append(item)
    return target
```

`None` 是 `NoneType` 的唯一实例（单例），判断它用 `is None` 而不是 `== None`：`==` 会调用 `__eq__`，可被重写，也可能返回非 bool——numpy 数组做 `arr == None` 会得到逐元素数组或直接报错。

## 动态类型

变量没有类型，值才有；标签随时可以改贴到别的对象上。

```python
a = 5
a = "hello"
type(a)     # str
```

`type(a)` 查的是 `a` 当前指向对象的类型，不是变量声明过的类型。这也是 `train_loss = 0.0` 之后可以直接 `train_loss += loss.item()` 的原因。

## 鸭子类型、迭代协议与魔法方法

Python 的接口靠约定，不靠继承：对象只要有对应方法，就能用于对应语法。

- `for x in obj` 不是计数循环，而是调用 `iter(obj)`，反复 `next()` 直到 `StopIteration`；背后是 `__iter__` / `__next__`。所以 list、文件、生成器、`DataLoader` 都能被 `for` 遍历。
- 自定义 `Dataset` 实现 `__len__` 和 `__getitem__`，就能被 `len()`、索引和 `for` 使用，不需要继承特定基类。

| 写法 | 实际调用 |
| --- | --- |
| `len(x)` | `x.__len__()` |
| `x[i]` | `x.__getitem__(i)` |
| `x + y` | `x.__add__(y)` |
| `str(x)` | `x.__str__()` |

## Pythonic 速记

- EAFP：先做、出错再处理（`try/except`），而不是一层层预检。
- 解包：`a, b = b, a`；`for k, v in d.items()`；`a, *rest = xs`。
- 推导式：`[x * 2 for x in xs]`；成员判断用 `in`。
- f-string、三元 `a if cond else b`、链式比较 `0 < x < 10`、切片 `xs[::-1]`。
- 真值：`None`、`0`、空容器、空字符串都为假，可以写 `if not items:`。
- 缩进即语法，Python 对缩进敏感。

## 坑与边界

- 可变默认参数跨调用共享，是训练循环里 `losses=[]` 越积越多的根源。
- 浅拷贝只复制一层；嵌套可变对象仍是别名。
- `is` 只用于 `None` 和单例比较，不要用来比数值或字符串内容。
- `del a` 只撕掉标签，不释放对象；引用计数归零才回收。

## 总结

赋值是贴标签而非复制；可变/不可变决定“修改”是原地还是新建；别名、浅拷贝、默认参数坑都是引用模型的直接推论。动态类型、鸭子类型、迭代协议和魔法方法则说明：Python 的接口由方法和协议约定，而不由类型声明保证。
